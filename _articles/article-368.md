Snp-897是寰宇重工自主研发、由[Snp-762]({{ '/articles/article-367/' | relative_url }})衍生的外贸战斗步枪，猎人也是已知使用者之一。其全自动能力用于应对突然快速逼近的大型野兽。

## 定型参数

| 项目 | 参数 |
| --- | --- |
| 工作原理 | 导气式、旋转闭锁枪机 |
| 枪机及机匣 | 适应7.62×51mm的新尺寸机构 |
| 射击模式 | 半自动／全自动 |
| 弹药 | 7.62×51mm |
| 标准弹匣 | 20发专用弹匣 |
| 可选弹匣 | 10发低突出量弹匣 |
| 拉机柄 | 左侧独立布局 |
| 空仓挂机 | 支持 |
| 枪管长度 | 510mm |
| 枪全长 | 1040mm |
| 空枪质量 | 4.6kg，不含弹匣及瞄具 |
| 自动射速 | 580发／分钟 |
| 100m机械支撑散布精度 | 1.3 MOA，与Snp-762在可比较的优质弹药测试条件下评估 |
| 实用有效射程 | 650m，典型单兵目标 |

采用专用7.62×51mm弹匣，不与使用7.62×45mm的Pck-35、Snp-762共用弹匣。有效射程在实战中受环境与射手条件影响。

## 代表性弹道与弹种

代表性弹道为7.62×51mm弹药、9.7g弹头、790m/s枪口初速，枪口动能约3.03kJ。此为型号代表参数，不同弹种、制造批次及环境允许变化。

已明确两种弹药名称及弹尖颜色：

- 格斗弹：黑色弹尖。
- 射手弹：铜色弹尖。

两者具体弹体结构、穿透、膨胀、精度差异及各自弹道尚未确定。黑尖不自动等于穿甲弹，型号代表参数也不代表两种弹药各项数据完全相同。Snp-897的综合作战威力系数尚未确定。

## 作战定位

全自动档是面向突然接近的危险大型野兽的应急能力，不代表日常必须以连发为主。7.62×51mm的后坐力与枪口上跳依然存在，全自动可用不等于长时间连续射击仍能保持低后坐力冲锋枪般的精度。

其精度比原版Snp-762略高，指可控精确射击条件下的枪械固有精度，不表示全自动散布天然优于半自动射手步枪。
