# 双政权第二轮交涉与国内监督危机

旧联合城与民众联邦在第一次跨控制区政治技术交涉中形成[《跨控制区必要公共事务临时联系备忘录》]({{ '/articles/article-435/' | relative_url }})后，双方继续处于军事对抗、主权争议及金融结算隔离之中。备忘录只规定了必要公共事务的联络渠道，并没有免除药品运输、财政支出、人员资料保护和设施维护中的实际困难。

随着部分联络事项进入执行阶段，**政治争议由“应不应该接触对方”转变为“已准许的事项由谁批准、监督、付款、纠错并承担责任”**。由此出现第二轮交涉及双方国内的监督危机。其制度结果是形成补充实施规则——**《必要公共事务联络执行附则》**。它为第一轮备忘录提供较明确的程序，不是新的建交条约、全面停战协议或总括债务继承安排。

## 一、争端的开始：双重放行与责任不明

在备忘录生效后的初期，一批用于医院的必要药品及卫生耗材在跨控制区转运中出现延误。供货、付款、运输路线和最终交接由不同主体负责，持有一方准许的运输证明，并不代表另一方及沿线实际控制机构已经核准全部手续。

各方起初对延误原因提出不同解释。旧联合城的部分官员认为应当严格核对医疗用途、收货机构与运输安全；民众联邦的地方卫生人员则认为既有批准重复核验导致不能及时交货；有关运输和支付主体还提出合同责任及可实际结算资金不足的问题。

此后核查确认：**多层行政许可、材料格式不一致、责任主体未能准确对应和支付保证不足，共同造成了部分执行障碍**。没有充分资料能够把所有延误归因于某一方蓄意妨碍，也不能仅凭民众联邦已获得个别医疗运输许可，就要求旧联合城开放其全部共同贸易结算网络。

受到影响的医院不得不调整一部分采购与治疗安排。既有备忘录能建立联系，但如果没有能够落实到经办人员和地方设施的执行规则，其效果十分有限。

## 二、旧联合城的国内政治反弹

### 议会监督与行政授权争议

卡卫政府参加第一次有限交涉后，旧联合城公民院和城邦院内部出现质询：行政机关是否通过技术联系事实性扩大了对民众联邦的贸易许可？相关支出由哪个预算项目支付？如果新增义务涉及成员城邦财政，应当由谁审议？

这种质询不等于议会全体反对医疗或人员查找，也不等于政府的全部联系工作违法。**行政机关在已有合法授权内可以处理具体事务，但不能通过国际性质不明的备忘录绕过法定预算、成员协议和司法监察。**

联邦秘书长**铭岸希李·卡卫**维护既有政府对外立场，强调有限居民事务联系不意味着承认民众联邦国家主权，也不改变旧联合城保有原组织席位、拒绝新政权直接加入共同结算体系的政策。他要求行政部门说明既已批准的通行事项为何仍发生不必要的延误，并对超出授权的承诺进行审查。

上院代表**欧姆西卡**支持必要的人道事务，但坚持各正式成员的财政协议不能因中央对外联系被永久改写。某成员提供铁路维护、仓储或能源支持时，费用应先识别适用的原有合同、合法财政义务及新的专门授权；不能一概认定由自治成员免费承担。

公民院议员**顾予宁**则强调居民权益：失踪人员名单的核验应有隐私边界，不能因为战争与政权对立便将家属的全部身份记录交由不受约束的机关查看；对医疗转运的安全核验也不能无限期搁置基本救治。

财政专业官员**伊莲娜·彼得罗夫**提出，将所有承诺分为已经在现有预算中获准支付、需要重新拨款、由合同相对方承担、尚不能确认法律责任四类。她提醒有关议员：**签发运输许可、确认一笔应付款与国库已有现金完成支付，属于不同的行政及财政事实。**

司法与监察体系保留依法审查官员权限、采购程序、信息处理与成员财政责任的职能。**有议会质询不等于相关官员已经被法院认定犯罪，政治批评也不能替代审计结果。**

### 危机没有推翻双院制

在这场反弹中，卡卫政府没有以战争为由解散议会；欧姆西卡也没有因财政争议宣布其代表的成员退出旧联邦。双方经过质询、部门说明及预算审议，继续维持可以依法执行的必要公共事务项目，同时要求政府缩小含混承诺、提高负责机关的可追责性。

原有六年秘书长任期、建设性不信任原则、两院合法表决条件继续有效。战争造成的出席与选区困难没有被一次特别听证自动消除。

## 三、民众联邦内部的政治反弹

民众联邦的**临时代表会议**也对第一轮联系结果展开审议。**过渡执政委员会**能够协调具体执行，并不等于它拥有未经代表会议授权决定所有公共资产、国防和永久外交立场的无限权力。

三种政治路线对此发生新的分歧。

**民生与法治建设路线**认为，能够确认失踪者消息、取得药品和继续使用原公共档案，证明有限接触有必要。但必须约束收集个人信息的范围，确保受影响居民能够提出纠错请求，并公开说明有限救助与正式养老金清偿的差别。

**共同安全与战时集中路线**忧虑通行名单、沿线设施信息及人员调配可能使军事安全受损，要求对跨区人员和路线进行必要审查。然而军事机关提出风险，不意味着它可以不经相应授权任意取消全部救助或直接掌握正常地方医院管理权。

**地方自治与解放区协作路线**则质疑过渡中央机关是否在与旧联合城谈判时替地方承诺费用，或者把原由地方管理的医院、供水、供电系统纳入新的中央控制。其要求是地方有能力参与设施服务及预算责任的商议，而不是地方可以完全不承担共同财政义务。

新政府最终要求过渡执政委员会在后续交涉中分别呈报**实际已完成的救助、尚未兑现的公共支出、涉及当地机构的合同与财产义务，以及需要新的议事授权的项目**。

这场争论没有形成一支自动取代临时政府的新全国政党；它进一步确立了民众联邦政治内部既有路线可以合作也可以互相监督的实践。

## 四、养老金证明争论：一纸认证不能代替到账

双方有限交换养老缴费资料后，一部分居民认为既然劳动记录已经证实，过去被拖欠的待遇应立即全部恢复。地方工作人员却指出，**证明某人的缴费史、确认原制度的给付义务、找到有关基金资产以及跨区完成付款，仍然是不同环节**。

民众联邦的临时救助可以在其财政允许范围内缓解居民生活困难；不能据此直接宣称全部原联邦养老金债务已归新政府承担。旧联合城也不能仅凭政治分裂宣称所有旧有缴费记录在法律上毫无意义。

第二轮交涉因而将**凭证真实性与责任主张分离**列为明确原则。任何一方确认对方提交的历史凭证是真实材料，不自动承认自己立即承担该凭证所载的全部金额。

## 五、跨区电力和铁路：维修权不等于所有权

双方又围绕部分相连公共设施发生费用和安全责任争执。

对于一处跨控制区公共设施，**允许工程技术人员检修、让居民继续使用服务、划分紧急事故通报责任和决定设施产权**是不同事务。

旧联合城的一些机构担忧维修通道被未经授权用于军事物资调动；民众联邦的地方政府则担忧旧方借维修名义恢复对设施的行政指挥。双方技术人员在实际工作中仍需要交换能够支持安全检修的必要信息。

因此第二轮交涉不统一划分全部跨线工业资产，而要求**逐项登记实际维护人、设施所在地、临时费用承担、通行限制和事故处理方式**，对不能解决的产权争议另行记录。局部维修可以开展，不代表永久划界、全面重开铁路运输或允许任何一方无限制进入另一方控制区域。

## 六、《必要公共事务联络执行附则》

经过双方分别审查内部授权、财政和安全要求，第二轮交涉形成**《必要公共事务联络执行附则》**，作为第一次备忘录的补充实施文件。它不是取代原备忘录的全新国家关系制度，而是限制并明确原来已获允许的事项。

| 执行事项 | 确立的规则 |
| --- | --- |
| 负责机关 | 每项事务分别载明双方具备权限的执行机构及必要地方联系人 |
| 医疗物资 | 明确申请、用途证明、付款责任、双侧放行与实际交接记录 |
| 被拘留及失踪人员 | 查找申请与人员确认分离；对未成年人、医疗和家属资料实行用途限制 |
| 铁路电力与管线 | 检修权限、事故报告、工程费用与设施所有权争议分别记录 |
| 工资及养老金资料 | 可以核验证据真伪，但不由确认凭证自动产生新的无限支付保证 |
| 财政授权 | 超出已有预算或成员协议范围的承诺须返回有关合法机关审议 |
| 异议与审查 | 设置事项编号、经办责任、答复、纠错及限制范围内的暂停机制 |
| 政治边界 | 不构成全面停战、正式建交、永久领土承认或旧结算网络的普遍开放 |

**该附则不是一个脱离两国行政体系而独立拥有强制执行权的超国家机构。**其执行依赖双方各自有效控制区的合法机关、实际愿意参与的地方设施与承包人员，以及可以兑现的资源。不能因它有书面程序，便宣称所有跨区关系已经恢复正常。

## 七、第二轮交涉的实质成果与未解决问题

第二轮交涉以后，一部分医疗运输和设施检修申请能够更清晰地找到负责机关；部分人员查找请求减少了重复提交资料的情况；有关养老金记录的官方答复也更明确地区分了档案核验与支付义务。

这些有限改进**没有统一恢复两国之间的银行结算，也没有使战时物流、财政或司法困难消失**。有些地方仍因实际战线、人员不足或运输中断难以办理许可；不具备安全与履约条件的事项可能继续延后。

旧联合城的国内政治反弹没有废除第一次备忘录，但促使卡卫政府提高对议会、成员协议和监察程序的说明责任。民众联邦内部的争论则推动了临时代表会议对过渡行政的预算与授权监督。

双方依然不承认对方全部主权主张，保留各自的军队与外交路线；**行政联系的程序化只是在战争中的局部治理成果，不是分裂已经走向必然统一或和平的证明。**

## 八、政治对话的重构

以下为根据各方职责和真实制度矛盾撰写的场景性重构，不属于未经证实的逐字档案：

> **旧联合城代表：**“允许运药不意味着我们支付全部运输费，更不意味着开放共同结算系统。”
>
> **民众联邦代表：**“那至少告诉我们，已经签字的运输许可，为什么到了下一处检查点又被要求重新申请。”
>
> **旧联合城财政人员：**“因为批准通行的是卫生机关，下一笔费用属于运输合同。文件将它们写成了同一件事。”
>
> **民众联邦地方代表：**“所以不要再把‘同意办理’写成‘已经完成’。医院里的人看不懂你们公文里的差别。”
>
> **旧联合城代表：**“我们可以把负责机构写清楚。”
>
> **民众联邦代表：**“还有申诉的地方。”
>
> **旧联合城代表：**“可以。但那不是承认你们的法院能审判我们全部官员。”
>
> **民众联邦代表：**“同样不是我们承认你们仍然可以指挥那家医院。”

## 九、后续历史定位

两次交涉逐步形成了**有限接触—国内监督—执行纠错**的制度链条。其意义不仅是双方政府能够谈判，更在于各自国内的议会、代表机关、财政部门与地方政府要求外交承诺真正成为可追责的公共行政行为。

这种长期现实促使双方越来越难以简单把所有跨区接触归类为叛国或投降，却没有消除双方围绕主权、国际承认、合法货币发行、共同贸易结算和永久战争结局的争执。
