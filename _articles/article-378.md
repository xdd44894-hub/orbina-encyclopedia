**SAMW**的正式英文全称为 **Smart Adaptive Multi-role Weapon**，中文装备名称为**分布式智能子母对地导弹**。它是一种防区外发射的**分布式智能子母对地导弹**，设计定位为多目标巡猎武器，主要用于对抗分散的地面装甲集群，并兼顾低空悬停或低速飞行的陆军航空兵目标。

## 精度、识别、毁伤与可靠性：正式试验指标

下列数值是俄庇娜设定中的**SAMW标准型试验标称统计值**。为避免混淆，**母弹投送**与**单个智能子弹药攻击**分开统计；子弹药的命中率不得乘以6后冒充某一目标被命中的概率。

| 统计项目 | 正式基准值 | 口径 |
| --- | ---: | --- |
| CEP圆概率误差 | **约1.6m** | 无主动防御的固定地面靶，单个子弹药的落点中位半径 |
| 目标正确识别率 | **94%** | 标准已知目标集的有效判别，不包含完全未知目标 |
| 固定装甲目标直接命中率 | **90%** | 每个已分配目标的子弹药，标准环境 |
| 移动装甲目标直接命中率 | **78%** | 每个已分配目标的子弹药，标准环境 |

| 中等防护移动装甲目标有效毁伤率 | **66%** | 每个已分配目标的一次子弹药攻击，使目标失去预定作战能力 |
| 高防护主战坦克有效毁伤率 | **32%** | 基准试验目标集，反映其不擅长保证突破最强防护 |
| 低空陆航目标有效毁伤率 | **52%** | 基准目标集，指任务规定的功能失效而非必然坠毁 |
| 强电子干扰环境任务成功率 | **58%** | 每个已分配移动装甲目标的有效毁伤任务，存在强干扰但不额外叠加主动拦截 |
| 较强综合拦截防御下任务成功率 | **45%～60%** | 按不同标准目标与防御组合分别测试的单子弹药任务完成率 |
| 母弹投送及释放系统工作可靠性 | **97%** | 母弹正常抵达规定释放条件并完成释放流程 |
| 单子弹药自身工作可靠性 | **96%** | 已正常释放的子弹药完成其规定的基本启动及运行流程 |
| 整弹任务可靠性 | **约95%** | 一发SAMW至少完成合格投送并使绝大多数子弹药进入可工作状态，不等于命中 |

### 统计条件与定义

- **CEP**是固定靶、指定环境和正常工作条件下，50%的落点落在所报半径内的统计指标；1.6m不是保证每发偏差都小于1.6m，也不适用于运动目标追踪效果。
- **目标识别率**以存在明确正确答案的标准目标识别样本为分母。它不同于发现率，也不意味着飞行员不需要确认任务目标。
- **直接命中率**是对已分配目标发起子弹药攻击的试次中，实际直接命中目标的比例。固定、移动和低空目标分别统计，不可混用。
- **有效毁伤率**按目标是否丧失预定任务能力计算，可以低于直接命中率；某次命中可能只造成非致命损伤。六枚子弹药各自统计，且不保证可以找到六个有效目标。
- **抗干扰条件成功率**涉及整个攻击任务的目标效应，不是单纯“导引头没有失灵”的概率。强电子干扰和主动拦截是不同考题，表中分别描述。
- **任务可靠性**仅反映技术流程能否正常完成，不包含目标是否被找到、击中或毁伤。母弹可靠性、单子弹药可靠性与整弹任务可靠性使用不同分母，不可直接把表中几个百分数相乘当成最终战果。

在已发现并有效分配六个代表性中等防护装甲目标、且无额外强拦截的**示例试验场景**中，一发SAMW可形成约**3～4个目标有效毁伤**的量级统计结果；这不是每次发射都能至少毁伤3个目标的保证，也不是对装甲编队的一律适用结论。

### 空猎-92系列名义挂载能力

[空猎-92A与92B]({{ '/articles/article-369/' | relative_url }})均正式适配SAMW，但它属于相对少见的对地任务弹药。按系列通用重弹挂载能力，**SAMW专门配置标准最大内载为4枚（弹体名义总质量4,480kg）**；与MO混合的已确认重弹组合为**2枚SAMW加1枚MO**。其他携弹配置以及兼容的轻型导弹数见空猎主条目的标准任务表。该上限是内部标准任务构型，不等于通用弹舱可以任意容纳18枚SAMW。

### G-7H空中模块补弹

SAMW现已拥有[寰宇重工G-7H重型多用途空中补给机]({{ '/articles/article-383/' | relative_url }})配套的正式**SAMW重弹补给模块**。每组模块预装**1枚SAMW**，含模块框架的名义总质量约**1.40吨**，可由G-7H在指定条件下整组交付[空猎-92A／92B]({{ '/articles/article-369/' | relative_url }})。专用重弹模块在受弹机已稳定进入补给位置后，典型完整交接约**2～3分钟／组**；等待会合时间和异常重复对接不计入。

接收模块仍受空猎的机体挂载空间和已认证接口容量限制，**空中补弹不增加空猎自身的4枚SAMW标准上限**，也不代表能够无条件给满载飞机继续增加弹药。

### 穿深指标的含义

SAMW以**每个52kg的子弹药**作为独立打击单元，320mm RHA为虚构世界观内标准均质钢靶试验的名义穿深，280～360mm为该类试验的常见表现区间，**不是六个弹头叠加后的总穿深**。每个子弹药只计算自身的命中效果，不把六枚弹药的穿透能力简单相加。

试验值不等于任何实际目标的确定结果：复合装甲、反应装甲、主动防御、命中条件、目标运动和有效识别情况都可能改变战果。SAMW能够应对包括坦克在内的装甲目标，但**不以正面突破所有重型坦克的主防护作为通用保证**；相较之下，其价值更多来自多目标分配和跨地面／低空目标的任务弹性。

### 补充的保障与可靠性约束

每个子弹药可在母弹释放后使用本地判断继续执行有限任务，失去弹间通信不必让其立即失能，但也不能据此推导成没有目标边界、没有任务时限的独立巡猎。12年是符合存储条件且按期检查时的设计封存寿命，并非保证到期仍无须检修、无条件可用。

## 系统组成

| 部分 | 已确认设定 |
| --- | --- |
| 母弹 | 承担远程投送、战场信息接收与中段导航 |
| 智能子弹药 | **6个**，均具备多模态目标感知能力 |
| 分布式决策 | 六个子弹药共享目标信息，进行协同目标分配，减少重复攻击 |
| 自卫与突防模块 | 感知拦截威胁后，可采取“分裂—诱饵—机动”的组合应对动作 |

## 任务过程与目标分工

母弹从防区外发射后，将六个智能子弹药带至目标区域附近并释放。子弹药分组搜索，其中一部分偏向地面装甲目标，另一部分偏向低空悬停或低速陆航目标。具体目标归属并非预先不可更改，而是由子弹药在共享信息的基础上，比较目标类型、可攻击条件等因素后动态决定。

任一子弹药探测到锁定、逼近拦截器或近炸等威胁迹象时，可启动自身的**“分裂”自卫动作**：释放小型诱饵／干扰单元并进行规避机动。其他子弹药则根据变化后的战场情况重新分配任务。

此处的“分裂”是子弹药**放出小型自卫诱饵／干扰单元**的描述，不代表一个子弹药自动裂变成若干枚新的完整攻击弹头。

## 特点与局限

SAMW的主要特点是单次投送可覆盖多个彼此分散的目标，分布式协同减少重复攻击，并避免单个子弹药被拦截就使整个六弹头系统全部失效。威胁感知与自卫动作旨在提高系统生存性，但**不能保证必然突破防御**。

**[空猎-92系列]({{ '/articles/article-369/' | relative_url }})（包括92A与92B）已确认可以挂载和发射SAMW**。不过，相对于标枪-6“刺客”、标枪-8E“长矛”和矛-C77“暴雨”三种常见导弹，SAMW在空猎上的配置**相对少见**。标准SAMW专用内载上限为4枚，亦已确定与MO的常用混载构型；其他构型仍须遵守机体任务挂载与安全限制。不能将系列标称18枚导弹容量直接套用为18枚SAMW。

已经确定母弹基本尺寸、发射质量、名义速度、投送航程、子弹药数量与质量，以及大宗采购参考价。**战斗部内部细节、传感器分型号、正式制造单位、其他正式适配载机与非标准任务构型的具体挂载数量**仍未单独锁定；不能擅自将标称18枚容量套用为18枚SAMW。
