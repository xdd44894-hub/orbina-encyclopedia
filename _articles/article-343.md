以下为联合城联邦完整国家工业体系的年度交付区间。“常态”指非全面战争、正常长期订单下完成验收并可交付服役的数量；“全面战时持续”指扩产稳定后通常自全面动员第三年起可维持的区间，不包括库存舰船。各舰种共享资源，不能将所有区间上限简单相加。年交付量不等于现役总量。

## 主力战斗舰（艘/年）

| 舰种 | 常态 | 全面战时持续 |
|---|---:|---:|
| 永恒常量级武装战略太空母舰 | 1–2 | 2–4 |
| 边境3000级快速太空母舰 | 14–26 | 23–44 |
| 止战级太空战列舰 | 4–7 | 7–12 |
| KaRty-e700“极地”级太空战列巡洋舰 | 110–175 | 180–270 |
| 远岸-600级太空巡洋舰 | 320–480 | 530–780 |
| 牧羊犬级太空驱逐舰 | 650–950 | 1,000–1,450 |
| 灰狐级太空护卫舰 | 1,100–1,650 | 1,750–2,600 |

## 支援、工程与运输单位（艘/年）

| 舰种 | 常态 | 全面战时持续 |
|---|---:|---:|
| M-440“仓桥”级支援舰 | 3,500–5,200 | 5,500–8,000 |
| X8／X10／X20系列工程舰 | 8,000–14,000 | 13,000–20,000 |
| 边境货运2200快速运输舰 | 5,000–8,000 | 8,500–12,500 |
| 载重-90系列重型运输舰 | 2,100–3,600 | 3,500–6,000 |
| LND-8“浅滩”登陆投送舰 | 1,400–2,300 | 2,300–4,000 |
| 公共仓储A7级补给舰 | 9,000–15,000 | 15,000–24,000 |
| 看门人-4型护航艇 | 15,000–26,000 | 25,000–40,000 |

联合城主要采用地面精密制造、模块化生产和轨道总装；也能在地面完整建造可自主行星起降的大型舰船，但成本较高。工程舰、维修、运输和补给体系是其航天工业的重要部分，不能只以主战舰产能衡量全体系。
