**G-7H重型多用途空中补给机**是[寰宇重工]({{ '/articles/article-009/' | relative_url }})正式量产的重型空中补给平台，主要承担**大吨位软管空中加油、预装填武器模块的空中补给、兼用应急运输**三类任务。它已具备标准化装备与正常作战保障用途，**不是实验验证机**。G代表补给机／空中补给系列，7代表该系列第七型，H代表**Heavy（重型）**。

G-7H能够为[空猎-92A／92B]({{ '/articles/article-369/' | relative_url }})以及[和声-1M]({{ '/articles/article-382/' | relative_url }})提供空中燃油补给；其中**空猎-92A／92B还能够接收G-7H转运的标准化武器模块**。和声-1M目前只列为加油对象，不列为武器模块补给对象。

该机以防区外后方作业为主要使用方式，不是隐身突防飞机，也不承担战斗机或预警机任务。

## 软管—锥套空中加油系统

G-7H设有三个软管—锥套加油位置，不采用硬式加油桁架：

| 加油系统 | 正式配置 |
| --- | --- |
| 左翼下加油吊舱 | **1套** |
| 右翼下加油吊舱 | **1套** |
| 机腹后段加油吊舱 | **1套** |
| 最大同时受油机 | **3架** |
| 单路标称输油流量 | **约1,200～2,000kg/min** |
| 中央泵站总流量上限 | **约4,200kg/min** |
| 输油来源 | 机翼／机身综合燃油箱，通过泵站分配 |
| 任务辅助 | 摄像监控、夜间灯光标记、压力与流量监控 |
| 安全设备 | 异常输油切断、软管紧急脱离、供油系统隔离 |

三架受油机可同时接受燃油，**但三路不能不受限制地同时达到各自2,000kg/min上限**；全机总输出仍受约4,200kg/min泵站能力限制。实际受油速度还受受油机油箱余量、供油条件与飞行状态影响。

为适应不同受油机，G-7H的三路加油装置可以分别调节输油工作状态，但不因此兼容未装软管—锥套受油接口的普通飞机。

## 空猎与和声的正式受油兼容性

| 受补给机 | 空中加油 | 空中武器模块补给 | 兼容性说明 |
| --- | --- | --- | --- |
| [空猎-92A]({{ '/articles/article-369/' | relative_url }}) | **支持** | **支持** | 具备与G-7H兼容的可收放式受油接口及专用武器模块受弹接口 |
| [空猎-92B]({{ '/articles/article-369/' | relative_url }}) | **支持** | **支持** | 与A型共享接口标准，机载AI与飞行员协同进行补给 |
| [和声-1M]({{ '/articles/article-382/' | relative_url }}) | **支持** | **不属于标准对象** | 设有与软管—锥套兼容的可收放受油接口；不具备G-7H武器转运架 |

空猎-92A/B的受油与受弹接口为正式机型适配能力，**不是“理论上可以改装”**；但其能够空中补弹仅限已经认证的标准武器模块，并不意味着五种导弹在任意配装、任意弹舱状态下都能被逐枚空中装填。大型特种弹药若无对应模块认证，不能仅因空猎可挂载就自动认定可由G-7H空中转载。

和声-1M最大燃油装载量仍按其自身既定的**约6.8吨**计算，G-7H不能使其油箱容量突破机体设计上限。受油后可增加任务时间，但仍受乘员工作时长与电子设备维护状态约束。

## 机背内埋式武器模块补给舱

| 项目 | 正式参数 |
| --- | --- |
| 弹舱位置 | 机背中后段，与尾部大型货门相互分离 |
| 结构 | **独立内埋式补给舱**，避开机翼主要承力部位 |
| 有效内部尺寸 | **长约12m、宽约3m、深约2.5m** |
| 舱门 | 向上开启的双开式／蚌式舱门 |
| 装载量 | **通常8～10组预装填武器模块** |
| 武器模块最大总质量 | **约18吨** |
| 装载／约束 | 任务模块导轨、机械锁紧与电气状态监控 |
| 舱内安全 | 独立温控、惰性气体抑爆、静电接地、防爆泄压 |
| 转运设备 | **向上伸出的可伸缩转载弹架** |
| 受弹机位置 | G-7H的后上方，使用认证的专用接口 |

武器模块舱是本机**正式量产并投入使用的装备**。弹舱开启、模块外伸和近距离交接均属于严格限定飞行状态的活动，不允许与任一软管加油作业同时进行。机腹油路与机背武器舱分开设计，且不把机背武器舱视为可以在飞行中随意敞开的普通货舱。

### 标准化武器模块

标准模块为可整体装卸的武器挂架／弹舱组合，内部可预先安装**2～4枚中距导弹**，或按认证配置携带若干小直径炸弹。模块统一具有承力挂梁、机械锁止、供电与数据接口。

G-7H实施的是**完整模块交接**，而非在空中逐枚拆装导弹。完成转运后，受弹机仍须完成武器连接状态检查；模块在交接期间保持安全约束。不同模块的外形与重量不能仅凭“8～10组”的总数自动判定兼容。

G-7H与空猎-92A／92B使用兼容的标准化武器模块接口。普通战斗机及不具备对应受弹架的飞机不适用此功能；空猎既定的标准内载导弹容量与G-7H能转移的模块组数是不同指标。

### 实际补弹任务限制

接收武器模块的飞机位于G-7H后上方专用空域，使用自身可收放的受弹接口，与G-7H机背转载机构进行整组转运。全过程由飞行员与任务操作员监督，必要时由受弹机AI辅助保持稳定。

| 项目 | 正式任务指标 |
| --- | --- |
| 每次转运单位 | **1个完整的标准化武器模块** |
| 常规单模块交接任务时间 | **约8～14分钟**，视相对飞行与设备状态 |
| 标准机上模块存量 | **8～10组**，不等于一次任务必然全部转运 |
| 风险限制 | 尾流、相对运动、碰撞、静电与武器安全 |
| 操作条件 | 需符合稳定气象与已认证补给包线，夜间和复杂气象显著受限 |
| 任务切换 | **先结束加油并回收软管，再开始武器模块补给** |

G-7H具备成熟的常规服役保障能力，不代表所有天气、所有武器模块或所有受弹机可以无条件执行空中转载；任务必须符合已形成的型号认证条件。

## 四种正式任务模式

| 模式 | 名称 | 主要用途 |
| --- | --- | --- |
| **A** | 纯加油 | 最多约80吨可转移燃油；可按流量上限服务最多3架受油机 |
| **B** | 综合补给 | 约60吨可转移燃油＋12吨武器模块；**先加油，完成系统切换后再补弹** |
| **C** | 武器模块补给 | 8～10组模块、16～18吨任务武器载荷，基本不输出燃油 |
| **D** | 应急运输 | 地面拆除可拆模块架并调整货舱，运输应急物资与任务装备 |

模式与燃油／载荷选择不是四套不同机体。G-7H可以根据任务在地面更换、调整模块，但不能在飞行过程中任意增加燃油或武器存量。

任务控制允许常规自动化监测、飞控辅助和安全联锁，但**不将加油／武器转运权限交给无监督的全自主AI指挥**。各任务席位共同进行补给，驾驶舱飞行员仍保有飞机本身的安全操纵职责。

## 后方部署与航空安全

G-7H**不配备战术自卫系统**：无雷达告警、无导弹逼近告警、无电子干扰机、无干扰弹发射器，也不装自卫空空武器、预警雷达或专用电子战侦察设备。飞机保留的气象雷达、TCAS、卫星通信、数据链、照明与对接摄像头属于飞行和补给保障用途，并不等同战场自卫设备。

它主要依靠防区外工作、友方战斗机护航、空域预警和后方指挥保障生存。强威胁空域、严重气象条件与不具备足够地面保障的机场均不适合常规重型补给任务。
