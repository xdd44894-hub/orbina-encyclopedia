**洪水-7**是[寰宇重工]({{ '/articles/article-009/' | relative_url }})生产的**重型战术轰炸机**，以**28吨最大载弹量、同级低价和高产量**为主要市场定位。它不追求隐身、高速突防、复杂电子战或无人自主作战，而是以相对成熟的动力与机体技术、有人机组和大批量标准化生产降低采购与维修成本。

洪水-7最具识别度的设计是**循环导轨式弹药挂载系统**：大部分弹药储存在机内分区弹仓，沿机内导轨输送至机腹及靠近机身的挂点，已经完成投放的挂点可以在符合任务条件时重新获得下一组弹药。它是**机内供弹、机外复用挂架**的机械挂载体系，不是利用导轨加速发射弹药的轨道炮。

洪水-7的**最大载弹量为28吨**，低价基本型的**最低销售价约1.17亿Ɓ**。相对于价格可达14亿～36亿Ɓ的主流高端重型轰炸机，它以低成本、数量和火力载荷争取市场。洪水-7本身速度较慢、目标体积较大且缺乏战术自卫能力，正常作战需要友方战斗机护航；规模化投入使用时也可能承受较高损失。

## 洪水系列型号关系

洪水系列发展出三种明确分工的正式型号：**洪水-7保持低价大载弹量的基础市场路线，洪水-7P（Plus）与洪水-8则不再以低价为主要目标，而是在原有制造与导轨挂载技术基础上进入中高端及高端重型轰炸机领域。**

| 型号 | 产品路线 | 动力与机体关系 | 最大载弹量 | 军购参考 |
| --- | --- | --- | ---: | ---: |
| **洪水-7（基础型）** | 成熟、低成本、大批量 | 四发涡桨，原始系列机体 | **28吨** | 常见构型**1.29亿Ɓ**；最低**1.17亿Ɓ** |
| **[洪水-7P（Plus）]({{ '/articles/article-385/' | relative_url }})** | **高端深度改进型** | 沿用并强化洪水-7的总体布局与涡桨动力技术 | **32吨** | **6.8亿Ɓ** |
| **[洪水-8]({{ '/articles/article-386/' | relative_url }})** | **高端远程衍生型** | 保留洪水系列循环导轨理念，重新设计更大的四发涡扇机体 | **42吨** | **17.8亿Ɓ** |

三种型号均使用**机内储弹、导轨输送、机外挂点循环复用**的基本原理，但**导轨数量、挂点承重、弹舱规模、自动化程度以及电子设备并不相同**。洪水-7P和洪水-8增加的成本换取更好的动力、航电、防护和任务能力，**不会追溯改变原洪水-7的低价定位及其既有性能**。

## 循环导轨式弹药挂载系统

洪水-7使用**固定机内导轨储弹网络＋可重复接收弹药的外部挂点**，代替大量传统的独立一次性外挂弹位。机内的分区储弹位负责安全固定弹药，内部输送路径将兼容弹药转交给已经空出的外部挂点。挂点本身仍通过普通武器挂载／释放装置完成投放，**导轨只负责运输和重复装载，不负责弹药飞行推进**。

### 标准挂架与弹仓容量

| 项目 | 正式指标 |
| --- | --- |
| 主导轨挂点 | **4组**，位于机腹主要承力区域 |
| 辅助导轨挂点 | **2组**，位于机身下部近中央区域 |
| 全机可重复使用挂点 | **6组** |
| 单个主挂点允许弹药质量 | **最多约2.5吨** |
| 单个辅助挂点允许弹药质量 | **最多约1.0吨** |
| 机外挂点同时挂弹质量上限 | **约12吨**，仅为全部挂点质量上限之和 |
| 内部储弹空间设计上限 | **约22吨**，随弹药体积与兼容储弹架变化 |
| 全机机内外弹药合计 | **不得超过28吨** |
| 机内输送通道 | 主挂点和辅助挂点分区供弹，不要求所有轨道直接通至翼尖 |
| 地面装填 | 通过专用地勤装载设备将弹药入仓并校验库存 |
| 飞行中复装 | 仅从本机既有储弹区向空出的兼容挂点转送 |
| 供弹管理 | 机组监督、位置和载荷状态反馈、故障隔离 |

**22吨机内空间容量、12吨机外挂点容量和28吨全机载弹量是三个不同限制**，不是可以相加到34吨的额外载荷。典型满载弹任务可以采用**机内18吨＋机外挂点10吨＝28吨**，也可以在满足机体重心和弹药体积要求的前提下改变分配。

### 可循环挂载的工作特征

- 机外挂点完成一次投放后，不必因此永久闲置：在飞行状态允许的情况下，可以从本机内部储弹位再次接收兼容弹药。
- 机内和机外采用统一的载荷清单；武器操作席负责授权，导轨供弹操作席负责系统状态和可用挂点管理。
- 主挂点与辅助挂点承担不同质量级别的弹药，**较重弹药不自动兼容辅助挂点**。
- 导轨复装期间存在短暂的挂点不可用状态；系统不能把正在移动的弹药同时算作机内库存和机外挂弹。
- 单一路径出现卡滞或传感故障时，允许**隔离该路径，其他经确认正常的挂点继续工作**。不能保证故障后的所有弹药都能任意跨轨改送。

### 标准型循环工作性能

| 项目 | 设定指标 |
| --- | --- |
| 主挂点再次形成可用挂载的名义周期 | **约35～55秒／次**，弹药位于可输送的就绪储弹位且系统正常 |
| 辅助挂点再次形成可用挂载的名义周期 | **约20～35秒／次**，限兼容轻型弹药 |
| 挂点投入下一次使用的状态确认 | 包含在上述名义周期内 |
| 多挂点协同 | 由中央供弹管理器避免不同导轨路径争用，实际时间随库存位置和任务变化 |
| 循环动作正常完成率 | **约97%／次**，指标准维护条件下的机构工作统计，不等于命中率 |
| 机组人工状态确认 | **必须保留**，武器投放本身仍须单独授权 |
| 自动化边界 | 可以自动搬运、监控与隔离故障，**不能独立决定打击目标或自行发射** |

这些周期是洪水-7**虚构世界观内的标准机型能力值**，不是在所有气象、过载、弹种与故障状态下的必达保证。较大的非标准弹药、转轨受阻或者库位不合适时可能延长时间或禁止循环复装。循环挂点提高的是同一个位置的重复利用率，**并不增加全机28吨弹药总量**。

## AiF标准航空炸弹家族

寰宇的[**AiF航空一体化弹药家族**]({{ '/articles/article-398/' | relative_url }})采用**100／250／500／1000／2000／5000磅级**重量分类，并按G通用、P侵彻、F破片、T温压、S特种、C布撒任务型区分；可按需要选用K1惯卫、L2半主动激光、M3多模或W4滑翔增程套件。

洪水-7可将完成机械、质量与接口适配的AiF弹药纳入既有循环导轨体系，**不因此改变28吨全机弹药上限、2.5吨主挂点和1.0吨辅助挂点限制**。加装套件后的实际组合重量须计入全机载荷，特定重量级并非自动兼容所有挂点。

## 弹药适配及挂载限制

洪水-7主要搭载符合该型导轨挂架重量、空间和投放接口条件的**常规航空炸弹、部分制导炸弹及适配的大型对地弹药**。为维持低成本优势，标准机型不以兼容全部高技术导弹、全部特殊载荷为目标。

| 载荷类别 | 正式使用原则 |
| --- | --- |
| 中小型常规航空炸弹 | 主挂点及符合质量条件的辅助挂点均可采用标准兼容构型 |
| 制导航空炸弹 | 需要兼容供电、数据与投放授权接口 |
| 大型对地弹药 | 优先使用主挂点，且必须满足单点2.5吨上限 |
| 非标准弹药 | 未完成接口适配的不能直接进入循环轨道系统 |
| 外部挂点重复使用 | 只对完成一次投放后重新形成可用状态的挂点生效 |

洪水-7的机内供弹轨道与[G-7H重型多用途空中补给机]({{ '/articles/article-383/' | relative_url }})的飞机之间武器模块转载系统**是不同装备**：前者在一架飞机内部为**自己的挂点复装**，后者为**另一架适配飞机提供整组模块**。两者不能只因都称为“导轨”就认定弹药模块直接互换。

| 项目 | 正式配置 |

| 机载雷达 | 常规导航／气象用途，不采用大型空中预警雷达 |
| 任务计算设备 | 装载清单、基本目标数据管理与挂点状态显示 |
| 机载光电设备 | 具备基础昼夜观察和任务确认能力，性能随构型不同 |

洪水-7不将昂贵的复杂智能化、定向隐身或全自动空战能力作为低成本基本型的标准配置。机上具备正常航行、天气规避、避碰与运输机级安全保障设备，不因此获得电子战自卫能力。

## 自卫能力与运用方式

洪水-7**没有自身战术自卫能力**：不装自卫空空导弹、机炮、雷达告警自卫装置、导弹逼近告警、战术电子干扰机或干扰弹发射器；也不具备隐身突防能力。它需要依靠外部空情预警、友军战斗机护航、任务航路规划及较低威胁的空域来执行轰炸任务。

其速度低、尺寸大，遇到现代防空系统时风险较高。洪水-7采购方通常利用**大量采购、标准化维护与可接受的低单价**获得持续投送能力，不能因为拥有28吨载弹量就把它描述成能够单机压倒高防护体系的超级轰炸机。

它可以和寰宇重工的[空猎-92系列]({{ '/articles/article-369/' | relative_url }})协同承担护航与任务支援，但并不因此成为现有[空猎—和声—G-7H三机种联合编队]({{ '/articles/article-383/' | relative_url }})的固定第四机型；具体搭配按任务另定。

洪水-7的主设计目标是**大载弹量、可循环挂点与低价大批量部署**，并以速度、防护、电子设备等级和自卫能力上的明显弱点作为代价。
