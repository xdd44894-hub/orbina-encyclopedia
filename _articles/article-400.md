**枭1式**是[寰宇重工]({{ '/articles/article-009/' | relative_url }})航空与无人飞行系统产品线中的**高端远程隐身战略轰炸机**，采用大型无尾飞翼布局和四台自适应循环发动机。它以**低可探测突防、远距离打击、多机传感协同、复杂电子战与可选择的战略载荷**为主要任务，与寰宇的[洪水-7]({{ '/articles/article-384/' | relative_url }})、[洪水-7P]({{ '/articles/article-385/' | relative_url }})、[洪水-8]({{ '/articles/article-386/' | relative_url }})并非简单替代关系。洪水系列依赖机内供弹、循环外挂点及较高持续火力；枭1式则为了保持隐身构型，优先采用**全内置弹舱**。

该系列包含以**两名人类机组**为标准的**枭1式**和专门取消常驻乘员的[**枭1B式无人型**]({{ '/articles/article-401/' | relative_url }})。A／B在下文中仅用于区分基础有人构型与专用无人衍生型；**“枭1式”仍为有人基型的正式名称，不擅自将它改称“枭1A式”**。

## 定位与现有轰炸机产品线

| 项目 | 枭1式 |
| --- | --- |
| 研发／制造 | **寰宇重工** |
| 类型 | **高端远程隐身战略轰炸机** |
| 基础构型 | **双人有人驾驶**，保留机载AI辅助与飞控自动化 |
| 专用无人衍生型 | [枭1B式]({{ '/articles/article-401/' | relative_url }}) |
| 设计任务 | 高隐蔽突防、战略威慑、远程精确打击、无人机协同和电子支援 |
| 技术路线 | 大型飞翼、全内置武器、宽频低可探测材料、四发自适应循环发动机 |
| 主要比较 | 洪水-8的最大载弹量**42t**；枭1式以隐身任务能力换取较低弹舱容量 |

## 机体、结构和乘员

| 项目 | 正式系列基型参数 |
| --- | --- |
| 机体布局 | **无尾飞翼**；翼身高度融合，无垂尾、平尾 |
| 前缘 | 单后掠前缘，内翼段尖化及曲率修形 |
| 后缘 | 锯齿化多操纵面后缘 |
| 飞控控制 | 升降副翼、分裂式偏航操纵面和冗余数字飞控 |
| **翼展** | **约52m** |
| **机长** | **约27.5m**，为容纳纵向主弹舱和核心设备的修订尺寸 |
| 机高 | **约5.8m** |
| 机翼面积 | **约410m²** |
| **基本空机质量** | **约96t**；含固定航电、基础自卫系统和基本舱体设备 |
| **最大起飞重量** | **约200t**，属于原180～200t级上限 |
| **最大内油质量** | **约78t**，与最大武器载荷需按任务分配 |
| 常规内置弹药质量 | **约22～25t** |
| **特种重载弹药上限** | **约30t**，限特种弹舱认证构型，需相应减少燃油或其他设备 |
| **标准乘员** | **2名人类**：1名飞行员、1名武器系统官；AI负责辅助武器分配和态势分析 |
| 驾驶模式 | 有人驾驶为标准；可依认证采用遥控／无人在机状态的有限任务或转场，**不等同专用无人B型** |
| 机体设计寿命 | **约28,000飞行小时**；设计服役年限参考**约30年** |

“AI辅助武器系统官”在有人型中指**武器系统官使用AI辅助系统**，不是把一台AI当作第二名人类乘员；两名乘员的实际工作包括驾驶、任务监督、武器授权和系统管理。

无尾机体需要依赖冗余数字飞控维持稳定，不因取消尾翼就自动具有特殊超机动能力。其复合材料中央承力结构与局部金属承力框架兼顾大翼展机身、弹舱载荷及长期服役要求。

## 发动机与飞行表现

| 项目 | 正式参考指标 |
| --- | --- |
| 动力 | **4台三涵道自适应循环发动机（ACE）** |
| 单发最大推力 | **约18～20吨力** |
| 全机最大推力 | **约72～80吨力** |
| **发动机自身推重比** | **约15～18**，不是整机推重比 |
| 满200t起飞重量时整机推重比 | **约0.36～0.40**，按单发最大推力估算 |
| 最大平飞速度 | **约Ma 0.90**，高亚声速 |
| 经济巡航速度 | **约Ma 0.68～0.76** |
| 高速巡航速度 | **约Ma 0.82～0.87** |
| 超声速巡航 | **无** |
| 实用升限 | **约15,000～18,000m**，高端值对应有利轻载状态 |
| **轻载内油转场航程** | **约12,000～14,000km** |
| **一次空中加油后总航路航程** | **约18,000km级**，不是在14,000km基础上再增加18,000km |
| 常规弹载任务参考往返作战半径 | **约3,800～4,800km**，按航路、在空时间及余油条件变化 |
| 典型起飞跑道需求 | **约2,700～3,300m**，与起飞重量及机场环境相关 |
| ACE经济性效果 | 在指定同代固定循环动力基准下燃油效率提升**约25%**，有利工况下可带来**约25%～30%**航程收益 |

上表的最大速度、最高升限、最大内油转场航程和重载投弹能力属于**不同任务工况**，不能全部叠加为一次出动的性能。

### 质量与燃油平衡示例

| 工况 | 空机 | 人员与随行保障 | 弹药及专用组件 | 燃油 | 起飞质量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 轻载远程 | 96t | 1t | 8t | 78t | **183t** |
| 标准轰炸 | 96t | 1t | 24t | 75t | **196t** |
| 双13.6t特种钻地弹 | 96t | 1t | **28.6t**（27.2t弹体＋1.4t专用组件） | 72t | **197.6t** |

这解决了原始草案中**两枚13.6t武器合计27.2t，超过22～25t常规载弹量**的问题：该组合专门归入经过结构验证的**约30t特种重载构型**，不是把全机一般载弹量扩大为任意30t弹药。特种大弹是否真正装入弹舱还须满足舱门开口、外形、固定点及重心限制。

## 低可探测能力

| 项目 | 构型和判定范围 |
| --- | --- |
| **优化正前方RCS** | **-40dBsm量级**，即约**0.0001m²**；限指定频段、洁净构型和有利入射角 |
| 多方位隐身 | 以比旧地球B-2级参考目标进一步减小散射为设计目标；**不将“全向低一个数量级”当成任意频段和任何方向的实测常数** |
| 蒙皮 | 宽频吸波／透波复合材料；局部按传感器功能分区 |
| 外形细节 | 锯齿化口盖与舱门、埋入式传感器窗口 |
| 进气道 | S形遮蔽进气通道 |
| 排气与红外抑制 | 机身上表面及尾喷口上缘遮蔽、冷气流掺混，降低中长波红外暴露 |
| 武器部署 | 尽量保持弹舱关闭，以全内置构型维持低可探测状态 |
| 发射与传输 | 主动AESA工作、对外数据链、高热动力或弹舱开启时均可能增加被探测风险 |

“隐身”在俄庇娜并不是绝对不可见；红外、多站雷达、电子侦察和综合监视仍可能发现或跟踪飞机。

## 内置弹舱与武器适配

| 项目 | 正式参数和边界 |
| --- | --- |
| 弹舱总体布局 | **前后双主弹舱＋两个翼根辅助舱** |
| 单座主弹舱纵向空间 | **约9～10m级**，不代表该长度的任何弹体均可装入 |
| 常规弹药上限 | **约22～25t内置武器总质量** |
| 特殊弹药配置上限 | **约30t**，包括专用固定组件并满足200t全机重量限制 |
| 空射高超声速导弹 | **通常4枚；最多6枚**需专用尺寸、质量和布局认证 |
| 该类导弹自身参考射程 | **约1,500～2,000km级**；不是轰炸机飞行航程 |
| 隐身巡航导弹 | **常规24枚；最多32枚**限紧凑弹型和合适挂架构型 |
| 重型钻地弹 | **2枚13.6t级**，属专用重载弹舱任务 |
| 核常兼容 | 内置旋转挂架可按任务认证搭载常规／核航弹或相应巡航导弹 |
| 标准化航空炸弹 | 可使用符合尺寸、重量、信息接口和任务认证的[**AiF弹药家族**]({{ '/articles/article-398/' | relative_url }}) |
| 常规外挂方案 | 不作为保留隐身性能的标准任务构型 |

高超声速导弹、巡航导弹、双重型钻地弹和核载荷属于**分别选择的任务构型**，不是所有上限可同时装载。13.6t级重型钻地弹**不是**[AiF-5000]({{ '/articles/article-398/' | relative_url }})（5000磅级），两者应当分开。

核武器的携带能力与**具体释放授权**分属不同环节：不得因为装有AI、远程数据链或无人飞行功能，就认定机载AI具备独立决定核武器使用的权力。

## 航电、AI与无人机协同

枭1式采用**多阵列AESA、被动电子支援、嵌入式光电／红外观察、惯性与卫星融合导航和机载任务计算系统**。AESA可以按构型承担探测、电子支援相关任务和有条件的电子攻击；后者与高度隐身状态之间存在暴露取舍。

- **AI辅助武器分配**：提供方案、环境评估、航路及武器状态建议，按授权由人类乘员确认重大打击行为。
- **电磁频谱管理**：综合分析干扰和发射风险，并提示可能影响本机被动隐身的通信状态。
- **传感器融合**：将本机与经数据链连接的友方平台信息融合，不意味着传感器永不丢失目标。
- **CCA协同**：可同时任务级协调**约4～8架协同作战无人机**，承担侦察前锋、电子战节点、诱饵与外部分布式载弹任务；这些无人机上的弹药**不计入枭1式机内22～30t载荷**。
- **指挥边界**：协同数量指任务分配与数据管理能力，不意味着两名机组逐架全程手动驾驶；复杂电磁干扰、链路受限时可控制数量或能力下降。

## 自卫系统

| 组件 | 正式参考构型 |
| --- | --- |
| 基本定向能自卫设备 | **2座低外形转塔**；部分任务型可有第3座 |
| 每座额定输出等级 | **约100～300kW** |
| 每座转塔自身质量 | **不超过400kg**，不含共用供电、储能、散热及全机管路系统 |
| 典型作用 | 在具备跟踪与视线条件时，短距离干扰或损伤来袭弹药的外露光电／红外导引部件 |
| 持续工作限制 | 高功率输出、热管理和暴露窗口受供能／散热限制 |
| 常规反制 | 热焰弹、箔条、拖曳诱饵及软杀伤电子对抗 |
| 总体防御思路 | **隐身回避探测＋电子软杀伤＋有限定向能自卫** |

这类机载定向能转塔不是超大型舰载反装甲激光炮，不能声称必定摧毁各种高速导弹，也不能凭空生成可持久防弹的“能量盾”。俄庇娜[能量武器与等离子体能量盾]({{ '/articles/article-399/' | relative_url }})对激光及高速动能弹的作用边界仍然成立。

| 成熟期年交付能力 | **约18～30架／年**，指形成成熟供应链后的参考规划能力，**不等于既有实际年产量** |
| 主要保障设施 | 大型隐身维护机库、复合材料蒙皮与低可探测校验、专用重弹装填、任务数据与自适应动力维护 |
| 主要成本驱动 | 飞翼制造一致性、低可探测维修、三涵道动力、传感器系统、机载AI与定向能热管理 |

这些采购和产能数字描述**设计与工业能力口径**，不自动证明该型号已按成熟期速度批量交付。机体设计使用寿命、单次任务航程与军购成本是三个不同指标。

## 与无人型及洪水系列的关系

[枭1B式无人型]({{ '/articles/article-401/' | relative_url }})以枭1式的飞翼气动、隐身材料、发动机与内置弹舱体系为基础，**取消常驻人类机组并重构任务控制、飞控冗余和数据链**。两型基本平台近似，但无人型不是把有人型驾驶舱简单换成AI软件。

[洪水系列]({{ '/articles/article-384/' | relative_url }})更重视较低价格下的大规模常规弹药投送，枭1式专注高风险复杂空域中的隐身任务；**枭1式22～25t的常规内置载弹量不应被写成高于洪水-8的42t总载弹上限**。
