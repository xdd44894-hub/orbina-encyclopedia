**萨德林标准单兵三日套餐**是[萨德林共产乌托邦共和国]({{ '/articles/article-008/' | relative_url }})的**标准型一人三日份单兵食品配给**，与[《萨德林高寒单兵三日套餐》]({{ '/articles/article-406/' | relative_url }})构成**不同类型的套餐**，不能把两者的清单、燃料块规格、重量或价格混用。标准型以**多种现成餐食、蔬菜配菜、糕点、浓缩果浆饼干和独立调味包**组成三日食品供给；没有在本条所列清单中配发高寒版的牛舌、鹅肝酱、伏特加或高脂高能食品组合。

本条目按照正式给定清单记录：**三日食品净重2,934g、总热量约9,070kcal，平均约3,023kcal／日**；拆除运输外包装后，连同部分必要附件与随身包装的携行重量**估计约3,399g（约3.4kg）**；完整装箱状态**约5.5kg**。除食品重量、数量和能量标签外，包装总重属于估算口径，不可将“整箱5.5kg”与“拆箱3.4kg”互相替代。

## 箱体、重量和携行方式

| 指标 | 正式设定及统计口径 |
| --- | --- |
| 份数 | **1人3日** |
| 标称箱体容量 | **20L** |
| 给定外箱尺寸 | **40×30×20cm** |
| 按给定尺寸计算的外部几何包络容积 | **24L**（40×30×20＝24,000cm³） |
| 完整运输箱重量 | **约5.5kg** |
| 拆箱后食品与所携附件、内包装重量 | **约3,399g（约3.4kg）** |
| 三日突击包的装填方式 | **先拆开完整箱装包装，再把各包、各罐与附件逐件取出装进背包** |

**20L与24L并列的口径：** **20L**为给定的**箱体标称容量**；**40×30×20cm**的外廓几何容积按数学计算是**24L**，不能写作20L。此前**高寒版**已明确存在24L外箱与20L内箱的双层设计，**但标准版尚未单独确认同样的“箱中箱”、具体泡沫层或防火防水标准**，不因两者尺寸相似便擅自照搬高寒版的包装工艺。

**5.5kg与3.4kg并列的口径：** 食品净重2,934g＋随行非食用附件215g＋预计随行包装250g＝**3,399g**。若完整运输箱重约5,500g，那么拆箱时去掉的**外箱、保护材料、运输分隔等不再携行的部分差额约为2,101g**。这属于由两个重量目标反推的**需要由外部包装承担的质量差额**，**不是已经对外箱及衬垫逐项称量得到的数据**。如果将来外包装材料无法达到约2.1kg，须重新调整运输箱重量或随行重量的标称口径，不能强行令所有参数同时精确成立。

## 与高寒版的共用食品规格

[《萨德林高寒单兵三日套餐》]({{ '/articles/article-406/' | relative_url }})和本标准型中的**同款食品采用同一单位规格与营养口径**，不能因为两款军粮定位不同而让相同食品出现不同的热量。

| 共用食品 | 两版统一的基础规格 | 标准型装箱 | 高寒型装箱 |
| --- | --- | --- | --- |
| **浓缩果浆饼干** | 每包**100g、3块、约600kcal**，苹果、橙子、蓝莓各1包 | **300g、约1,800kcal** | **300g、约1,800kcal** |
| **巧克力** | 每包**100g、约550kcal** | **100g、约550kcal** | **200g、约1,100kcal** |
| **速溶咖啡** | 每包**9g、约40kcal**（现行军粮标签口径） | **27g、约120kcal** | **27g、约120kcal** |
| **白糖** | **约4kcal／g** | **3包×5g＝15g、约60kcal** | **3包×10g＝30g、约120kcal** |
| **食用植物油** | **约9kcal／g**，按实际密度折算毫升 | **3袋×10g＝30g、约270kcal** | **80mL、约650kcal** |

**同款不等于同样装箱数量。** 两套产品的巧克力份数、糖包规格、食用油装量各有不同；这里统一的是**单件单位净重和相应热量密度**。**9g咖啡标称约40kcal**及**100g果浆饼干约600kcal**为用户已指定、两版共同采用的军粮食品热量数据，实际配方需匹配这样的热量密度，不能擅自把咖啡写成无添加纯黑咖啡，也不能用普通低脂果酱饼干的热量替换。巧克力的少数赶工批次可能出现苦甜分布不均，但这**不是两版常规配方不同**。

## 浓缩果浆饼干的乳化浓缩配方

**标准型和高寒型的苹果、橙子、蓝莓三味果浆饼干采用相同的“高糖高脂乳化浓缩果酱”馅料。** 每种口味的制备配方以**100质量份原始果浆**为基准，而非100g成品：

| 要素 | 正式设定 |
| --- | --- |
| 糖体系 | 成品目标**68～70°Brix**；果葡糖浆占糖组分的**50%～60%**，其余为白砂糖 |
| 油脂 | 相对于100份果浆加入**10～12份氢化椰子油** |
| 乳化剂 | **0.4份单双甘油脂肪酸酯** |
| 稳定剂 | **0.1～0.2份黄原胶** |
| 酸度 | 成品**pH 3.6～3.8**，柠檬酸添加量偏低 |
| 浓缩 | 真空浓缩至**68～70°Brix** |
| 乳化 | **65℃均质**，形成细油脂乳液 |
| 后处理 | **快速冷却后灌装** |

**口味机制：** 浓缩果浆和果葡糖浆中的果糖强化入口甜味，较少柠檬酸让酸味不易抵消甜感；黄原胶增强黏稠度，乳化椰子油增加厚重口感。这能够解释士兵所说的**“Слишком приторно！”——“甜得发腻！”**，不需假定所有批次生产失误。

**统计说明：** °Brix是**可溶性固形物指标**，**不等于成品的添加糖百分比**。对于乳化油脂食品，测量前须确定水相取样与折光校正口径；果葡糖浆的50%～60%占比还需要确认按糖固形物还是糖浆供货质量计算，因此不擅自虚构糖的实际加入克数。**65℃均质及快速冷却不单独构成货架期或微生物安全认证**，具体杀菌、包装与保质期验证未确定。

此方案确定的是**馅料而非整块饼干**：每包仍为**100g、3块、约600kcal**，三味共**300g、约1,800kcal**。新增的**10～12份椰子油**有助于提高能量密度，但无法仅据此证明**整块饼干600kcal／100g**；还需明确饼干基体油脂、馅料占比及最终营养标签。氢化椰子油的具体氢化程度与反式脂肪含量尚未设定。

## 浓缩果浆饼干：糖分疑虑与士兵口味评价

本标准型中的**苹果、橙子、蓝莓浓缩果浆饼干**与[高寒版]({{ '/articles/article-406/' | relative_url }})**使用同款产品**，每包**100g、3块、约600kcal**，三包共**300g、约1,800kcal**。其中的**果浆经过浓缩处理**，形成非常明显的甜味，部分士兵食用后觉得**甜腻感过重**。

**不少士兵会直接抱怨：“Слишком приторно！”——“甜得发腻！”** 对于糖分，有士兵**怀疑浓缩果浆饼干可能放糖过多、甚至疑似超标**；但这是**口味反馈与未经验证的怀疑**，并非已经正式确认的食品检验违规、实际检测结果或全军普遍投诉比例。**果浆的总糖含量、额外添加糖数量、实际监管限值尚未设定**，因此不能将这些猜测升级为确定事实。

**甜得发腻不等于全部热量来自糖。** 普通糖约4kcal／g，即使100g全是糖也只能提供约400kcal。**目前已经明确乳化浓缩果酱使用氢化椰子油**，但要解释整块饼干**600kcal／100g**还需要其基体和馅料比例的完整核算。果浆饼干的**整体甜腻感**与高寒版记载的**个别巧克力批次混合不均、同一块局部甜苦不一**属于不同问题。

## 重量与热量的复核

| 分类 | 正式合计 |
| --- | ---: |
| **全部食用物资净重**（主食、罐头、饮品粉和调味料） | **2,934g** |
| **三日食品总能量** | **约9,070kcal** |
| **三日平均能量** | **约3,023kcal／天** |
| **非食用附件质量** | **215g** |
| **随行包装袋／罐体等硬盒估算质量** | **约250g** |
| **拆箱携行总重量** | **2,934＋215＋250＝3,399g（约3.4kg）** |
| **完整运输箱参考重量** | **约5,500g** |
| **运输箱相对拆箱携行质量的差额** | **约2,101g（5,500－3,399）** |

**上述食品净重2,934g与能量9,070kcal可由逐项清单精确相加复核，热量数值本身均为约数。** 军需包装与真实罐体金属质量没有经过逐件称重，因此215g附件是直接按给定参数相加，250g随行包装和5.5kg整箱重分别为设定估算值。

**能量密度注意：** 与高寒版共享的果浆饼干**300g含约1,800kcal（约600kcal／100g）**，四种**200g米饭／面条包各约900kcal（约450kcal／100g）**，能量密度都明显偏高。以用户明确标注的**套餐热量**为准，不擅自修改；但产品形态究竟采用脱水、浓缩、高脂配方或其他方式，**尚未给出详细工艺**。不应把上述指标误读为普通含大量水分的熟米饭或常规低脂水果饼干的普遍热量值。

## 与高寒型的区别

[《萨德林高寒单兵三日套餐》]({{ '/articles/article-406/' | relative_url }})偏向高寒与较大体力消耗任务，除了肉类罐头还包含较多油脂、干肉、坚果、奶酪、能量棒等食品；标准型则突出**四种米饭／面条主餐、酸菜、腌黄瓜、香肠、土豆泥、糕点和独立调味组合**。

标准型的**三日热量约9,070kcal、日均3,023kcal**为正式清单的合计；高寒型此前按常见同类食品能量密度估算的**约14,000～18,000kcal**仍只是参考区间，**不是与标准型同等精度的正式标签数值**。标准型完整运输箱**约5.5kg**，高寒型**约6kg**；两种套餐**均须拆箱后逐件装入三日突击包**，但各自的实际随身携行重量须分别计算。

**价格必须分开：** 高寒型现有正式数字为**生产成本约12.8Ɓ、军购15Ɓ、民售33～40Ɓ**；**标准型的生产成本、军购价与民用零售价尚未确定**，不能自动套用高寒型报价。

## 日常使用与供应范围

标准型是一人三日的**独立预包装食品组合**，**不是要求每个士兵每餐只能照固定菜单吃一种指定食品**。是否需要额外饮用水、饭盒、餐具、当地饮食习惯、分配时段和使用地域细节还未分别给出完整规程，**不能把高寒型的取冰烧水制度自动当作标准型的全部使用规则**。但是加热主食及咖啡通常仍需要适当的饮用水和容器，单兵应按任务保证必要的饮水与炊具。

萨德林拥有大型国营食品厂[**Старая кухня（老厨房）**]({{ '/articles/article-408/' | relative_url }})，其供应全国肉类罐头总量的41.1%；**尚未指定该厂为标准型军粮的制造商，也未规定该套餐的合同、出厂成本或售卖价格**。
