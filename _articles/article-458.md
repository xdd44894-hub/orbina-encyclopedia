# CrystalDiamond（晶钻，CD）

**CrystalDiamond**，中文名称**晶钻**，通用简称 **CD**，是一款面向工业与科研领域的**综合三维建模、数字化设计和工程模拟软件平台**。软件本体**完全免费**，采用**部分开源**的开放方式，支持第三方扩展，并倡导跨地域发行与使用。

CD的设计方向是以易于操作、可扩展、可重复利用的工具降低工业创造门槛。它并非能够取代实体试验与工程判断的万能工业设备，而是让从初学者到专业人员都能在统一的可视化环境中完成不同层次的设计工作。

## 品牌识别

- **标志**：以钻石“非洲之心”的形状为灵感，设计为**像素化钻石图案**。
- **主要配色**：蓝、白、黑。
- **动态形式**：LOGO可以旋转；不由此推定固定旋转速度、特效或音效。
- **视觉方向**：精确、理性、数字化，强调易辨识的计算机图形风格。

“**为了世界工业**”体现其创作理念，但不在此将其定为企业法定口号、政治纲领或官方宣传语。

## 使用方式与交互理念

CD重视**直接操作与实时可视化反馈**。使用者可以选取对象、连接部件、调整参数并直接观察变化，常规操作尽量避免繁琐的手动计算提交过程；需要高成本求解的工程仿真仍可以进入更深入的分析流程。

软件支持图形化编辑、可视化工程反馈和多任务工作流。单屏、双屏和三屏工作站均可使用，并不强制要求多显示器。

CD强调**简单易学而非功能简陋**。其基础教程《入门第一课：装修设计》以立方体与房间尺寸为起点，介绍环切、挤出、倒角、门窗、家具资产、材质、灯光、渲染及导出。该课程可供普通学生或专业研究人员学习软件的基础操作。

## 建模与数字化设计

| 功能领域 | 软件能力 |
| --- | --- |
| 网格建模 | 顶点、边、面、N边面操作；挤出、倒角、环切等硬表面建模 |
| 曲线与曲面 | 控制点曲线、曲面和NURBS，支持工业外形设计及与网格衔接 |
| 元球建模 | 借助体积平滑融合形成有机或抽象形状 |
| 雕刻模式 | 推拉、抓取、平滑、刻痕笔刷；支持按需动态拓扑细分 |
| 修改器 | 非破坏式堆栈，包括细分、镜像、阵列、布尔、形变及晶格 |
| 程序化建模 | 脚本控制台、可视化节点、节点组复用和批量自动化 |
| 工业精度工具 | 精确数值变换、单位表达式、数值锁定、网格吸附、公差检查、二维约束草图及参数化更新 |

CD还能够用于**GPU芯片刻线或版图相关几何设计**，但这项能力本身并不等于软件已经内置完整的半导体设计、工艺验证、流片认证或晶圆制造流程。

## 工程物理模拟与风险反馈

CD可以让使用者在三维视口中观察机构、罐体、管线等模型在设定工况下的模拟行为，强调“**像操作机器一样操作模型**”的体验。

- **局部受力与失效风险显示**：加载条件发生变化时，相关部位可以逐渐变黄、变红，用于表示模型局部受力或潜在失效风险，而非对整个模拟给出一个颜色分数。
- **失效演示**：例如提高罐体的内部液压时，风险区域会逐渐突出；当模拟达到预测失效条件时，可以展示结构破坏或爆裂的动画并显示失效／错误提示。
- **可信度计算**：一般情形下，模拟可信度不必然达到100%；启用“**理想化**”选项后，**被设定的理想模型内**可信度可以达到100%。这一数值与黄红色受力显示互相独立。

**理想化模型的100%不等于现实工程绝对安全。**模拟可信度、计算有效性以及实际装置风险需要区分；软件可突出危险征兆，但不能自动代替材料试验或工程责任。

## 资产库与官方资源

CD支持把物体、材料、节点组等内容保存为可检索、可拖拽、跨项目复用的资产。工业资源可包含例如**6XXX系铝合金**、**ISO 7380螺丝**等材料或标准件。

**CrystalDiamond官方网站免费提供ISO标准机械零件资产库。**该资源库是官方基础工程素材服务，不是官方插件交易市场。

## 插件及第三方生态

CD的插件为运行时可动态加载的代码模块，可通过开放接口增加工具面板、操作符、菜单、属性、节点流程、自动化、资产管理、仿真及行业专业功能。其适用领域可延伸至机械制造、建筑、汽车、船舶、航空航天、军工、能源和电子设计。

- **插件开发自由**：用户可以自行开发、发布、分享或出售插件，并从中获得商业收益。
- **官方不经营插件交易平台**：第三方插件的交易、上架、侵权投诉及盗版处置不属于CD官方自建商城的运营业务。发生盗卖纠纷时，开发者通过实际交易平台及适用法律维护权益。
- **恶意插件行为**：对于故意制作或传播恶意病毒插件、蓄意破坏用户系统或数据的行为，CD官方可采取法律行动；不能将普通插件不兼容或意外崩溃直接认定为恶意。
- **软件开放性**：CD本体免费、部分开源；第三方专业插件不因此被强制要求免费。

旧资料曾用“**精准变换_82年度版**”“**车刀-3.0**”“**Sketcher**”演示精确操作、机械设计与二维约束草图等插件方向；这些名称目前仅保留为**源稿中的功能示例**，不将“82年度版”解释为俄庇娜纪年，也不预设三个插件已作为对应版本正式发行。

CrystalDiamond作为**开放、易用、跨行业的工程工具**存在于俄庇娜的科研与工业生态中；不意味着全世界所有工程机构只能使用CD，也不意味着建模或模拟能够代替实际制造与物理验证。

该软件的具体研发机构、创立时间、开源模块许可证、硬件商业模式和全部行业认证没有在现行设定中确定，因此不为它附会特定公司、国家、年份或普及率。此前历史穿越假设中的“1982年”、江浙沪工业园区、现代工作站穿越展示和硅谷反应等情节**不属于本软件的俄庇娜正式历史**。
