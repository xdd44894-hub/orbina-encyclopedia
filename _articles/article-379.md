**MO**的正式英文全称为 **Momentum Ordnance**，中文代号名称为**“钢甲武士”**。MO“钢甲武士”是一种针对重装甲主战坦克的**重型动能反坦克导弹**。其特色是依靠重型弹体投送并加速末段动能侵彻体，以高速撞击和侵彻体结构作用于重装甲目标，而非将传统化学能破甲战斗部作为主要杀伤机制。

## 精度、识别、毁伤与可靠性：正式试验指标

下表为俄庇娜世界观中的**MO“钢甲武士”标准型标称测试数据**；测试样本、目标活动方式和防护条件必须明确，不将穿深、落点偏差、任务成功率当作同一个指标。

| 统计项目 | 正式基准值 | 口径 |
| --- | ---: | --- |
| CEP圆概率误差 | **约1.0m** | 正常环境、固定地面靶的末段落点中位半径 |
| 目标正确识别率 | **96%** | 已知目标集、具有正确判定标准的分类测试 |
| 固定装甲目标直接命中率 | **93%** | 标准环境中单枚导弹对有效指派目标的直接命中 |
| 移动主战坦克直接命中率 | **82%** | 标准环境中单枚导弹对有效指派目标的直接命中 |
| 重装甲主战坦克有效毁伤率 | **68%** | 标准测试对象，一枚导弹使目标丧失预定战斗能力 |
| 强电子干扰环境任务成功率 | **59%** | 移动重装甲目标、存在强干扰且不额外叠加主动拦截 |
| 先进主动防护下攻击任务成功率 | **55%** | 指定标准测试的任务完成率，不代表所有APS均为此值 |
| 整弹任务工作可靠性 | **96.5%** | 合格发射后正常完成推进、导航与末段流程；不等于目标毁伤 |

### 数据解释

- **CEP**适用于固定靶落点统计，表示约50%的落点位于所列半径内。对于运动坦克，必须以单独的**移动目标直接命中率**衡量，而非用CEP替代。
- **目标识别率**是分类正确率；不等同于搜索发现率，也不是最终击毁概率。
- **直接命中率**说明是否命中目标；穿深指标只描述标准试验钢靶条件，两者不能互相推导。
- **有效毁伤率**是预定战斗功能失效的统计结果，可能发生命中但未贯穿、贯穿而未彻底失能等情况；并非每次命中必然摧毁车辆。
- **抗干扰环境与主动防护试验**采用各自指定的场景和统计分母；两项百分率不允许被直接当作所有战场条件下的通用结果。
- **任务可靠性**是导弹本体按设计正常工作的比例，不包括目标是否找到、直接命中或产生有效毁伤，因此96.5%不可解释成96.5%的击毁率。

### 空猎-92系列名义挂载能力

[空猎-92A与92B]({{ '/articles/article-369/' | relative_url }})正式兼容MO，但属于相对少见的重型对地弹药。**MO专门配置标准最大内载为2枚（名义弹体总质量3,100kg）**；与SAMW混合的已确认重弹构型为**2枚SAMW加1枚MO**。标准挂载组合参见空猎主条目。MO的弹体长度与直径明显超过常见小型导弹，不将标称18枚导弹容量直接套用于MO。

### G-7H空中模块补弹

MO“钢甲武士”现已拥有[寰宇重工G-7H重型多用途空中补给机]({{ '/articles/article-383/' | relative_url }})配套的正式**MO重弹补给模块**。每组模块预装**1枚MO导弹**，含模块框架的名义质量约**1.80吨**，可在符合机型条件时整组交付[空猎-92A／92B]({{ '/articles/article-369/' | relative_url }})。专用重弹模块在受弹机已稳定进入补给位置后，典型完整交接约**2～3分钟／组**，不包括远程会合、排队及异常重新对接。

这属于已确认的正式空中补弹能力，但**不改变空猎本身2枚MO专用配置上限**，更不能把空猎的18枚常规小型导弹标称容量换算为18枚MO。

### 穿深指标与实际毁伤

MO的**约1,100mm RHA名义穿深**是俄庇娜世界观内针对均质钢试验靶的标准型指标，约1,000～1,200mm为参考试验区间，反映它作为重型动能反坦克弹药的定位。这不是根据Mach 4速度或弹体总质量直接推算出的现实物理定律，也**不是对任意角度、任意复合装甲和任意主动防护系统的必穿承诺**。

这里的RHA表示均质钢试验厚度参考；对于多层复合材料、动态防护和不同防护机理，不能把其名义厚度直接兑换成相同的防护水平。即便实现贯穿，车辆是否立即失去战斗能力仍取决于命中位置、内部隔离和损伤控制等因素，不指定恒定的毁伤概率。

MO的侵彻效应以动能攻击为主，既有设定中的末段开舱／抛射机构、两级或多级推进、信息更新和自卫突防能力保持不变。本条目补全的是**结果性性能和后勤规范**，不规定可供现实制造复现的弹芯具体结构、材料工艺或推进控制配方。

### 补充的保障与可靠性约束

12年为符合规定环境、封存包装及检查制度时的设计存储寿命，24个月为正常条件下的技术检查周期；两项均不能视为故障不会发生的保证。通信中断后可依已有任务数据执行有限自主控制，但目标信息过期或目标变化仍会影响结果。

## 系统构成

| 部分 | 已确认设定 |
| --- | --- |
| 重型弹体 | 为远距离飞行、推进能量和末段动能弹芯提供容积与质量空间 |
| 推进系统 | 两级或多级推进，支持将弹体加速至高速度 |
| 末段机构 | 在末段开启舱段／实施抛射，释放动能侵彻体 |
| 动能弹芯 | 以超音速实施高速动能撞击 |
| 末段制导 | 根据目标信息修正弹道，旨在提高对重装甲目标的攻击有效性 |
| 自卫与突防能力 | 设计上考虑面对主动防护系统时的诱饵、机动及多弹协同／饱和等对抗方式 |

## 作战定位

该弹可由具备相应载荷和接口能力的远程平台投送，在中段持续接收目标更新，末段则以高速动能侵彻体实施反装甲攻击。作为重型平台适用的反装甲弹药，其设计重点是高速末段能量与重装甲目标打击能力，而非同时搜索多个不同类别目标。

MO与[SAMW]({{ '/articles/article-378/' | relative_url }})的定位存在区别：SAMW强调六个子弹药的分布式多目标巡猎；MO集中强调单个重装甲目标的动能侵彻。两者不应混为同一武器系列。

## 效果与未确定参数

MO不依赖传统化学能破甲的基本定位，使其在世界观中的复合装甲与反应装甲对抗方面具有独特价值；但**“超音速”并不自动等于必然击穿任何主战坦克**。实际效果仍受目标防护、命中状态、侵彻体结构和速度等条件影响。

**[空猎-92系列]({{ '/articles/article-369/' | relative_url }})（包括92A与92B）已确认可以挂载和发射MO“钢甲武士”**。不过，相对于标枪-6“刺客”、标枪-8E“长矛”和矛-C77“暴雨”三种常见导弹，MO在空猎上的配置**相对少见**。已确认标准专用内载上限与SAMW混载标准任务构型；具体非标准占位与改装弹舱方案仍需另行核定，不可将空猎系列标称18枚容量直接理解为18枚MO。

MO的标准型尺寸、发射质量、名义高速飞行速度、射程、末段弹芯速度等级和大宗采购参考价已确定；但**具体弹芯材料与结构、真实交战速度、不同装甲体系下的穿甲效果、制导硬件型号、正式制造单位、其他适配发射平台，以及空猎非标准载荷配置下的携弹数量**仍未进一步明确。既有的重装甲打击定位不意味着能够无条件击穿全部坦克。
