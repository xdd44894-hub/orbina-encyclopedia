**MO“钢甲武士”**是一种针对重装甲主战坦克的**重型动能反坦克导弹**。其特色是依靠重型弹体投送并加速末段动能侵彻体，以高速撞击和侵彻体结构作用于重装甲目标，而非将传统化学能破甲战斗部作为主要杀伤机制。

## 正式规格

| 参数 | 标准指标 |
| --- | --- |
| 弹种 | 重型空射动能反坦克导弹 |
| 全弹弹长 | **5.85m** |
| 最大弹径 | **520mm** |
| 全弹发射质量 | **约1,550kg** |
| 母弹典型高速飞行状态 | **Mach 2.3** |
| 有利条件下的最大射程 | **约170km** |
| 末段动能侵彻体速度级别 | **Mach 4级**，不代表固定命中速度 |
| 主要目标 | 重装甲主战坦克 |
| 动力形式 | 两级／多级推进 |
| 末段方式 | 释放独立动能侵彻体实施攻击 |
| 中段信息 | 支持任务更新与目标跟踪 |
| 末段控制 | 弹道修正与目标条件评估 |
| 空猎-92搭载地位 | 正式兼容；相对少见 |
| 大宗采购参考价 | **约280万Ɓ／枚** |
| 标准均质钢穿深参考值 | **约1,100mm RHA** |
| 试验常见穿深区间 | **约1,000～1,200mm RHA**，不同条件下变化 |
| 主要毁伤机理 | 高速动能侵彻、冲击与装甲后次生毁伤 |
| 对主动防护系统 | 具有既定突防设计，但不保证突破 |
| 任务通信中断时 | 继续以已有信息进行有限自主处理，可靠性视情况下降 |
| 标准密封储存寿命 | **12年**，需符合检验与储存要求 |
| 常规技术检查周期 | **24个月**，异常情况提前检查 |

这些为俄庇娜世界观内的**标准型名义参数**。170km是特定有利飞行条件下的最大射程，不是对所有地形、发射条件与运动目标的必达保证；Mach 4级描述末段动能弹芯的名义速度等级，不能代替某次交战中的真实相对撞击速度，更不能直接推出确定的装甲穿透深度。

### 穿深指标与实际毁伤

MO的**约1,100mm RHA名义穿深**是俄庇娜世界观内针对均质钢试验靶的标准型指标，约1,000～1,200mm为参考试验区间，反映它作为重型动能反坦克弹药的定位。这不是根据Mach 4速度或弹体总质量直接推算出的现实物理定律，也**不是对任意角度、任意复合装甲和任意主动防护系统的必穿承诺**。

这里的RHA表示均质钢试验厚度参考；对于多层复合材料、动态防护和不同防护机理，不能把其名义厚度直接兑换成相同的防护水平。即便实现贯穿，车辆是否立即失去战斗能力仍取决于命中位置、内部隔离和损伤控制等因素，不指定恒定的毁伤概率。

MO的侵彻效应以动能攻击为主，既有设定中的末段开舱／抛射机构、两级或多级推进、信息更新和自卫突防能力保持不变。本条目补全的是**结果性性能和后勤规范**，不规定可供现实制造复现的弹芯具体结构、材料工艺或推进控制配方。

### 补充的保障与可靠性约束

12年为符合规定环境、封存包装及检查制度时的设计存储寿命，24个月为正常条件下的技术检查周期；两项均不能视为故障不会发生的保证。通信中断后可依已有任务数据执行有限自主控制，但目标信息过期或目标变化仍会影响结果。

## 系统构成

| 部分 | 已确认设定 |
| --- | --- |
| 重型弹体 | 为远距离飞行、推进能量和末段动能弹芯提供容积与质量空间 |
| 推进系统 | 两级或多级推进，支持将弹体加速至高速度 |
| 末段机构 | 在末段开启舱段／实施抛射，释放动能侵彻体 |
| 动能弹芯 | 以超音速实施高速动能撞击 |
| 末段制导 | 根据目标信息修正弹道，旨在提高对重装甲目标的攻击有效性 |
| 自卫与突防能力 | 设计上考虑面对主动防护系统时的诱饵、机动及多弹协同／饱和等对抗方式 |

## 作战定位

该弹可由具备相应载荷和接口能力的远程平台投送，在中段持续接收目标更新，末段则以高速动能侵彻体实施反装甲攻击。作为重型平台适用的反装甲弹药，其设计重点是高速末段能量与重装甲目标打击能力，而非同时搜索多个不同类别目标。

MO与[SAMW]({{ '/articles/article-378/' | relative_url }})的定位存在区别：SAMW强调六个子弹药的分布式多目标巡猎；MO集中强调单个重装甲目标的动能侵彻。两者不应混为同一武器系列。

## 效果与未确定参数

MO不依赖传统化学能破甲的基本定位，使其在世界观中的复合装甲与反应装甲对抗方面具有独特价值；但**“超音速”并不自动等于必然击穿任何主战坦克**。实际效果仍受目标防护、命中状态、侵彻体结构和速度等条件影响。

**[空猎-92系列]({{ '/articles/article-369/' | relative_url }})（包括92A与92B）已确认可以挂载和发射MO“钢甲武士”**。不过，相对于标枪-6“刺客”、标枪-8E“长矛”和矛-C77“暴雨”三种常见导弹，MO在空猎上的配置**相对少见**。其重型弹体的具体占位与混装数量有待参数明确，不可将空猎系列标称18枚容量直接理解为18枚MO。

MO的标准型尺寸、发射质量、名义高速飞行速度、射程、末段弹芯速度等级和大宗采购参考价已确定；但**具体弹芯材料与结构、真实交战速度、不同装甲体系下的穿甲效果、制导硬件型号、正式制造单位、其他适配发射平台，以及空猎不同载荷配置下的携弹数量**仍未进一步明确。既有的重装甲打击定位不意味着能够无条件击穿全部坦克。
