**新来戈大坝**位于秦棠，是由**秦棠政府、[寰宇重工]({{ '/articles/article-009/' | relative_url }})与深蓝科技**共同参与建设的大型水电、供水及洪水调节工程。全球攻势期间，坝区在[“锋刃”战役]({{ '/articles/article-393/' | relative_url }})中遭到严重破坏，部分战时报道亦称其为**“寰宇大坝”**；两个名称指**同一设施**。

大坝本身并非一方企业能够无限制处置的军用资产。秦棠政府负责公共监管、验收及运营；寰宇负责大型土建、坝体、钢结构、施工机械与运输；深蓝负责发电机组、泄洪调度、监测系统、水文与配套供水专业工程。建坝合作由寰宇重工主席长子推动，秦棠向寰宇提供东北矿业资源优惠开采或供货条件，已确认条件约为相应市场价的**30%**。

| **建设总工期** | **24个月**（前期准备及缓启动4.5个月＋主体施工18个月＋收尾1.5个月） |
| **正式投入使用** | **开工后第三年启用** |
| **建设总成本** | **约1,380亿Ɓ** |
| 主要投资／运营主体 | 秦棠政府主导公共运营，寰宇与深蓝分别承担建设专业合作 |

48km指沿**整个挡水坝线**计算的总长度，不表示48km均为相同断面的高耸混凝土主体；90m为最大坝高，沿线随平原地形和河谷截面变化。**58m为早期设定的坝体厚度**，不能直接用作全部坝段的底宽、顶宽或均匀截面。水域覆盖全国7%耕地指水利调控、灌溉和供水所影响的农业范围，**不是水库淹没全国7%的耕地**。

装机容量是发电设备的额定功率，**不等于全年8760小时都按13.2GW满功率运行**；52TWh属于平均水文条件下的年发电量参考。236亿m³是整个水库容量，**不代表洪灾中全部一次性泄出**。56,000m³/s则是既定泄洪系统设计工作能力，不能与事故时出现的非受控洪峰混为一谈。

## 建设周期与三方工程分工

新来戈大坝的**正式建设总工期为24个月**，分为三个连续阶段：前期准备、场地组织与缓启动试开工**4.5个月**；多施工面并行的主体建设**18个月**；收尾、检查、分段验收与设备联调**1.5个月**。工程在**开工后的第三年启用**。这里的“第三年启用”是投入使用年份，并非“主体施工又持续第三个完整年度”。

该工程按平原长坝线开展多区域建设，部分挡水坝段、发电厂房、泄洪枢纽与运输配套工程可以分区并行实施；**并行施工是24个月能够完成大体量工程的重要前提**。集团重工业生产能力提供了大宗建材、重型装备和物流支撑，但不意味着任何一段工程都能省略正常检查及试运行。

秦棠政府负责监管与运营；寰宇重工负责坝体、施工、钢结构和运输；深蓝科技负责水电设备、泄洪调度、自动安全监测及水文、供水专业工程。秦棠以东北矿业资源约为市场价**30%**的优惠供货或开采权益作为重要合作条件，该矿业产能高于秦棠自身工业的消化能力。

## 工程作用及建设成本

新来戈大坝原计划发挥**大型水电、河流调节、工业供水、城市供水及防洪削峰**等多重作用。秦棠的工业生产、部分城市用电和附近农业依赖其稳定调度，坝区还带动大型运输、公路、施工维护与沿线服务业活动。

建设总成本约**1,380亿Ɓ**，属于涵盖坝体、发电设施、输变电、水文调度、公共供水与配套工程的全项目口径，不是仅计算混凝土与钢材的造价。工程的经济价值还包括供电、供水和长期防洪效益，不能只用建造合同额计算其战时损失。

## “锋刃”战役中的工程毁坏

全球攻势期间，新来戈大坝所在地区成为寰宇与深蓝争夺的重要地点。战斗造成坝区基础设施中断，并引发供电及泄洪控制系统异常、局部结构严重受损，最终发生**非计划大量泄水与局部坝体失效**。

| 项目 | 灾害期间统计 |
| --- | --- |
| 事故前水库估算蓄水量 | **约181亿m³**，低于236亿m³总库容 |
| 前46小时非计划大规模下泄总水量 | **约47亿m³** |
| **事故期间最大洪峰流量** | **约125,000m³/s**，短时非常态峰值 |
| 相对于设计最大泄洪流量 | 最大异常洪峰约为常规设计最大泄洪流量的**2.23倍** |
| 坝区发电能力暂时损失 | **约11,000MW**，大部分主力机组停运 |
| 大型道路／电力／供水设施 | 多处停运或严重损坏 |
| 首批灾区应急措施 | 大范围人员撤离、道路封闭及跨地区水灾救援 |

**异常洪峰高于正常泄洪设备的设计最大流量，并不意味着完好的泄洪闸门被人为调到超设计流量**；事故洪水中还存在局部结构失效和不受控制的外泄，二者统计口径不同。47亿m³为最初46小时的大规模非计划下泄量，不是整个水库全部水量。

## 洪灾面积与人员损失

| 统计项目 | 战灾统计 |
| --- | --- |
| **最大淹没及复合洪涝影响面积** | **约4,900km²** |
| 其中受淹或严重内涝农业用地 | **约2,100km²** |
| 其中城镇建成区、工业及交通用地 | **约430km²** |
| 其他河漫滩、湿地、山谷与受淹低地 | **约2,370km²** |
| **洪灾直接死亡** | **约31,700人** |
| **洪灾受伤** | **约106,000人** |
| **洪灾失踪** | **约13,400人** |
| **死亡、受伤及失踪总计** | **约151,100人** |
| 被迫撤离或长期失去正常住所 | **约182万人** |
| 受灾影响总人口 | **约520万人** |
| 直接基础设施与财产损失 | **约730亿Ɓ** |
| 长期重建和综合恢复支出估计 | **约980亿Ɓ**，与直接损失不是可直接相加的独立项目 |

总计**151,100人**为死亡31,700＋受伤106,000＋失踪13,400的**不重叠统计合计**。失踪者尚不能全部等同死亡；182万撤离或失去住所人数与520万受灾影响人口也**可能包含上述伤亡人员，不应在不同统计口径间重复相加**。

最大4,900km²范围包含主河道外溢、低地积水、城市排水瘫痪及回水区，不代表整片区域水深一致。灾害波及**萨瑞拉西北部首都及经济核心地区**。目前已正式确认**秦棠位于萨瑞拉西北方向**；这与两国既有的贸易联系和灾害影响区域一致，但不能仅凭国家方位反推出大坝的精确上下游关系、洪水传播路径或国界形状。

## 战后后果与责任争议

“锋刃”战役军事上以寰宇取得局部战术胜利结束，但大坝恢复稳定运行仍需秦棠公共部门与工程合作方开展长期修复。人员失踪、受伤、住宅损失及生计中断使这场灾难远超一般军事设施破坏。

深蓝公开指控寰宇主动毁坝后以维修为名夺取地区；寰宇则指控深蓝蓄意轰炸大坝，以洪灾扩大其军事影响。战争记录可以确认交战造成的**重要设备失效、设施损坏和后续非计划洪灾**，但不能仅据任一方宣传确定**蓄意破坏的完整责任链**。

寰宇内部的工业AI“雷曼”曾预先知悉某些袭击风险及间谍活动，并有仿生替身卷入相关事件；**这一背景不能自动证明雷曼直接指挥毁坝，也不能免除任何其他参与者应受的调查**。

新来戈大坝事件说明：一座服务发电、工农业和防洪的巨型公共工程，虽然只发生局部结构与控制系统灾难，也可能对跨地区数百万人造成长期影响。
