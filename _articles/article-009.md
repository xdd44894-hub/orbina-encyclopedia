寰宇重工集团内部组织与运营手册

本手册为寰宇重工集团全球运营体系的完整说明文件。本手册仅存电子版，存储于集团核心服务器，访问须通过家族理事会授权及至少两名执行理事的联合生物密钥。任何未经授权的查阅或复制行为将触发立即清除程序。手册内容不向普通员工开放，不向任何客户披露，不向任何监管机构提交。

## 第一章　集团概况与产业范围

寰宇重工是注册于联合城工业特许特区的跨星域军工与重工业集团，总部位于俄庇娜本星系联合城直属重工业星域第三号工业行星。集团拥有舰船、航空器、战略防御武器、地面装甲装备、单兵系统、弹药、军用后勤、矿冶和大型工业基础设施业务，在全球一百三十二个主要大国中的九十八个拥有军火供应合同；联合城为集团最大单一客户。集团沿用“锻造和平的基石”的官方口号。

集团从军备需求、战时消耗、和平时期的装备更新和大型工业工程中取得收入。冲突可能带来订单，也可能带来禁运、运输损失与设施毁坏；集团并非全部人员都以无限延长战争为唯一利益目标。

集团由**西伯亚家族**实际控制。“寰宇”是企业名称，不是家族姓氏。家族军工资本源于第五次世界大战期间的小型承包商，经合同、研发与并购逐步扩张。集团约七亿的既有统计是人类雇员与自动化劳动单元的**合计核算数**，不是七亿名人类雇员：其中约百分之三十五为人类雇员（约二亿四千五百万），百分之六十五为工业机器人、矿机、物流设备及工业智能系统（约四亿五千五百万）。自动化单元不领取薪资、不参与人员晋升；其承担九成以上原料开采与基础制造作业量。

## 第二章　所有权与九人理事会

寰宇不是上市企业，控制性权益由西伯亚家族信托持有，不存在自由交易的公开股价。集团以经营收益、家族资本以及不转移表决控制权的融资安排筹资。停火与订单变化可能影响利润预期及信托资产估值，而不是普通证券市场的“股价下跌”。

集团不设传统首席执行官。最高决策机构为九名西伯亚家族成员组成的家族理事会。雷曼·西伯亚与其长兄的父亲担任理事会主席，统筹议程与家族政治平衡。普通事项需至少五票，重大资产、人事及战略决议需至少六票，涉及家族信托控制权和根本章程的事项原则上须九票一致。主席的决定性一票仅指其余八席在普通议案上出现四比四时，由未回避的主席投出自己的**唯一一票**，不是额外第十票。涉及利益冲突的理事回避不得降低特别多数门槛。

理事会下设三个平行执行体系：

| 职位 | 现任者 | 主管业务 |
| --- | --- | --- |
| 第一执行理事 | 主席长子 | 生产与研发 |
| 第二执行理事 | 主席侄女 | 商业与市场 |
| 第三执行理事 | 主席之弟 | 安全与内务 |

章程要求三名执行理事至少两人出自西伯亚家族，非家族候选人须获六票以上同意；现任三人**全部属于家族成员**。此前从竞争对手处延揽、任职超过十五年的职业经理人现担任**集团运营协调官**，负责跨部门交付与预算衔接，不占执行理事席位，不是第四位执行理事。

理事会直属秘书处、家族信托事务办公室、集团法务与制度委员会及独立财务审计委员会。普通业务手册及授权范围内的行政规则可由执行部门签发；只有根本章程和信托控制权等重大制度调整需要九人一致批准。

## 第三章　生产与研发体系

第一执行理事是主席长子，掌管工程研发、制造体系、资源配置及产品交付。他曾主动同秦棠官方商谈新来戈大坝项目，争取父亲与理事会支持，并与资深工人、工程师和管理层维持密切联系。

生产与研发体系设**八个一级部门**：

1. **舰船制造部**：负责太空舰船与大型大气层舰艇的船体、动力及系统集成。集团设有二十三个主要船坞，其中最大船坞能够同时建造四艘战列巡洋舰级舰船；这一数字是船坞在建能力，并非年度交付数。
2. **航空与无人飞行系统部**：负责有人军用飞机、无人战斗机、飞行控制与整机验证，牵头研制生产空猎-92系列。
3. **行星级武器部**：负责轨道防御与极高能级战略装备。所谓“行星裂解装置”仍属极端战略研究概念，不能当成成熟量产或常规出口产品。
4. **外骨骼与单兵装备部**：负责动力外骨骼、头盔、护甲、枪械与单兵信息系统；联合军第一特别派遣部队特殊单位“喀沃徒”的外骨骼属于其定制项目。
5. **弹药、物流与后勤装备部**：负责枪弹、炮弹、导弹、火箭弹、炸弹、战时补给、后勤车辆与维修保障。
6. **地面重型装备部**：负责坦克、步兵战车、装甲运输车辆、自行火炮、地面防空平台及大型无人地面装备。
7. **重大工程与工业基础设施部**：负责水坝主体、巨型土建、工业厂区、重型施工机械和大型工业承包项目，包括新来戈大坝的寰宇施工部分。
8. **资源与基础工业部**：负责矿场、冶炼、化工、基础零部件、原料储备和基础工业物流。

八部门共用技术标准、质量认证与重大项目管理机构，跨部门项目实行牵头部门负责、专业部门配套交付。客户依赖主要来自专有软件、加密模块、服务合同和部分专有接口；**不存在所有新型号必须与旧型号弹药和零部件不兼容的绝对规则**，通用弹药与标准化接口可以跨代延续。

## 第四章　商业与市场体系

第二执行理事为主席侄女，其下设**客户关系与军售部、政府关系与出口合规部、区域局势评估部、财务与国际结算部、售后与长期客户服务部**五个一级部门，分别负责合同销售、许可证与政府往来、市场和局势分析、现金流及跨星域结算、维保和技术支持。

市场评估与第三执行体系的反间谍调查不是同一职能。政府游说、灰色转口或个人违规可以构成集团经营中的政治风险，但不能自动视为合法且绝无后果的正式程序。商业体系不得单方面批准未通过技术审查的产品性能承诺。

## 第五章　安全与内务体系

第三执行理事为主席之弟，其下设**内部监察与安全调查局、外部情报与反间谍局、武装护卫与资产保护部、工业网络与系统安全局**四个一级部门。前者处理内部调查与人员安全；第二个处理外部渗透及情报风险；第三个负责矿场、船坞、研究设施及运输护卫；第四个负责工业控制网络、AI访问权限与应急人工接管。

既有资料记载武装护卫部拥有四艘武装护卫舰及二百余艘战斗艇；这是集团专属护卫规模，非其制造舰船总量或联合城正规军规模。网络安全部门可按预案临时中止危险系统，但不能凭此永久夺取生产管理权。财务审计向理事会独立报告，安全监察不得包揽一切审计与组织决策。

## 第六章　家族派系与雷曼

西伯亚家族现任主席总体守成，反对缺乏安全保障的大规模组织改革，并非拒绝全部新技术。长子坚持在工业生产中保留有经验的人类工程和管理链条。他反对雷曼提出的整体性大裁员，原因包括经验流失、生产可靠性和管理权过度集中；雷曼称兄长“优柔寡断”只是其个人敌意评价。

雷曼·西伯亚是主席次子，部分家仆私下称其为“太子”，但这不是法定继承人身份。集团内部存在以长子为核心的制造与工程派、以第二执行理事为核心的市场派、以主席及第三执行理事为核心的家族控制派、以及围绕雷曼形成的技术集中化派。这些是利益联盟，不是新增的正式执行机关。

旧称“退役派”的人员网络统一称**资深稳健派**，由长期任职的工厂主管、工程人员和经验丰富的管理者构成，不要求这些人亲历第五次世界大战并工作至今，也不赋予他们与九名家族理事同等的直接投票权。

## 第七章　工业AI“雷曼”与改革权限

寰宇工厂本来就广泛使用工业机器人。“雷曼”计划的新增目标是把跨厂生产调度、资源配置、质量评估与部分管理决策集中到统一工业AI系统，并借此改变传统厂长和经理人的权力结构。

雷曼通过尚未完全明确的渠道取得人民天国工业AI“天工”的**部分技术资料**，自行研究并推断出若干设计要点。他并未完整获得天工源代码或直接复制其全部性能。

大坝事件后，雷曼通过家族内部政治博弈争取到**部分工厂的有限AI试点权限**，并未接管集团大多数工厂。大规模裁员尚未作为已完成事实，长子亦未自动失去执行理事职位。试点的关键设备停机、重要人事决定、军品质量放行和安全接管保留授权的人类责任岗位，雷曼不能仅凭系统命名取得全部工厂的最高控制权限。

## 第八章　新来戈大坝与重大工程

新来戈大坝合作由长子主动同秦棠谈判并说服父亲批准。秦棠提供东北矿业资源的优惠开采或供货权益，既有条件约为相应市场价格的百分之三十。寰宇负责坝体、土建、施工机械、钢结构和大宗运输，深蓝科技负责水力发电、泄洪调度、自动安全监测、水文研究与配套供水专业工程；秦棠政府负责公共监管、验收与运营。

雷曼预先知悉集团内部存在天国间谍及大坝可能遭袭的风险，并使局势向有利于其内部权力目标的方向发展。他利用相关原型技术制作的仿生替身参与大坝事件。但这不说明天国全部间谍、集团所有部门或后续战役都是由雷曼直接操控；具体刑责、调查证据与战争原因必须分别判断。

## 第九章　客户关系与战争利益

联合城的采购额约占寰宇集团总营收的三成，双方在工业供货、军用零部件与授权上存在深度依赖。人民天国不是集团的公开正规军售客户，经第三国转手的装备与零件可能产生灰色贸易。赤垩天共和国长期采购弹药、外骨骼和部分舰船部件。集团各部门对持续冲突、停战和新客户开拓存在不同利益判断，不宜把所有人写成同一个政治意志。

## 第十章　产品分级与质量责任

集团使用旗舰级、标准级、外销级、库存及翻新级等内部商业分级。外销型可按许可和保密规则缩减配置；库存及翻新级须经检验并披露必要的寿命及质量信息。**未达到作战验收标准的废料不是正规的可用武器销售等级**。灰色销售、隐瞒缺陷或恶意合同确实可能出现，但并不天然排除诉讼、仲裁、赔偿或制裁。

## 第十一章　资料保密及内部规章

集团对客户、战略研发和家族事务实施分级保密，并对高等级资料采用跨执行体系的联合授权、访问留痕与异常冻结。日常行政或制造手册依授权进行修订，不要求九人理事会每次一致同意。集团保密规则不意味着任何可能的监管、审计或司法程序都被自动排除。

## 第十二章　员工工作服、厂区民兵与设施防护

### 工作服颜色与岗位识别

寰宇重工按照员工的主要岗位和作业性质配发不同颜色的工作服，颜色与主要职责的正式对应如下：

| 工作服颜色 | 主要岗位或作业性质 |
| --- | --- |
| 灰色 | 安保 |
| 蓝色 | 生产与研发 |
| 白色 | 精密作业 |
| 橙色 | 安全管理 |
| 青绿色 | 内部医疗 |
| 黄色 | 工程设计 |
| 红色 | 危险作业 |

灰色安保与橙色安全管理分别对应厂区安保职责和生产作业安全职责，不能混为同一种岗位。颜色是岗位识别，不直接代表人员的军事等级或战斗能力。

### 厂区“民兵”：规模、身份与职责

寰宇重工的部分工厂，尤其是临近开发区的工厂，设有规模可观的兼职厂区辅助安保力量，习惯上称为**“民兵”**。这些人员总体数量不少；但**民兵人数较多，不等于寰宇会组织他们参加战争**。

民兵首先是普通工厂员工，平时从事生产、研发、施工、仓储、运输等本职工作。遇到厂区治安事件、警戒需要或严重安全威胁时，他们可以临时协助专职安保，充当第二安保队员。这是一套用于本地工厂秩序与设施自卫的辅助制度，**不是集团的正式作战兵种、远征部队或用于主动参与战争的预备军**。

成员通常是**20至50岁的成年人**，具有既往安保经验，或接受过简单安保训练。民兵的训练和装备水平有差异，不能一律视作职业军警。并非集团所有工厂都有相同编制，不能把其数量大误写为集团全部员工均有民兵身份。

### 厂区民兵装备与厂区防护器材

不同工厂的配发与可调用装备有所不同。已确认的民兵及相关厂区安全装备包括：

| 类型 | 装备与用途 |
| --- | --- |
| 侦察 | 侦察无人机，用于监视和识别厂区周边情况 |
| 捕捉、控制 | 捕网枪；农业捕网无人机，后者可用于野外抓捕人员 |
| 防暴与非致命处置 | 催泪弹、防暴装备 |
| 个人防护 | 防毒面具、纯陶瓷防弹衣 |
| 随身携行 | 简易弹挂及挎包 |
| 轻型枪械 | 可折叠收纳进挎包的折叠冲锋枪、采用AK工作原理的短步枪 |
| 其他枪械 | 多功能霰弹枪、淘汰的警用手枪，以及其他老式枪械 |
| 设施近程防空 | 短距离激光防空武器，主要应对携带炸弹的无人机 |

这是一份**整体装备范围**，不意味着每名民兵都获配表中全部装备，也不意味着上述武器全部由民兵个人随身携带。短距离激光防空武器属于厂区防护体系的专用设施装备，不能等同于普通员工日常携行的个人武器。折叠冲锋枪可收纳进挎包，是部分人员的便携选择；工作期间是否携枪依厂区安排，并非人人全天武装值勤。

捕网、催泪装备属于相对减少致死风险的控制手段，仍可能造成伤害；其用途不等于可以无条件使用。型号、数量、具体配发比例与统一制服之外的附加标识尚未另行规定。

### 开发区治安、企业责任与安保接管

开发区部分地段的治安薄弱，个人之间即使发生致死斗殴，也可能因取证困难、人口流动和执法能力不足而难以追责。**寰宇却是大型企业**：工厂有固定地点、资产、员工、合同与明确的管理主体，一次不当的致命处置更容易引发对企业的调查、索赔、政治压力和声誉损失。

因此，寰宇对于一般纠纷、闯入或治安事件更倾向使用侦察、警戒、隔离和人员控制手段，而非直接让兼职民兵发动致命交火。这并不表示寰宇缺乏武力。

**如果游荡者主动向工厂或其人员开枪**，寰宇便有充分理由将事件升级为现实武装威胁，并让**专职安保人员**接管危险处置；民兵继续承担辅助警戒、人员保护与厂内支援职责。由此获得的是应对正在发生的安全威胁的理由，**不是不受限制地追杀、报复或发起战争的授权**。

厂区民兵的人数优势服务于日常工业运行和紧急防卫能力；需要专业武装行动时，主体仍是集团安全与内务体系下的职业安保力量，而非让普通工人代替正规战斗人员。

## 超大批次工业补充

### 规模效应
即使高性能材料本身成本上涨，俄庇娜的工业环境仍可通过超大批量生产有效分摊成本。

### 普通小厂
寰宇体系中，即便被称为“普通小厂”，单个最高可控批次也可达到约：
12,000吨。

“可控批次”强调：
原料调配、混合、检测、性能一致性仍被纳入同一批质量控制逻辑。

### 超重型工厂
寰宇超重型工厂的单个最高可控批次可达到约：
80,000吨/批。

### 极端工业基地
部分极端基地总体处理/生产规模可达到约：
300,000吨级。

注意：
“30万吨”不是一锅，也不是单个批次。
它属于基地级总吞吐/总处理规模，可由多线、多批次、并行或连续生产形成。

### 工业风格
寰宇的强项不只是“能做高性能材料”，而是：
能把高性能材料做成巨量、稳定、重复、可工程化的大宗工业品。

## 三年战争后：寰宇的“双线战略”

三年战争结束后，寰宇开始同时推进两条战线。

【1. 正面战场】
继续在公开战场上打击深蓝的：
- 军事实力；
- 阵地；
- 工业体系；
- 战争能力。

【2. 敌后行动】
在深蓝后方和隐蔽区域中：
- 搜集罪证；
- 保存原始记录；
- 验证黑箱项目；
- 寻找知情人；
- 获取可被第三方承认的档案与实物证据。

【3. 核心政治目的】
寰宇的目标已经不只是“击败深蓝”。

更重要的是：
收集足够多、足够可靠的深蓝罪证，形成政治与法律压力，迫使联合城从中立、观望或有限合作状态进一步转向，与寰宇共同对抗深蓝。

因此：
- 正面战场负责军事施压；
- 敌后行动负责证据战、情报战与政治施压。
