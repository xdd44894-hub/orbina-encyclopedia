# 新型活跃菌种-MR100

**新型活跃菌种-MR100**是生物学家为一种无法归入任何已知菌种的异常菌类所赋予的研究编号。其相关线索来自藏朔原[炉膛信仰]({{ '/articles/article-436/' | relative_url }})极端分支的系列调查。部分涉案[现实失衡能（RDE）]({{ '/articles/article-001/' | relative_url }})设备表面出现可活动的血肉状增生物，后来确认其本质是MR100菌群，**并非炉火成神或死者血肉复活**。

## 一、已确定的生物学特征

- **分类**：无法与任何已知菌种对应，正式研究编号为“新型活跃菌种-MR100”；确切分类与演化来源未知。
- **生活方式**：依赖动物宿主的共生／寄生性菌类，可以寄附于人类及其他动物；“共生”描述其依附生活状态，不保证对宿主有利。
- **传染性**：很强；实际传播途径与传播距离尚未确定。
- **离体运动**：可主动进行短距离移动，但脱离动物宿主后极易死亡。
- **环境敏感**：过热、过亮或过大的噪声均可使其死亡；确切阈值未知。
- **宿主外观**：感染后可以没有明显可见异常。
- **精神感知与行为**：部分感染者报告悲观情绪、自杀念头、幻觉或幻听；案件调查还发现不少感染的人和动物会自行接近RDE设备，进入后发生致命的自毁行为。不是每个感染者都已证实发生上述全部表现。
- **RDE关系**：MR100的活跃程度**不随人类尸体数量增加而必然提高**；向设施投入更多尸体并不能替代它所需的动物宿主。

上述菌类的神经行为影响机制、宿主范围、感染率与病程尚未确立。对于动物的相关事件，研究者可以记录其行为和死亡，但不能据此断定它们具备与人类相同的主观自杀意图。

## 二、调查线索：寒夜散步后返回工厂

一名工人在夜间吃完饭后，明知外面天气寒冷，却突然想出门散步。走了很长一段路，他发现自己**不知不觉回到了RDE工厂**。被发现时，连他本人都无法解释自己为什么会走到那里。

这段经历使调查者注意到：感染相关的异常行为未必伴随显著的面部变化、发狂或可见的躯体畸变。一个人可能像平时一样吃饭、出门、走路，却在**毫无清晰动机和自觉解释的情况下趋向RDE设施**。

但此例**并未直接证明**MR100的哪一种神经机制在起作用，也不能仅凭“回到工厂”认定所有此类行为都由菌体电信号直接指挥。它是一条值得追查的异常个案，而非已完成的因果实验。

## 三、三态电语：MR100的群体交流体系

**MR100拥有菌群之间使用的语言，借电信号进行交流，基础编码为三进制。** 与人类用声带发音不同，MR100的“字”是可辨识的电信号状态序列。以下采用研究转写名称**“三态电语”**；名称和汉语释义是观察者为了记录而使用的工具，不代表菌群具有与人类完全同构的词汇或意识。

### 1. 信号字母与帧结构

每个基本电信号时隙有三种有效状态：

| 三进制符号 | 观测转写 | 状态含义 |
| --- | --- | --- |
| **0** | 低 | 有效的低电位状态，**不等于静默** |
| **1** | 中 | 有效的中电位状态 |
| **2** | 高 | 有效的高电位状态 |

**每3个三进制状态组成一个基本语素**，总数为 `3³ = 27`。这些是有意义的基本符号，不是人类意义上专门拼音的二十七个字母。

- 单个语素由连续三个有效时隙构成，按顺序读取。
- 语素之间以**两个空时隙**隔开；完整电文之间以**五个空时隙**隔开。空时隙是未发送信号，与符号0的有效低电位状态不同。
- 因此 `000` 是合法语素，不会被误当成没有发出电文。
- 这些时隙与间隔是本设定的**标准化转写规则**，并未规定它们在现实测量中必须等于多少毫秒；具体传导介质、通信距离、信号来源器官和误码机制暂不指定。

这套字母表由**27个基础语义单位**组成，语言可以通过**重复、组合、否定、程度与时间标记**表达超过27种含义。特别要注意：

- `021` 的字面意义是**强电性地标／共振源**，在相关案件中经常指向RDE设备；**不等于**菌群知道人类把那台装置叫作“RDE工厂”。
- `001` 可指宿主这个对象，也可用于“依附于宿主之内”的情景。
- `020` 与 `122` 可以合用，表达“沿熟悉路径返回”。
- `201` 是**紧邻其后语素**的否定词，不是全句自动否定。
- `212`、`220` 用作前一状态或动作的程度修饰；`221` 标明前一对象为复数或群体。

### 3. 基础组句法

一般结构是：**主体 → 倾向／动作 → 目标／方向 → 状态／时间**。电语不严格区分名词、动词和形容词，同一基础语素可以随位置承担不同功能。

简单复合词可连续并列：`020 122` = 依循旧路归返；`022 101` = 热危险；`111 120` = 衰弱至终止。

### 4. 可逐位解码的电文

**电文 A：宿主正在趋向熟悉的电性源**

```text
001 200 020 122 021 202
```

逐符号：宿主／趋向／归返／旧路／强电性地标／现在。

译文：**“宿主此刻正沿熟悉路径返回那处电性源。”**

这是为说明那名夜间散步工人而构造的**示例电文**，不是声称已从该工人的身体里取得了原始记录。

**电文 B：菌群离开宿主后衰弱**

```text
000 012 001 111 120
```

逐符号：本群／离开／宿主／衰弱／死亡。

译文：**“离开宿主后，我们会衰弱、死去。”**

**电文 C：警戒高热、强光与巨大噪声**

```text
000 022 101 212 102 212 110 212
```

逐符号：本群／危险／热／增强／光／增强／声振／增强。

译文：**“警戒：强烈的热、光和声振正在威胁菌群。”**

**电文 D：无法确定是否该靠近目标**

```text
000 200 011 021 222
```

逐符号：本群／趋向／接近／强电性地标／疑问。

译文：**“我们要接近那个电性源吗？”**

这些中文句子是**研究者的语义译文**；电语真正编码的是状态、趋向和关系，而不是完整的汉语句子。

## 四、电语与宿主行为的关系

MR100能够以电信号彼此交流，与受感染人类出现**情绪低落、幻觉幻听、无意识回到RDE设施**等行为异常是两组并存的已知事实。二者可能存在关联，但**尚不能把每一次异常行为直接等同于菌群正在发送可翻译的命令**。

研究者尤其需要区分：

1. **菌群之间的电语**：具有三进制基本符号、组合语法与可记录的电信号。
2. **宿主主观体验**：可能出现悲观念头、错觉、幻听或难以解释的趋向行为。
3. **信徒的宗教解释**：部分炉膛信徒将上述体验误解为炉火或神明的“回应”。

三者不能混作一件事。MR100本质上仍是未知菌类，而非已证实的神灵。相关犯罪及宗教误读详见[《藏朔原·炉膛信仰》]({{ '/articles/article-436/' | relative_url }})，工业背景见[《藏朔原现实失衡能产业》]({{ '/articles/article-046/' | relative_url }})。
