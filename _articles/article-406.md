**萨德林高寒单兵三日套餐**，是[萨德林共产乌托邦共和国]({{ '/articles/article-008/' | relative_url }})面向高寒地区单兵行动配发的**一人三日份军用食品套餐**。新版在原有肉罐头、抹酱、水果饼干、巧克力、咖啡、酒类与简易加热用品的基础上，大量增加**能量棒、压缩饼干、坚果、油脂、奶制品、肉干、速食面及燕麦片**，使其既保留饮食品种，也更能适应高寒及高体力消耗环境。

**既定报价不变：军方大宗采购11Ɓ／整箱；非军方采购33～40Ɓ／整箱**。这是整套三日套餐的价格，不是每天或某种罐头的单价；未设定独立的制造成本、补贴额或利润率。非军方销售也为普通居民提供尝鲜渠道。

## 食品重量与能量统计口径

依照已明确的**克数**逐项相加，新版固态、半固态食品以及以克数标记的糖、调味料与咖啡合计**4,001g**；这里**尚未纳入两包速食面（未标单包重量）、80mL植物油、200mL伏特加、铝片支架、玻璃杯、火柴、燃料块、湿巾、罐体和纸箱**，因此**4,001g是部分食品净质量，并不是6kg整箱重量**。

**明确指定热量的四组新增食品**如下：

| 已标定能量 | 合计热量 |
| --- | ---: |
| 压缩能量棒4根 | **约1,000kcal** |
| 植物油80mL | **约650kcal** |
| 蜂蜜80g | **约240kcal** |
| 牛肉味＋黑虎虾味速食面各1包 | **约800kcal** |
| **以上四组小计** | **约2,690kcal** |

全箱其他食物还包括大量肉类、油脂、乳制品、主食与坚果，因此**实际全箱热量明显高于上述2,690kcal部分合计**。若仅按常见同类食品的典型能量密度粗估，**全箱不计酒精热量的食品总能量可落在约14,000～18,000kcal量级，即平均约4,700～6,000kcal／天**；这只是**未获得全部品牌营养标签前的宽区间估算**，**不是已确认的正式产品标签热量**。酒精饮料不能视为安全的高寒补给热量来源。

**新版的设计目的与旧版有所不同：** 较多高能主食、油脂、坚果及奶制品能够提高三日高体力消耗任务的能量保障能力，但也会带来实际重量、携行体积、乳制品存储与野外补水、燃料使用等问题。**这份套餐没有自带饮用水**，士兵还须另行保证饮水安全与炊具。

## 巧克力的批次口味差异

部分赶工生产批次的**100g巧克力**可能出现糖分混合不够均匀，**同一整块有些位置很甜、有些位置明显发苦**的现象。**新版一箱包含两包各100g的巧克力**；出现过口味不均的情况，并不等于每箱两包都必然如此，更不能把它误写为专门设计的苦甜双口味。

既定原因是**赶工导致混合不充分**。目前未确定涉及的生产日期、批次比例或质量检验处置办法，亦不能只凭甜度差异推定已经发生食品安全事故。

## 食用方式与额外自备品

萨德林高寒地带士兵通常**另外自备粗粮面包**，配罐装肉类、鹅肝酱、午餐肉泥、蔬菜酱或花生酱食用。压缩饼干、能量棒、坚果、牛肉干可在不方便烹调时取用；燕麦、奶粉、速食面及热饮则通常需要适当的水与加热条件。这里**只确定物品及一般使用方式，不把整箱强制划分成未经指定的三张日菜单**。

高寒地区常见**融冰取水**，但**融化冰不等于完成水源净化**。新版虽然有四块固体酒精和铝片炉支架，但在连续融冰、烧水与加热面食等情况下，**燃料是否充足取决于单块燃料的重量、天气、锅具及实际需求**；不能把它写成能自动满足三日全部饮水的完整炊事系统。

**必须自备水、刀叉勺、饭盒、餐巾、粗粮面包等。** 铝片支架是一片用来支撑饭盒并容纳燃料的简易金属薄片结构，**不包括饭盒，也不是自带燃烧器和风扇的复杂炉具**。20mL玻璃小杯同样不能替代正常的饭盒和饮水容器。

伏特加200mL、40度仍然是既定箱内物资，但**酒精饮料不能取代补水、保暖或失温救治**。食品储存、乳制品保存方式以及具体使用时限等应依后续产品工艺与包装标准另行确定。

## 与维涅沃平原师的区别

**这套新版仍然是高寒地区单兵三日配给，不代表[裘尔]({{ '/articles/article-407/' | relative_url }})所属“维涅沃平原师”的平原日常口粮。** 平原地区的配给餐油水相对更少，有条件取得水并烧开而不必融冰；裘尔擅长现做**牛肉罗宋汤、三天仍不容易变硬的松软面包**，并以**公锅取汤与入口试吃分开用两副勺子**保持卫生。他的手艺及当地供餐方式不能被高寒预包装套餐的物品清单替代。

## 在萨德林军需体系中的定位

新版比此前的三日套餐**额外重视高能量、耐储食品与高寒作业所需的能量密度**，但整箱约6kg、外部尺寸40×30×20cm的仓储包装本身不方便直接随突击包携行，因此形成**大箱集中配发—拆箱拆隔间—单件分散装包**的野外携行方式。

由于新增大量不同类型食品、两包速食面与乳制品，后续如果设定更准确的产品标签热量、速食面净质量和包装保质期，应直接修订本条参数，而不是在旧版资料之外另建“未归档记录”。
