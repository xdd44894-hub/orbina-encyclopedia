**萨德林高寒单兵三日套餐**，是[萨德林共产乌托邦共和国]({{ '/articles/article-008/' | relative_url }})面向高寒地区单兵行动配发的**一人三日份军用食品套餐**。新版在原有肉罐头、抹酱、水果饼干、巧克力、咖啡、酒类与简易加热用品的基础上，大量增加**能量棒、压缩饼干、坚果、油脂、奶制品、肉干、速食面及燕麦片**，使其既保留饮食品种，也更能适应高寒及高体力消耗环境。

**正式价格：生产成本约12.8Ɓ／整箱，军方大宗采购15Ɓ／整箱；非军方购买33～40Ɓ／整箱保持不变。** 这些均以一人三日份的整箱为单位。食品厂以规模化供货取得收益，不能把售价与生产成本之间的差额直接等同于税后净利润；民用销售渠道让普通居民也能体验这种三日军粮。

## 食品重量与能量统计口径

依照已明确的**克数**逐项相加，新版固态、半固态食品以及以克数标记的糖、调味料与咖啡合计**4,001g**。**另有已确定质量的固体酒精燃料4块×55g＝220g**，两项合计**4,221g**，但220g属于**加热燃料而不是食品**，不能加到食品净质量中。**4,001g食品净重**尚未纳入两包速食面（未标单包重量）、80mL植物油、200mL伏特加、铝片支架、玻璃杯、火柴、湿巾、罐体、双层箱与防护衬垫；**4,221g也不是完整整箱毛重**，现有整箱参考重量仍为约6kg。

## 肉类罐头的产业背景

萨德林拥有[**Старая кухня（老厨房）**]({{ '/articles/article-408/' | relative_url }})这一**全国最大的国营食品厂**，其供应量占**全国肉类罐头食品总量的41.1%**，并向众多农场收购猪、牛、鸡，**收购报价一贯比私营企业平均报价高25%**。

该厂与本套餐中的肉类罐头属于**相关的食品工业领域**，但**尚未正式确认鸡肉、猪肉、牛舌罐头由其生产，也未确认它负责三日套餐整箱装配或军方采购合同**。因此套餐的生产成本**约12.8Ɓ**、军购价**15Ɓ**和民用价**33～40Ɓ**不能自动归入该厂的营业收入或利润表。

## 巧克力的批次口味差异

部分赶工生产批次的**100g巧克力**可能出现糖分混合不够均匀，**同一整块有些位置很甜、有些位置明显发苦**的现象。**新版一箱包含两包各100g的巧克力**；出现过口味不均的情况，并不等于每箱两包都必然如此，更不能把它误写为专门设计的苦甜双口味。

既定原因是**赶工导致混合不充分**。目前未确定涉及的生产日期、批次比例或质量检验处置办法，亦不能只凭甜度差异推定已经发生食品安全事故。

## 食用方式与额外自备品

萨德林高寒地带士兵通常**另外自备粗粮面包**，配罐装肉类、鹅肝酱、午餐肉泥、蔬菜酱或花生酱食用。压缩饼干、能量棒、坚果、牛肉干可在不方便烹调时取用；燕麦、奶粉、速食面及热饮则通常需要适当的水与加热条件。这里**只确定物品及一般使用方式，不把整箱强制划分成未经指定的三张日菜单**。

高寒地区常见**融冰取水**，但**融化冰不等于完成水源净化**。单兵套餐明确配发**4块各55g的固体酒精燃料，合计220g**，可配铝片炉支架和自备饭盒用于食品加热及必要的小规模烧水。**这220g是个人随箱燃料，不承担整支部队三天全部融冰与饮水的供给任务**；实际使用时长及能融化多少冰仍受天气、燃烧效率、锅具和加热需求影响。

**必须自备水、刀叉勺、饭盒、餐巾、粗粮面包等。** 部队在设有炊事保障时可在**开饭时从保温桶集中分配水**，但这不表示士兵可以完全不携带个人饮水，也不表示所有分散行动都有炊事兵随行。铝片支架用于支撑饭盒、在下方容纳燃料，**不包括饭盒，也不是自带燃烧器和风扇的复杂炉具**。20mL玻璃小杯不能替代正常的饭盒和饮水容器。

伏特加200mL、40度仍然是既定箱内物资，但**酒精饮料不能取代补水、保暖或失温救治**。食品储存、乳制品保存方式以及具体使用时限等应依后续产品工艺与包装标准另行确定。

## 炊事兵的额外融冰与集中分水保障

萨德林高寒部队的炊事兵通常会根据驻地条件与任务需求，**额外携带融冰燃料、相关炊事工具**，或**直接携带装有水的保温桶**。在有集中炊事安排的情况下，炊事人员会在**开饭时向士兵分配饮水**，使个人不用单凭四块固体酒精去解决一切融冰、煮水需求。

这种做法让**单兵口粮**和**单位炊事、供水保障**各司其职：

- **个人配给：** 每箱220g固体酒精、铝片炉支架和火柴，主要供临时加热食品或应急使用。
- **炊事保障：** 另外携带融冰燃料、工具，按集体用餐人数和环境条件准备水；也可以采用保温桶运输已备好的水，在开饭时分发。
- **分散行动：** 无法依赖随时有炊事人员和保温桶到场，因此个人仍须自备足够饮水与合适的补给安排。

**使用保温桶不意味着冰自动变成安全饮用水。** 取水、融冰与需要的净化／卫生处理属于独立环节；保温桶的用途是运送和保持已获得的水，而不是代替水源处理。炊事兵携带的**额外燃料、工具和保温桶不属于一箱约6kg单兵套餐的装箱物资**，不能和220g随箱固体酒精重复计算。

## 与维涅沃平原师的区别

**这套新版仍然是高寒地区单兵三日配给，不代表[裘尔]({{ '/articles/article-407/' | relative_url }})所属“维涅沃平原师”的平原日常口粮。** 平原地区的配给餐油水相对更少，有条件取得水并烧开而不必融冰；裘尔擅长现做**牛肉罗宋汤、三天仍不容易变硬的松软面包**，并以**公锅取汤与入口试吃分开用两副勺子**保持卫生。他的手艺及当地供餐方式不能被高寒预包装套餐的物品清单替代。

## 低价高配给的产业与成本解释

萨德林的高寒三日套餐虽然同时包含肉类罐头、奶制品、坚果、牛肉干、牛舌罐头与多种高能食品，**军购整箱售价仍为15Ɓ，单箱生产成本约12.8Ɓ**。这并非食品没有价值，而是**大规模畜牧农业、动物原料多部位利用、高度自动化加工、标准化批量生产、军购特定税费优惠以及军方集中交付**共同作用的结果；**不能用单独一句“科技先进”代替成本核算**。

### 农牧原料：规模、分级利用与上游收入

萨德林的食品工业依托**大规模农牧生产、经过微量改造与杂交及基因筛选的“Пятнистый Толстячок（小肥牛）”快长型小体型肉牛、标准化屠宰加工体系**。这种小肥牛**不是旧地球常见的成年牛**：育种目标是**较小的体型、较快达到出栏条件、较多可食用肉、较低脂肪**，其**幼年阶段代谢快、采食量大、增重快**。更短的生长周期与较多可食用肉有利于稳定供给，但**幼年吃得多也意味着必须投入足够的饲料，不能因此断定总饲料成本或每公斤肉成本无条件更低**。具体出栏月龄、饲料转化效率和肉用率尚未定量。

牛舌罐头不是**300g纯牛舌**：每罐使用该小型肉牛**一条牛舌**，以**牛胸、牛里脊、牛胃等肉及内脏**填满剩余空间。**小型快长品系的舌头与旧地球成年大牛的舌头不是同一个规格**，因此不能拿后者的典型重量直接反驳300g整罐配方。每头牛仍然只有一条舌头，牛舌供给受实际屠宰数量约束；多部位利用提高整头牲畜的食用原料利用程度，但并不让牛舌数量凭空增加。

以[**Старая кухня（老厨房）**]({{ '/articles/article-408/' | relative_url }})为例，这家国营食品厂负责全国**41.1%的肉类罐头供应**，向农场收购猪、牛、鸡时，报价**一贯比私营厂平均报价高25%**。较高的农场收购价意味着**养殖者得到更好的单次销售收入**，并不直接决定一整箱军粮的总成本：其余加工、库存损耗、产品分级利用与产能利用率也影响单位成品成本。**是否由老厨房生产本套餐，尚未确定**；这里以其作为全国食品工业的相关实例，**不能将老厨房的收购溢价直接代入这套军粮的具体合同成本**。

### Пятнистый Толстячок（小肥牛）：以时间和肉用率优化供应

萨德林并不依靠采购旧地球常见成年肉牛来实现牛肉罐头的大量供应。其养殖体系使用名为**“Пятнистый Толстячок”**、中文通称**“小肥牛”**的肉用品系，经过**少量生物改造、不同谱系杂交和定向基因筛选**选育，具有小体型、快长特点。**“Пятнистый Толстячок”在俄语中的字面意味接近“斑点小胖墩”，但正式中文通称是“小肥牛”；名称本身不应额外推断已确认某种斑纹、毛色或具体外观。**这种牲畜的核心生产特征是**幼年生长快、幼年代谢速度快且进食多、肉用产出高、脂肪比例较低、出栏较快**。这描述的是萨德林畜牧业的**育种结果与总体养殖方向**，并不是给所有牛都赋予完全相同的体重、单日采食量或出栏时间。

更快达到出栏条件，能够减少部分存栏时间以及被占用的畜舍、饲养设施和周转资本；较高的可食用肉产出率则可能提高每次屠宰的原料利用价值。不过**代谢旺盛和吃得多需要更多对应的饲料供给**，缩短出栏时间与降低饲料总量之间并非必然同义。要比较真正的单公斤肉成本，还必须考虑**累计饲料投入、存活率、动物卫生、畜舍能耗、实际胴体重量与可食用肉产出**，目前尚未设定足以计算这些指标的数值。

这类牛的**脂肪较少**也意味着不能单靠牛肉本身解释高寒套餐的高热量；现有配给还通过**黄油、植物油、坚果、花生酱和巧克力等独立油脂来源**提供大量能量。小型快长肉牛主要解释的是**肉类供应速度、罐装牛舌尺寸和多部位原料组织**，不直接解释所有食物和税收为什么便宜。

### 人工与能源：高产能分摊，而非免费劳动

食品加工采用**高度机械化、自动化和标准化的生产体系**，把重复性的分切、灌装、灭菌、检漏、装箱与仓储搬运尽可能集中到规模化产线。专业工人仍负责设备维护、品控、物流与异常处理，其劳动费用照常计入成本；低单位人工费来自**单条生产线在一定时间内能完成更多箱**，不意味着无工资、无设备维护费。自动化设备的折旧、工厂电力、供水、热能和食品安全检验也应计入单箱生产成本。

### 税制与渠道：军购优惠不同于民用零售

萨德林针对**符合条件的军事食品大宗采购**实行**特定税费优惠**，从而减少军粮的部分销售／流通环节负担。与普通消费者一箱一箱零售相比，军方实行**大宗合同、固定规格、集中验收与集中交付**；军需仓库向部队进一步分发的成本，**不应擅自全部算作食品厂的出厂生产成本**。

税费优惠**并非国家能够免费取得肉类或机器**，而是国家的税收和军需预算安排。具体税种名称、税率、减免额度、适用期限暂未规定，**不补造统一免税、无税国家或国家必然补贴亏损的设定**。

### 12.8Ɓ整箱成本的示例核算模型

下表是一套**与已确定12.8Ɓ总成本相符、用于说明低价机制的标准估算分摊**，**不是已经公开的某家生产商内部真实账簿，也不证明每个批次的分项成本永远不变**。成本随原料价格、能源、设备产能和采购规模等条件波动，但下列示例**合计必须等于12.8Ɓ**。

| 单箱生产成本构成 | 参考分摊 |
| --- | ---: |
| 猪、牛、鸡、牛舌配肉及牛肉干等畜禽原料 | **4.10Ɓ** |
| 全脂奶粉、奶酪、黄油等乳脂原料 | **1.50Ɓ** |
| 谷物、速食面、燕麦及压缩饼干原料 | **1.35Ɓ** |
| 巧克力、坚果、蜂蜜、糖与其他高能食品原料 | **1.20Ɓ** |
| 蔬菜、咖啡、调味料、伏特加等其他原料 | **1.15Ɓ** |
| 食品加工、罐装及灭菌 | **0.70Ɓ** |
| 24L外箱、20L内箱、防护泡沫与食品包装 | **0.95Ɓ** |
| 酒精燃料、铝片炉架、小杯、火柴与湿巾 | **0.35Ɓ** |
| 人工与生产自动化监管 | **0.33Ɓ** |
| 电力、供水、工业热能 | **0.24Ɓ** |
| 食品检验、生产质量控制 | **0.22Ɓ** |
| 设备折旧、厂区维修保养 | **0.36Ɓ** |
| 厂内仓储及出厂前物流 | **0.35Ɓ** |
| **合计** | **12.80Ɓ** |

在该估算模型中，**食品及饮品原料共9.30Ɓ（约72.7%）**，其余3.50Ɓ覆盖加工、设备、人工、包装及厂内物流。**“Пятнистый Толстячок（小肥牛）”快长型肉牛与多部位混合罐头有助于解释可供应规模**，但不是原料免费；牛里脊、饲料、畜牧维护和加工成本仍然真实存在。**4.10Ɓ的畜禽原料分项只是已纳入高采食量与短出栏周期等因素的核算模型参考，不是已测定的单头牲畜养殖成本**。

### 生产商如何在军购15Ɓ时获利

按生产成本约12.8Ɓ、军购15Ɓ计算，**每箱售价与生产成本差约2.2Ɓ，简化毛利率约14.7%**。大规模、稳定订单使工厂能组织采购、保持产线利用率，靠持续交付获取累计收益。**每百万箱的销售额约1,500万Ɓ、生产成本约1,280万Ɓ、差额约220万Ɓ**，但后续仍可能承担管理、财务、合同、税费及其他相关开支，**220万Ɓ不是最终税后净利润**。

### 为什么普通居民买一箱要33～40Ɓ

**33～40Ɓ是面向普通消费者的零售试吃价格，15Ɓ是军方大宗采购价格**，不是两个不同的食谱或品质等级。民用销售需要另外承担商业物流、门店仓储、零售经营与相应税费，也可能包含经销商利润和较小批量经营的成本。因此**民价可以显著高于军购价**，但**尚未确定各项民用渠道费用的正式具体数额**；不能直接用33～40Ɓ减去12.8Ɓ，推导某一家食品厂的实际净利润。

这一框架解释的是**多种产业与制度因素共同产生的低价**：上游农场可以获得较好的收购价，生产商通过规模化制造与集中合同获得利润，军队以大宗合同采购，民间又有独立的试吃零售市场。**不意味着萨德林所有农业原料、所有食品、全部税种或所有民用品都同样低价。**

## 采购价格、生产成本与民用流通

| 统计口径 | 价格／收益参考 | 说明 |
| --- | ---: | --- |
| **食品厂整箱生产成本** | **约12.8Ɓ** | 生产环节参考成本，非军方报价 |
| **军方整箱大宗采购价** | **15Ɓ** | 最新确定的军购价格 |
| **民用试吃整箱售价** | **33～40Ɓ** | **不变**；非军方购买的零售价区间 |
| **军购售价－生产成本** | **约2.2Ɓ／箱** | 简化毛收益空间，未扣除其他合同、管理、融资、税费及相关费用 |
| **军购简化毛利率** | **约14.7%** | 2.2÷15；按生产成本计算，不是净利润率 |
| **成本加成率** | **约17.2%** | 2.2÷12.8 |
| **民售价相对军购价** | **约2.20～2.67倍** | 33÷15至40÷15；不能据此直接推断厂方民售利润 |

**军购订单靠量赚钱：** 假定成本与售价保持在上述水平，食品厂**每交付100万箱，军购销售额为1,500万Ɓ，生产成本约1,280万Ɓ，二者差额约220万Ɓ**。这个差额**还不是最终净利润**，但大量稳定订单会扩大可供食品厂获取收益的总规模。这一机制符合既定的**食品厂通过走量获得丰厚累计收益**的设定，不另行编造补贴制度或固定销售合同量。

民用价格继续保留**33～40Ɓ一箱**，使普通居民有机会购买和品尝军用三日套餐。军方与民用在这里使用**同一基本套餐清单**，不自动设立民用缩水版。零售渠道可能涉及额外流通费用，**不能直接以33～40Ɓ减去12.8Ɓ来声称食品厂净赚的利润**。酒类销售适用所在地区的购买许可与年龄制度。

## 在萨德林军需体系中的定位

新版比此前的三日套餐**额外重视高能量、耐储食品与高寒作业所需的能量密度**。包装采用**外廓24L的保护外箱＋20L独立食品内箱**，层间设防震、防火、防水泡沫衬垫和冗余空间；整箱约6kg。士兵在三日突击包携行时，需要**拆掉外箱与必要的内箱分隔，逐件重新装包**，而不是背着完整双层包装行军。

由于新增大量不同类型食品、两包速食面与乳制品，后续如果设定更准确的产品标签热量、速食面净质量和包装保质期，应直接修订本条参数，而不是在旧版资料之外另建“未归档记录”。

## 与标准单兵三日套餐的区别

萨德林另有[《萨德林标准单兵三日套餐》]({{ '/articles/article-409/' | relative_url }})，与本高寒型**并行而非互相覆盖**。标准型以小黑椒土豆泥、酸菜、腌黄瓜、香肠、芝士黄油蛋糕、**两种米饭包和两种面条包**为核心，按照完整清单合计**三日约9,070kcal（平均3,023kcal／日）**、食品净重**2,934g**，拆箱携行约**3.4kg**、完整运输箱约**5.5kg**。

**加热燃料不可混写：** 标准型为**6块×25g＝150g**，本高寒型为**4块×55g＝220g**。两者虽均以**40×30×20cm**为给定外部尺寸，但标准型的**20L标称容量**目前并未明确采用本高寒型的**20L内箱、防护衬垫与24L外箱**同一结构。

**价格也不可混写：** 本高寒型正式成本约**12.8Ɓ**、军购**15Ɓ**、民售**33～40Ɓ**；标准型对应价格尚未确定。本高寒型约**14,000～18,000kcal**是根据同类食品估计的能量区间，**不是与标准型9,070kcal同样确定程度的产品标签**。
