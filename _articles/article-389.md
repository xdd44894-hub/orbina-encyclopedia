**“攀登”**是寰宇—深蓝[“全球攻势”]({{ '/articles/article-004/' | relative_url }})中的碎洋旧军事基地攻取行动。战役总体为**寰宇军事胜利**：寰宇突破外围海岸与山体防御，占领军事基地主要设施；但其试图在战争中完全掌握的秘密证据最终没有形成可公开控制的完整成果。

## 战区与交战目标

碎洋旧军事基地曾经承担公司战争时期的军事用途。全球攻势期间，深蓝在其周边部署**约8,000名武装安保参战人员**，基地内包含海岸工事、山体洞穴、防空区域和被称为“尖顶灯塔”的高层设施。

寰宇宣称深蓝在旧基地内秘密研制气象武器；深蓝则宣称这里是普通气象监测与军事驻防地点，指控寰宇觊觎战略位置。**深蓝曾在更早的“风暴眼”行动中实际使用A1104气象武器**，但这并不意味着外界在“攀登”开始时已掌握充分公开证据。

## 六个战斗阶段

| 阶段 | 战场特征 |
| --- | --- |
| **抢滩登陆** | 寰宇先取得通向岸线及登陆区域的通路 |
| **洞穴断层** | 战斗延伸到山体洞穴、地下空间和防御结构 |
| **海上炮轰** | 双方争夺沿海与山体外侧的火力控制 |
| **空中狗斗** | 战区空中力量交锋，支援地面推进 |
| **山谷攀升** | 寰宇沿山谷、高地与通道逐步接近上部设施 |
| **顶峰决战** | 战斗集中于尖顶灯塔及周边最后防区 |

作战最终使寰宇控制基地主要军事节点，深蓝驻防武装失去持续守住该基地的能力。**约8,000人是基地初始武装驻防规模，不是被歼灭人数**。

## 尖顶灯塔与“利剑”小队

战斗后期，寰宇**“利剑”小队**进入尖顶灯塔总裁室，发现深蓝气象武器的相关证据，以及[洛古里克遇害案]({{ '/articles/article-032/' | relative_url }})被掩盖的真相。洛古里克于**俄庇娜历134年**死亡，因此“攀登”发生在134年以后，也发生在“风暴眼”之后。

小队认识到自己获得的秘密足以使其无法安全回归原有组织，遂主动制造尖顶灯塔被导弹击毁和小队成员死亡的假象：一人携带证据跳窗成为外界追查的诱饵，其余人员经总裁室秘密电梯进入地下，在防空区域隐匿，战争结束后分别逃亡。

从人员进入总裁室到尖顶灯塔被击毁，外部记录约为**1分42秒**。灯塔实际遭寰宇一方的俄庇娜军团导弹打击；关于打击原因，寰宇曾依次以AI误判和深蓝干扰作为公开解释，**均不等于事件的完整事实**。残骸未发现该小队尸体。

## 战役投入、消耗与伤亡统计

### 统计范围与作战节奏

**人员身份口径：** [深蓝科技]({{ '/articles/article-040/' | relative_url }})**没有正式企业军队**，而是以“设施安保”名义**额外聘用了84万名武装人员**。本战役资料的“深蓝参战武装人员”指实际进入战区指挥体系的安保／其他武装参战人员，**不等于深蓝正规军，也不是84万人同时投入这一战役**。寰宇有自身正规作战部队；**交战人员伤亡、装备损失及七大战役已定数值保持不变**，仅修正深蓝人员的组织与聘用身份。

战区连续作战时段设为**24天**。下表为寰宇—深蓝两方的**战役期累计统计**，用于体现不同战区的战争规模与后勤负担；战役起止的俄庇娜历**绝对年份仍未确立**，此处不擅自指定具体开战年月日。战役发生地的地方警察、救援机构和不属于双方指挥链的军队，不直接计入企业军事人数。

登陆、山体洞穴、岸炮、空战与峰顶攻坚造成装备消耗的明显分段集中。海上与航空保障消耗已包含在燃油及保障经费统计内，绝非只靠118辆坦克就完成海岛登陆。

### 双方战斗编成与装备投入

| 指标 | 寰宇及受其指挥的参战力量 | 深蓝及受其指挥的参战力量 |
| --- | ---: | ---: |
| 战区累计参与参战武装人员（人） | **16,800** | **10,400** |
| 主战坦克累计入场（辆） | **118** | **84** |
| 其他装甲／履带车辆累计入场（辆） | **210** | **170** |
| 战区参战战斗机独立机体（架） | **64** | **47** |
| 战斗机出动架次（次） | **540** | **350** |

“参战武装人员”指整个战役先后进入本战区指挥体系的**不同人员累计数**，包含后方保障、轮换和增援，并非这些人一直同时处在前沿直接交火。“坦克入场”按**独立车体首次入场**计算，维修后再投入不重复登记。“出动架次”则每飞行一次计一次，故可以大于独立战机数。

### 装备不可修复损失与参战武装人员伤亡

| 指标 | 寰宇 | 深蓝 |
| --- | ---: | ---: |
| 参战人员阵亡（人） | **1,380** | **2,050** |
| 参战人员受伤（人） | **2,110** | **2,900** |
| 参战人员失踪、被俘（人） | **290** | **1,080** |
| **参战人员伤亡与失踪合计（人）** | **3,780** | **6,030** |
| 主战坦克不可修复损失（辆） | **29** | **34** |

| 战斗机不可修复损失（架） | **8** | **12** |

“不可修复损失”是经评估彻底报废或无法再恢复使用的装备，**不包括可在后方修复的临时故障、受损、维修轮换及短暂停飞**。失踪、被俘不全部等于死亡；受伤人员按本战役伤者记录，战役中重复就医不另记一次。上述人员统计不把独立民事灾害受害者混入参战武装人员名册。

### 弹药、无人平台、燃料与物资折价

| 指标 | 寰宇 | 深蓝 |
| --- | ---: | ---: |
| 火炮及迫击炮弹消耗（发） | **48,000** | **35,000** |
| 各型精确制导弹药消耗（枚） | **620** | **405** |
| 一次性任务无人平台消耗（架／套） | **600** | **420** |
| 全军航空、地面与支援燃料消耗（吨） | **12,400** | **8,300** |

军用物资折价按**已经消耗的弹药、燃料、毁损装备及现场保障物资**估算；**不含完整参战装备采购原值**，也不等于双方三年战争全部军费开支。被损毁装备在此按不可修复的残余／折旧状态估值，飞机或坦克的采购价不能简单乘以战损数量，再重复并入费用。精确制导弹药按一次投射消耗计算，无人平台统计不包含可以返回并再次出动的可回收机型。

### 既定事件与统计口径校正

既定的**约8,000名深蓝基地武装驻防人员**是战役开始时的守备规模；战区累计登记10,400名深蓝参战武装人员包括后续进入的约2,400名增援与外围支援，不能将其误写为基地最初就驻有10,400人。深蓝1,080名失踪或被俘人员不等同死亡。**“利剑”小队伪造阵亡**，不计入实际战死数字；尖顶灯塔遭到的导弹打击包含在精确制导弹药消耗中。


## 战役结果

| 项目 | 结论 |
| --- | --- |
| **军事胜者** | **寰宇**，控制基地主要军事设施 |
| 深蓝损失 | 失去碎洋基地的主要阵地和该处继续驻防的能力 |
| 关键设施 | **尖顶灯塔毁灭** |
| 秘密事件 | “利剑”小队伪造死亡并转入隐匿状态 |
| 战略后果 | 寰宇取得地理和军事节点，但未能以官方调查完整控制相关秘密 |

“攀登”因此是一场**军事结果与情报结果明显分离**的战役：公开战争史中胜负较清楚，真正影响后续历史的秘密证据却流出了正常组织体系。
