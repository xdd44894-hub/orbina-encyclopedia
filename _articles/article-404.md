**战役集合群**，简称**战集群**或**集合群**，是俄庇娜少数军事规模足够庞大、具备跨军种联合指挥能力的主要国家在战争时期设立的**战役级联合军团编制**。它的位置为**集团军之上、战区之下**，专门统合一个战略方向上多个集团军的战役行动。

战役集合群**不是平时常设的超大型集团军**。平时依托**地区预编指挥机构**储备人员、规划、通信与协调机制；战时根据战略方向和战争需要，转入正式的战役集合群指挥状态，整合指定集团军及其联合支援单位。

## 使用国家及适用范围

此类编制只适合**极少数国家级军事强权**，并非俄庇娜所有国家、企业、佣兵组织或地方自治武装的通用编制。当前明确可采用此层级的**代表性国家**包括：

- **[赤垩天共和国]({{ '/articles/article-008/' | relative_url }})**；
- **[萨德林共产乌托邦共和国]({{ '/articles/article-008/' | relative_url }})**；
- **[联合城联邦]({{ '/articles/article-007/' | relative_url }})**；
- **人民天国**。

以上是已明确的主要使用国示例，**不能据此推定全世界只有这四国绝对有资格**；其他极少数具备相应国家级军事力量、战区控制和联合保障能力的主要大国也可能采用。对未明确设定的国家，不默认其存在战役集合群编制。

**重要边界：** [寰宇重工]({{ '/articles/article-009/' | relative_url }})虽拥有**4个各15万人的顶尖重装合成集团军**，但这并不自动使其获得国家级战役集合群编制。集团军数量满足“3～5个”的典型指挥对象规模只是**必要条件之一，不足以证明具备国家级战区授权与联合军种指挥权**。[俄庇娜军团]({{ '/articles/article-011/' | relative_url }})总规模庞大，也不因拥有众多战斗单位就成为可自设国家级战集群的主权军队。企业、佣兵在国家战役中可以作为合同或配属力量参加，但不能凭名称或兵员数量自行升格为正式战役集合群。

## 编制层级与指挥关系

| 项目 | 正式定义 |
| --- | --- |
| **正式名称** | 战役集合群 |
| **简称** | 战集群、集合群 |
| **层级** | **战区之下，集团军之上** |
| **组织性质** | **战时按照战略方向组建的战役级联合军团** |
| **平时状态** | **不常设**；由地区预编指挥机构准备相关指挥资源 |
| **战时状态** | 地区预编指挥机构转入正式战役集合群指挥体系，接管指定部队的战役协调 |
| **典型下辖** | **3～5个集团军**，外加必要的直属／配属联合支援单位 |
| **核心任务** | 统合一个战略方向内多集团军的战役行动 |

基本军令传递层级：

**战区 → 战役集合群 → 集团军 → 集团军下辖作战编制。**

这说明**战役集合群是指挥与协调层级，不是把三个集团军重新改称一个“特大集团军”**。所辖集团军继续保留各自的编制、指挥机构、兵种与建制保障系统，战集群负责其共同战略方向上的战役统合和跨军行动协调。

战区可同时设若干战役集合群，分别负责不同战略方向；**具体设立数量、名称和番号必须依据战争需要**，不以平时的固定常备军总数机械推算。

## 战役集合群主官与机关

| 主官／机关 | 标准配置 | 主要职责 |
| --- | --- | --- |
| **司令员** | **中将** | 指挥整体战役行动，负责跨集团军任务部署与行动协调 |
| **政治委员（政委）** | **中将** | 负责政治工作、组织纪律、人员动员和战役政治保障 |
| **参谋长** | **少将** | 统筹联合参谋工作、战役计划与命令执行协调 |
| **联合参谋部** | 设立 | 战役筹划、态势维护、多集团军计划衔接与联络 |
| **联合火力中心** | 设立 | 协调地面、空中及必要的海上／其他已获授权火力 |
| **后勤保障中心** | 设立 | 跨集团军供给、运输、维修、医疗后送与资源分配 |
| **情报与电子对抗中心** | 设立 | 综合侦察、情报研判、电磁态势和电子对抗任务协调 |

**司令员中将、政委中将、参谋长少将**属于本编制已确定的标准主官配置。不同国家是否在本国行政语境使用相同的译名、礼仪及政工制度属于制度适配问题；**不能擅自把政委删除或将司令员改成其他将官等级**。

## 典型下辖与直属支援

| 编制单位 | 典型数量 | 性质与作用 |
| --- | ---: | --- |
| **集团军** | **3～5个** | 战集群主要地面作战兵力；各集团军仍保持自身内部编制 |
| **陆航／航空旅** | **1个** | 为战集群提供机动、侦察、支援及与空中体系的战役协同 |
| **远程火力旅** | **1个** | 战集群集中掌握的战役纵深火力与火力分配能力 |
| **防空反导旅** | **1个** | 重要区域、战役机动走廊和高价值节点的防空反导协调 |
| **无人作战旅** | **1个** | 组织战役级无人系统的侦察、支援及其他获授权任务 |
| **电子对抗与网络战大队** | **1个** | 电子对抗、网络任务协调和相关技术保障 |
| **工程与防化旅（工化旅）** | **1个** | 战役工程、通路保障、防化防护和灾害环境任务 |
| **勤务支援旅** | **1个** | 战役层级综合勤务、供应与后勤支援 |
| **空军代表** | **视任务配属** | 与国家空军建立战役联合协调和授权联系 |
| **海军代表** | **视任务配属** | 适用于滨海、海峡、岛屿与其他需要海空地联动的战区 |

上述为**典型编制**而非每一场战争都强制采用完全相同的实际兵力表。是否同时拥有这些单位、配属人员数、装备规模和任务时长，依战略方向及上级战区命令确定。

**直属旅与配属代表不包含在3～5个集团军的数量中**，但也不能默认所有旅都完全脱离原部队而成为永久的战集群直属常备部队。战时可以由现有军种力量指定配属，战后按原军事制度调整或撤销临时指挥关系。

空军、海军代表可以参与联合计划与火力协调，**不意味着战役集合群仅凭代表在场就自动取得整个空军或海军的无限指挥权**。实际部队转隶、支援关系、战略武器使用和战区界线仍服从国家及战区授权。

## 核心任务与战区级区别

战役集合群的职责主要是将一个战略方向内分散的集团军作战计划，统一为能互相衔接的**战役进攻、战役防御、联合火力、战役机动和长期保障行动**。

- **跨集团军协同：** 协调不同集团军的战役目标、攻防节奏、侧翼衔接与后续增援。
- **联合火力打击：** 由联合火力中心整合可用的远程火力，并与经授权的空中、海上等军种火力协调。
- **战役后勤统筹：** 按整体战略方向安排补给、维修、医疗、运输与物资优先级，不要求每个集团军各自孤立保障。
- **情报与电子对抗：** 将多个集团军及联合单位的情报需求、电子对抗任务和相关数据联系起来。
- **空地海联动：** 通过配属及联络机制，使地面主要兵团行动与空军、海军实际任务衔接。

**战区**负责更高层的整个战区战略部署和多个战略方向之间的资源与任务分配；**战役集合群**负责其中一个战略方向的多个集团军及配属力量协调；**集团军**负责其本级所辖师旅和直属火力与保障单位的具体作战。三者**不是同一层级的不同名字**。

## 人数、战役结束与统计约束

由于不同国家的集团军规模、兵种占比及装备结构并不相同，**战役集合群不设全球统一的固定总人数**。不能把[寰宇重工]({{ '/articles/article-009/' | relative_url }})单个**15万人的重装合成集团军**直接当成联合城、赤垩天、萨德林或人民天国所有集团军的共同人数标准，再机械计算每个战集群有45万～75万人。

战集群的总兵力取决于**实际纳入的3～5个集团军及直属／配属部队**；其中人员数量应避免重复计算从集团军临时配出的旅、航空单位或保障分队。

因为它是**战时成立的指挥结构**，战役结束或战略方向调整后，联合单位与相关军令关系可以解除或重新配置；地区预编指挥机构也可恢复平时状态。这与国家永久存在的战区和集团军常备编制有明确区别。
