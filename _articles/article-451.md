# 藏朔原语 Žaġręn

**扎格伦语 · 统一语言总纲 · 语言阶段 V0.6 · 字典版本 V0.2**

藏朔原语是俄庇娜世界的斯拉夫语后裔语言家族，由旧地球俄语移民语言及其他斯拉夫方言长期接触，经过定居藏朔原后的独立音变、词汇演进、方言分化与再接触而形成。**它不是现实语言 Slovio，也不是通过特殊字符替换得到的俄语。**

本条是**现行规范唯一总入口**。早期形态学和原始比较词汇仍保留为历史语料；只要 V0.6 与旧版出现词形冲突，先查本条的书写规范与 [V0.2《扎格伦字典》]({{ '/zagren-dictionary/' | relative_url }})，再查原始屈折格位，不能混为同一历史时段。未完成验证的格尾、重音或现代动词系统不会被擅自宣称已完成。

## 二、方言与历史层次

| 简写 | 中心方言（本地名称） | 分布 | 保留和创新特点 |
| --- | --- | --- | --- |
| **N** | 珀璃璐卡 **Pęrlÿkań** | 北部 | 软化、鼻化、音节前化和局部送气创新 |
| **SE** | 丽庞萨 **Lipańsë** | 东南 | 去鼻化、辅音融合、部分元音央化 |
| **W** | 雷西尼昂帕 **Reśinąmp** | 西部 | 深舌侧音、摩擦化、词尾脱落与高频缩略 |

三地来自共同的 **Proto-Žaġręn（原始藏朔原语）**，重建词根用星号 `*` 标注。藏朔原**没有统一官方语言**；这三种是主要中心方言，并不排除地方过渡方言及其他语言。

演化顺序是“重建祖语 → V0.1–V0.5所描述的早期方言 → V0.6现行词典原形与新增规则”。V0.5 以古早期文本作为对照，不为迎合 V0.6 倒写历史。

## 四、正式语用标点

| 符号 | 名称 | 固定意义 | 作用范围 |
| --- | --- | --- | --- |
| **§** | 郑言符 | 郑重、庄严或慎重地发言；**并不自动表示大声** | 放在发言文本前。有引号时至闭引号；无引号仅下一句 |
| **¡** | 轻惊符 | 小惊、意外察觉 | 句末独立语气终止符 |
| **¿** | 微疑符 | 微微疑惑或试探性发问 | 句末独立语气终止符 |
| **！** | 大惊符 | 强烈惊讶或震动，强度不等于响度 | 句末独立语气终止符 |
| **？** | 正疑符 | 标准疑问 | 句末独立语气终止符 |
| **•…•** | 聚焦符 | 左右成对包围句子重点 | 不可自身嵌套 |
| **/…\\** | 文引符 | 引用已写下的文字，不表示人物正在说话 | 斜杠开头、反斜杠结尾，不能自身嵌套 |

四种句末语气符号（¡、¿、！、？）**一句四选一**；平叙句用普通句号。§可和句末语气、•…•组合。标点不是词汇，也不进入IPA读音。

**合法组合：** `Mať ġoŵorit: §“Mÿ še imame •ӧġń•！”`（母亲郑重而惊讶地强调“火”）。

**文引：** `Na liste: /ӧġń\\.`（纸面文字“火”被引用，不表示有人说出这个词）。

## 五、V0.6音变：共同创新与三地差异

共登记 **21** 条现代演化规则，包括高频词缩约、鼻音融合、局部软化、尾音脱落等；音变只在声明的词类、词根和语音环境中有效。不得把它们当成对所有旧词无条件使用的机械替换。

| 编号 | 适用地域 | 规则说明与示例 |
| --- | --- | --- |
| **C01** | 三地 | 词根内部 /l,ɫ/ + 弱读 /o/ + /k,d/ 的元音脱落；ħolod→ħold / holod→hold / ħołod→ħołd；moloko→molko |
| **C02** | 三地 | 边界类派生词中 -nic(a) / -nic 失去弱读 i，成为 -nc(a) / -nc；ġranica→ġranca；granica→granca；ġranic→ġranc |
| **C03** | 三地 | 高频弱读副词 ešče 的 e- 脱落及 šč > š 合流；ešče→še |
| **C04** | 三地 | 高频风词词干末 -etr > -er（/t/ 在复杂韵尾中脱落）；ŵetr→ŵer；vetr→ver |
| **N11** | 北部 | 词首 /sne/ > /sę/（鼻音失去辅音地位，元音鼻化）；sneġ→sęġ |
| **N12** | 北部 | 历史软音节尾触发 /o/ 前化为 /ø/，后经类推推广到全词干；oġń→ӧġń；kośť→kӧśť |
| **N13** | 北部 | /ʒ/ 在后接 /e,i/ 环境软化成 /ʑ/，写ẑ；železo→ẑelezo；žiŵot→ẑiŵot |
| **N14** | 北部 | 历史 /tʲr/ > /tʰr/；新增字母 ṱ = /tʰ/，区别于 ť、t；ťruba→ṱruba；ťrubu→ṱrubu |
| **N15** | 北部 | 高频中性时间词 utro 末尾 -o 弱化脱落；utro→utr |
| **N16** | 北部 | 新祖语软化辅音 /kʲ,rʲ/ 后 /u/ 前化为 /y/，写 ү；*kʲuta→ǩүta；*rʲud→rjүd |
| **N17** | 北部 | 新祖语 *kʲ > ǩ，*dj > ď，*rʲ > rj；*kʲel→ǩel；*medja→meďa；*rʲud→rjүd |
| **SE11** | 东南 | 词首 /sne/ > /se/，失去鼻音但不保留鼻化；sneg→seg |
| **SE12** | 东南 | /z/ 在 /i/ 前软化为 /ʑ/，写ẑ；zima→ẑima |
| **SE13** | 东南 | /o/ 在 /l/ 之前于指定词根中央化为 /ɵ/，写ȯ；holod→hȯld；moloko→mȯlko |
| **SE14** | 东南 | /gn/ > /ŋ/ 写ң；旧 ogon 经次音节脱落 ogn 再同化；jagne→jaңe；ogon→ogn→oң |
| **SE15** | 东南 | 新祖语 *kʲ > ć，*dj > җ，*rʲ > r；*kʲuta→ćuta；*medja→meҗa；*rʲud→rud |
| **W11** | 西部 | 词末 /ɣ/ 在元音之后脱落（词中、带词尾时不自动脱落）；sneġ→sne；boġ→bo；droġ→dro |
| **W12** | 西部 | /r/ 在 /θ/（þ）后强化为 /r̝/，写ř；þrub→þřub |
| **W13** | 西部 | 词首 /ʒeɫ/ > /ʒɫ/ 的弱元音脱落；žełez→žłez |
| **W14** | 西部 | 新祖语 *kʲ > ǩ，*dj > ẑ，*rʲ > ř；软化辅音后u > ү；*kʲuta→ǩүt；*medja→meẑ；*rʲud→řүd |
| **W15** | 西部 | 沿用V0.5既有W09：多音节实词非重读-a词尾脱落；*kʲuta→ǩүt；*medja→meẑ |

**新增高频百词**遵从已知祖语音变基础，并对部分极高频功能词采用逐词登记的历史短化；这些短化并非额外一套无条件通行的音变规律。具体音节串与源词见 [百词数据库]({{ '/assets/data/zagren-core100-v06.json' | relative_url }})。

## 七、词法和句法的共享骨架

### 名词、代词

保留 **阳性／阴性／中性**、**单数／复数**、**主格 NOM／属格 GEN／与格 DAT／宾格 ACC／工具格 INS／处所格 LOC** 六格，有生性影响特定宾格。旧研究中14个代表名词和7组人称代词拥有完整三方言格位，并有不规则亲属名词。

### 动词

保留未完成体（IPFV）与完成体（PFV）对立；历史体系已记录非过去时六个人称数位置、过去式四个性数位置、祈使形、条件式和未完成体分析式将来。旧版36个动词中包含4种不规则高频动词，其原有格位应通过V0.6限定音变逐项复核，不直接批量重写。新25个高频动词本轮仅登记不定式原形和体。

### 形容词和分词

历史第四卷有44个形容词、20个分词、9,360个三方言屈折格位；规则包括性数格一致、性质词比较级和动词分词。新增15个形容词仅登记阳性主格原形，不据此宣称其他性数格均已审定。

### 程序支持范围

[语法实验室]({{ '/zagren-grammar/' | relative_url }})能使用旧版有据可查的 **2,025个名词、代词和动词格位**，并对V0.6已备案词根执行限定音变；它不等于全语言的自由造句器。词典条目可以查原形，但新100词的全部格位尚未生成。

## 共同复合词与语言文化

“骨”来自祖语 `*kosʲtʲ`，“山”来自 `*gora`；两者结合，形成与藏朔原历史神明**曲韦钟（戴勒·特尔维拉）**有关的地方用语：

- 北部：**Kośťġora**
- 东南：**Kośćgora**
- 西部：**Koštġor**

可译为“尸骸之山”，既可作为形态清晰的普通复合词，也进入与曲韦钟有关的历史传闻。[曲韦钟]({{ '/articles/article-450/' | relative_url }})一条记录其生理死亡后意识仍驱动尸骸山、羊叫声与羊头异常目击等内容。

现代藏朔原的RDE工业、部族礼仪与冻土生活，将在语域词典中继续积累各自的借词与语义变化。部族名 **Pęrlÿkań / Lipańsë / Reśinąmp** 是现阶段使用的地方语言自称拼写，民族名称仍以中文既定名称为准。
