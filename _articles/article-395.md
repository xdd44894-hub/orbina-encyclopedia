**世纪大厦**是位于**联合城旧核心城区**的一座大型综合商业及办公高层建筑，也是寰宇—深蓝三年战争[“全球攻势”]({{ '/articles/article-004/' | relative_url }})中的[“回响”战役]({{ '/articles/article-387/' | relative_url }})最具代表性的重大民用建筑损毁事件发生地。

在“回响”战役中，**深蓝实际使用强震装置，使世纪大厦灾难性倒塌，造成约3,000人死亡**。这是已确定的历史事件真相，不是普通自然地震，也不是寰宇制造的假旗事件。深蓝在公开宣传中否认承担责任并指控寰宇捏造所谓地震武器；**战时公开说法和实际事件原因必须区分**。

## 建筑概况与规模

| 项目 | 世纪大厦正式建筑参数 |
| --- | --- |
| 所在地区 | **联合城旧核心城区** |
| 建筑性质 | **综合商业、办公与交通衔接型高层建筑** |
| **建筑总高度** | **约338m**，包含屋顶构筑部分 |
| **地上楼层** | **82层** |
| **地下楼层** | **6层** |
| 建筑总面积 | **约386,000m²（38.6万m²）**，含地下部分 |
| 建筑用地 | **约32,000m²（3.2公顷）** |
| 结构类型 | **钢结构外围框架与钢筋混凝土核心筒组合的高层结构** |
| 商业裙房 | **地上8层**，与主体建筑及公共通道衔接 |
| 主要用途 | 企业办公、商业零售、会议会务、餐饮、设备与通信服务 |
| 平常工作日日间使用及往来人流 | **约15,000～20,000人次／日**，包括访客和换乘人流，不等于同一时刻人数 |
| 满负荷综合承载能力 | **约17,000人**，包含不同楼层的实际使用限额 |
| 原工程建造成本 | **约165亿Ɓ**，含主体建筑及基础机电设施 |
| 战时结局 | **主体结构灾难性倒塌，完全丧失正常使用功能** |

世纪大厦是旧核心城区的重要民用地标，而不是寰宇重工总部或专门军事基地。楼内既有公司租户，也有餐饮、零售及面向公众开放的服务场所。**不能将楼内全部人员都算作寰宇军人、深蓝雇员或武装人员**。

### 建筑空间分布

| 区域 | 主要功能 |
| --- | --- |
| 地下6～2层 | 停车、地下装卸、后勤设备及附属设施 |
| 地下1层 | 地下公共通道与城市交通接驳空间 |
| 地上1～8层 | 商业裙房、公共服务、餐饮、展厅及通行大堂 |
| 地上9～45层 | 多家企业的办公及商务服务 |
| 地上46～73层 | 高层商务办公、会议与专业服务 |
| 地上74～82层 | 高区办公会议、公共观景及建筑设备配套区 |

这些楼层分区是**建筑的通常功能布置**，并不代表所有楼层在战役爆发时仍正常营业；也不意味着一座大厦内的全部企业在政治上属于同一阵营。世纪大厦可以衔接旧城区道路与地下公共交通，但**不把它虚构成控制整座联合城地铁系统的唯一枢纽**。

## “回响”战役前的地位

在全球攻势爆发前，世纪大厦承担典型的城市综合体职能：企业办公、商业往来、人员通行和部分社区公共服务依托它运转。楼宇内部的租户、工作人员与访客来自不同企业与社会阶层，附近还分布有旧城区住宅、道路、公共设施和其他商务建筑。

正因为高度集中了商业使用与公共往来人流，这座建筑的倒塌造成的后果远超单纯失去一栋办公楼。建筑下方和周边的道路、地下连接空间与城市管线也面临严重次生损害。

## “回响”战役与倒塌事件

### 攻防关系及事件原因

在“回响”战役中，**寰宇为防守方，深蓝为进攻方**。深蓝从联合城旧核心城区多个方向向寰宇防线进攻，世纪大厦所在区域处于交战影响范围。**战事发生于联合城，不等于联合城国家军队作为一个整体直接同深蓝开战**。

深蓝实际动用了**强震装置**，使世纪大厦遭受灾难性结构破坏并倒塌。这里确定的是**强震装置的使用、世纪大厦倒塌以及约3,000人死亡的因果联系**；并不将它写成自然地质灾害，也不额外编造装置的具体部署位置、运作原理、操作口令或型号结构。

### 指挥官的两次喊话

早期战役记录保留了现场指挥官在倒塌前的紧急疏散喊话：

> “不好！快散开！别管装置了！强震来袭！大楼要塌了！”

世纪大厦倒塌、导致约3,000人死亡后，指挥官又以阵亡同伴动员部队反击：

> “你们的脚下埋着你们的战友！怎能让敌人继续践踏他们！统统给我上！杀光那些杂碎！”

这两段话表现了**灾难发生时的应急与战场情绪**，不意味着死者全部为军人。第二段属于战争中的指挥官动员言论，不作为大厦死者身份的统计依据。

### 倒塌与即时后果

世纪大厦的主要上部结构丧失整体使用能力，坍塌和碎片波及相邻道路、建筑外立面、地下出入口及城市公用设施。局部区域交通中断，应急人员需要先确认通行与后续危险，再逐步进入废墟开展搜救。

在民用与军事行动交叠的城区，撤离、战场通讯、伤员转送和后续反击都受到建筑损毁影响。寰宇最终守住旧核心城区的主要军事节点，但这一**战术防御胜利**不能消除世纪大厦及周边的人员损失。

## 灾难统计与经济影响

以下数据为该事件的建筑与周边直接影响，不等同**整个“回响”战役**的人员伤亡。约3,000人死亡是先前确定的历史事实；其余建筑与灾后统计系对世纪大厦事件的正式新增设定。

| 项目 | 灾难与损失统计 |
| --- | --- |
| **直接死亡** | **约3,000人**，世纪大厦倒塌事件造成 |
| **受伤人数** | **约6,800人**，包含大厦及邻近受波及区域 |
| 死亡及受伤合计 | **约9,800人**，两类统计不重复 |
| 周边临时疏散与封闭区撤离 | **约24,000人**，不是新增伤亡人数 |
| 大厦主体状态 | **无法修复后恢复原有整栋建筑功能** |
| 建筑主体、固装设备及内部物业重置损失 | **约230亿Ɓ** |
| 邻近建筑及交通、公用设施直接修复损失 | **约58亿Ɓ** |
| **直接财产与设施损失合计** | **约288亿Ɓ**，不含全部企业停业、医疗与长期社会损失 |
| 旧城区主要临近道路的紧急封控 | **约11天**，其后分阶段恢复部分通行 |

**约6,800名伤员包含邻近建筑及周边受灾人员**，不能全部理解为倒塌瞬间位于世纪大厦内部。约24,000名撤离人员可能包含受伤人员，也不能与9,800人直接相加。总建筑面积是工程面积而不是一次坍塌时的人员数量，楼宇设计承载能力也不是实际在场人数。

约230亿Ɓ指建筑及其固装资产在战争损坏时的重置与财产损失口径，**不是165亿Ɓ原建造成本的重复统计**；两者对应不同时间和价格概念。邻近58亿Ɓ为另一组直接损害；企业经营停摆、救援医疗和长期城市修复成本尚未全部计入。

## 两套不同的战时宣传叙事

### 已确定的实际原因

**深蓝强震装置实际震塌世纪大厦**，造成约3,000人死亡。它既不是自然地震偶然撞上战役，也不是由寰宇制造的假旗事件。

### 深蓝的公开指控

深蓝否认或转移自身责任，指控寰宇刻意制造假旗事件，通过世纪大厦倒塌诬陷深蓝拥有所谓的“地震武器”，试图借此争取政治和舆论优势。

### 寰宇的公开指控

寰宇声称深蓝围绕经营权与商业利益发生争执，因竞争受挫而恼羞成怒，最终主动发动战争并导致世纪大厦惨剧。

双方公开宣传并非同样可信的事件真相：**深蓝强震装置导致倒塌属于已确定的实际历史；双方关于整个战争起因与商业责任的表述仍须与具体行动证据分开判断**。

## 战后的历史地位

世纪大厦成为全球攻势中企业战争波及高密度民用城市空间的标志性事件。它在军事上不是决定整场战争输赢的唯一目标，却成为“回响”战役最具社会记忆的伤亡事件之一。

大厦主体已无法恢复原有建筑功能，周边公共交通、地下设施与建筑废墟需要长期清理和修复。其原址最终是重建为相同规模大厦、保留纪念设施还是改作其他公共用途，**不因“回响”由寰宇守住城区而自动决定**。
