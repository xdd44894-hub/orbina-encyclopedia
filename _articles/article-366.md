Pck-35是寰宇重工自主研发的突击步枪，主要装备寰宇自身武装体系。

## 定型参数

| 项目 | 参数 |
| --- | --- |
| 工作原理 | 导气式、旋转闭锁枪机 |
| 射击模式 | 半自动／全自动 |
| 弹药 | 7.62×45mm |
| 通常使用弹匣 | 35发 |
| 其他兼容弹匣 | Snp-762的12发弹匣 |
| 拉机柄 | 枪身左侧独立设置 |
| 空仓挂机 | 支持 |
| 枪管长度 | 420mm |
| 枪全长 | 900mm，枪托展开状态 |
| 空枪质量 | 3.7kg，不含弹匣及光学配件 |
| 自动射速 | 650发／分钟 |
| 100m机械支撑散布精度 | 2.5 MOA，标准测试弹条件 |
| 实用有效射程 | 450m，典型单兵目标 |

有效射程在实战中受环境与射手条件影响。

## 弹道与综合作战评价

代表性定型参考弹道为7.62×45mm弹药、8.6g弹头、750m/s枪口初速，枪口动能约2.42kJ。不同弹种、制造批次及环境可产生差异，不是每种弹药的绝对常数。

其综合作战威力为旧地球7.62×39mm参考体系的2.1倍，包含射击精度等因素，不是枪口动能或每发子弹物理伤害的倍率。评价公式、测试场景、距离与权重尚未明确，不能从倍率反推初速或装药量。

## 系列兼容与外形

与[Snp-762]({{ '/articles/article-367/' | relative_url }})共用弹药和弹匣接口，但不代表内部零件全部通用。35发弹匣装满后重量和下伸长度较大，12发短弹匣在有支撑射击中更便于避让下方空间。

外观主要为深色枪身、红色局部发光线条和明显弯曲的弹匣。发光线条的用途及是否属于电子系统尚未确定，不能据此赋予激光武器或弹药加速功能。
