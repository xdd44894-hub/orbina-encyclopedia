**和声-1M**是一种中型双发涡桨特种任务飞机，统一承担**空中预警、电子支援／电子战、战场广播及通信中继**等任务。它采用成熟发动机改型与模块化电子任务舱，在有限的机体重量、供电、散热与天线空间内，通过射频资源调度实现多任务切换。和声-1M不是专门的超大型预警机，也不是单纯的电子干扰机。

起降场长是**设计参考值**，不是对高温、高海拔、湿滑跑道或单发失效时的无条件保证；实际飞行应按重量、气压、温度、风场与跑道状态确定使用限度。长翼展有利于滞空效率，但大面积雷达罩和外挂电子吊舱产生额外阻力，最高速度和续航不能全部同时达到。

发动机被描述为成熟型号改型，不代表具有某个尚未确定的现实制造商或发动机型号。经济巡航的平均燃油消耗在最长续航条件下约处于**600～650kg/h级（双发合计的任务平均参考）**，满功率电子任务和高速转场时消耗更高；这不是所有飞行高度均适用的恒定油耗。

## 电力、冷却与任务舱

| 系统 | 正式参考配置 |
| --- | --- |
| 主发电机 | **双路各约250kVA**，由两台发动机分别驱动 |
| 任务系统可用连续电功率 | **约200～240kW**，随环境与机体用电优先级调整 |
| 任务电子设备常见总电功率 | **约120～180kW**，视模块与工况变化 |
| 任务系统液冷散热能力 | **约170kW级连续热负荷处理能力**，峰值须受限 |
| 供电冗余 | 双发电路隔离、重要任务负载分级切除、独立应急电源 |
| 主腹部模块化吊舱 | 通常**约1.1～1.4吨级**，计入任务载荷 |
| 翼下轻型吊舱挂点 | **2处**，单处任务吊舱通常不超过**约400kg** |
| 任务舱布局 | 可更换射频／通信设备机架；保留独立供电、冷却与检修通道 |
| 八人舱内保障 | 增压、通风、操作员座椅与安全约束装置，长航时基本饮水及卫生保障 |

外挂吊舱、内部可更换机架和其他任务模块的**合计质量**仍受4吨任务载荷上限约束。翼尖ESM吊舱属于已计入基线的固装系统，不再重复占用翼下两处轻型挂点。

主发电机的铭牌视在功率（kVA）不能简单视为可完全分配给任务电子设备的有功功率（kW）；需先满足基本飞行、液压、环境控制与配电损耗。预警雷达、大型电子战吊舱及广播系统存在发射功率与热负荷冲突，频谱管理员和设备保护逻辑可以要求降级或暂缓工作，不能在未满足散热限制时强制持续全功率运行。

## 机体外形及设备位置

### 侧面布局

- **机头下方**：光电／红外转塔，用于目标辅助识别及任务态势观察。
- **机背**：长度约**9～10m**的平衡木式AESA雷达罩，自驾驶舱后方延伸至机翼后缘附近。
- **机身两侧**：较长的共形天线整流罩，布置电子支援测量（ESM）、VHF/UHF定向广播阵与数据链相关设备。
- **机腹中央**：大型可更换的模块化电子战吊舱，可根据任务选用通信干扰、雷达干扰或通信中继模块。
- **机翼下方**：预留**2个轻型吊舱挂点**，可接入额外电子任务吊舱。
- **尾锥**：可收放式拖曳HF天线，用于短波广播和中远程通信中继。
- **机腹后段**：液冷系统和电源相关整流罩。

### 顶面与正面辨识

翼展为33.5m，**两侧翼尖各装有1个ESM电子侦察吊舱**；这两个翼尖设备与翼下两个轻型吊舱挂点分别计算。较窄的机背平衡木雷达在左右方向**每侧约覆盖120°**，前后仍有覆盖盲区；飞机通过盘旋任务航线、机动调整和友方数据链补盲，**不因此获得360°连续、等效性能的本机探测能力**。

机身侧向共形阵列较长，能够支持定向广播与电子支援；机翼外段可布置少量刀形天线，但须兼顾气动与机体结构。正面轮廓由**上单翼、双发涡桨、机背长雷达罩、机腹任务吊舱以及翼尖ESM吊舱**共同构成。整体外观接近中型军用特种任务／运输平台，而非小型公务机。

## 三大任务系统

### 一、空中预警与电子支援

机背9～10m平衡木式AESA负责空中、海面搜索和航迹跟踪、目标指示；翼尖ESM承担无源射频侦收与辐射源定位，机头光电／红外转塔辅助识别。飞机同时具备敌我识别（IFF）、数据链与卫星通信。

和声-1M的预警性能定位处于**大型专用预警机和战术补盲平台之间**：具备较强的区域监视与任务指挥支援能力，但不按E-3、E-2一类专用预警系统的整体性能设定，也没有无条件全向覆盖能力。不同目标类别下的标称探测距离与航迹容量见下文，实际探测效果受到目标特征、背景杂波、飞行高度和电磁环境影响。

### 二、电子战与电磁对抗

- 机翼尖端ESM设备首先提供被动射频侦察信息。
- 机腹可换任务吊舱执行通信干扰、雷达干扰或欺骗干扰任务。
- 数字射频存储技术（DRFM）能够参与电子欺骗，形成假目标或模拟通信活动。
- 机翼下两个轻型挂点预留额外干扰／电子任务吊舱接口。
- 本机**不预设内置超大功率、可永久持续全功率工作的干扰机**；设备功耗与热负荷通过吊舱模块化、时间调度和任务模式管理控制。

电子战效能依赖具体任务吊舱、工作环境、频谱冲突和友军协同，不意味着单架飞机能够同时压制所有频段、所有目标。

### 三、广播与通信中继

机身两侧的**VHF/UHF共形定向天线阵**可用于战场喊话、应急播发及通信中继；尾锥拖曳式**HF天线**用于短波广播和中远程通信中继。HF属于**高频（短波）**，仅是相较VHF/UHF工作频率更低，不应将HF错误写成LF低频波段。

必要时可加装短偶极或刀形FM天线，实现区域调频应急广播；但受到机身长度、天线效率、发射功率与供电约束，不能视为地面大型高功率广播台的等效替代品。

支持多语种预录语音与文本转语音播发。**对外广播内容和播发决策由广播操作员控制，不存在无需人员授权的全自主AI播发制度**；智能系统可以在授权范围内承担文字转换、队列与技术辅助。

## 任务电子设备标称性能

以下数据均是和声-1M在俄庇娜设定中的**典型任务条件下的设计标称值**，并非在全部气象、电磁条件及全部目标上同时保证可实现的极限指标。

### 机背AESA与态势显示

| 项目 | 正式参考性能 |
| --- | --- |
| 平衡木雷达罩长度 | **约9.5m**，处于既定9～10m范围内 |
| 雷达阵面布置 | 左右侧向固定AESA阵面，合成侧向主搜索能力 |
| 本机方位覆盖 | 左右**每侧约120°**；正前和正后仍有盲区 |
| 高空大型目标标称发现距离 | **约290～350km**，有利探测条件 |
| 常规战斗机目标标称发现距离 | **约160～230km**，有利探测条件 |
| 低空旋翼／小型低空目标 | **约55～105km**，显著受地杂波、遮蔽及目标特征限制 |
| 同时管理的融合航迹 | **约180条** |
| 重点连续监视目标 | **约48条**，不等于另加48条独立航迹 |
| 常规更新周期 | **约5～12秒级**，视扫描扇区和优先级变化 |

“发现距离”不是稳定识别距离，更不代表武器能够在该距离直接攻击；一架飞机也不可能通过几组数字覆盖所有目标雷达散射特征。对海搜索在不同海况和目标尺度下单独受限。前后盲区通过飞机转向及友方情报补充，但不形成真正360°同步本机雷达能力。

### ESM、光电与通信

| 项目 | 正式参考性能 |
| --- | --- |
| ESM配置 | 双翼尖吊舱＋机身共形接收阵协同 |
| ESM态势管理规模 | **约120个已分类辐射源条目**，实际源区分能力受信号拥挤度影响 |
| 有利接收条件下的单次测向参考误差 | **约1.5°～3°**，不等于一次测向便获得精确地理坐标 |
| 辐射源定位方式 | 多次测向、平台运动或友方网络交叉验证 |
| 机头光电／红外转塔 | 昼夜观察、图像辅助识别与目标复核 |
| 光电识别 | 受云层、天气、目标大小、背景和视线遮挡限制，不规定单一通用距离 |
| VHF/UHF广播中继 | 区域定向播发与视距通信为主 |
| HF短波广播中继 | 可收放拖曳天线，随传播与电离层条件支持中远程联络 |
| 多语言广播 | 人员授权的预录语音、文字转语音与人工即时播发 |
| 数据链 | 多任务节点接入与态势分发；不视为可直接接管所有友军飞机 |

ESM的分类容量不表示能够在任何电磁环境下无误地区分120个同时发射的信号；测向精度也不等于地面定位精度。机载AI在和声-1M中可参与信息融合、航迹提示、系统诊断与射频调度建议，机组日常可称其为**“中控”或“智控”**。广播与电子任务仍由对应操作员及任务指挥员授权，不因这一俗称赋予AI独立的对外广播决策权。

### 任务系统运行率与保障

| 项目 | 正式参考值 |
| --- | --- |
| 完整任务系统可用率 | **约85%**，指按既定维护制度统计的平均任务设备可用水平 |
| 任务设备持续工作 | 受任务组合、供电与散热限制，必要时以分时工作保持稳定 |
| 机体设计总飞行寿命 | **约24,000飞行小时**，按计划检验与结构维护 |
| 设计服役年限 | **约25年**，不是无条件强制退役期限 |
| 标准维护资源 | 模块化任务机架和外部吊舱可独立检修／更换 |

85%的设备可用率不是任务成功率，也不能被当作飞机能安全飞行的概率。各机务单位的具体妥善率仍会随着使用强度、维护与备件状况而改变。

## 统一射频资源管理

本机的三种射频相关能力不是不加约束地同时全功率开启。33.5m翼展及较大机体允许更多天线间距、设备空间、供电和任务席位，但仍以统一调度机制避免自干扰和资源冲突。

| 调度维度 | 管理原则 |
| --- | --- |
| **频段** | 按任务条件分配雷达、电子战、通信及广播工作频段 |
| **时间** | 对可能相互干扰的功能采取分时使用，尤其避免同频干扰与广播同时全功率工作 |
| **空间** | 尽可能采用定向天线，限制不必要的全向辐射 |
| **工况** | 按任务优先级综合调度天线、发射功率、供电和冷却条件 |

### 四种正式任务模式

| 模式 | 任务名称 | 主要工作状态 |
| --- | --- | --- |
| **A** | 监视预警 | 机背AESA、ESM与数据链为主，广播待机 |
| **B** | 电子战 | 以ESM定位和任务吊舱电子战为主，雷达按电磁兼容要求降低功率或间歇工作 |
| **C** | 广播中继 | 以VHF/UHF定向阵、拖曳HF天线与通信中继为主；雷达停止或限制主动发射，保留ESM等被动侦察能力 |
| **D** | 应急救灾 | 雷达／机头光电巡查、应急广播与通信中继协同，**不开启电子干扰** |

模式是资源调度的任务优先级，不表示全部其他系统一概断电。尤其在模式C中，所谓“转为被动侦测”指**保留被动电子侦察与必要的信息接收**，并非把正常主动AESA雷达无条件变成具备同等性能的被动雷达。

## 八人乘员编成

两名飞行员承担飞机飞行、航行、安全与驾驶舱协同；机上六个任务席位分工如下：

| 任务席位 | 主要职责 |
| --- | --- |
| **雷达操作员** | 对空／对海搜索、航迹管理与目标指示 |
| **ESM／电子战操作员** | 辐射源侦收、电子战态势、吊舱任务操作 |
| **广播操作员** | 播发内容、语言版本、播放授权及对外广播控制 |
| **通信中继操作员** | 数据链、通信中继、网络节点与联络业务 |
| **频谱管理员** | 统一射频资源、工作时序、电磁兼容与优先级调度 |
| **任务指挥员** | 汇总态势、协调各席位、分配当前任务优先级 |

频谱管理员是和声-1M的关键专业岗位；机载辅助系统可为调度提供建议，但**不能以智能自动化为理由绕开人员对广播与任务的授权**。
