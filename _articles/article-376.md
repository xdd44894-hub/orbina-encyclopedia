矛-C77“暴雨”是空面／空空多用途导弹，能够对地、对空，并具备末端超音速霰射功能，也是空猎-92系列的正式适配弹种之一。

## 正式参数

| 参数 | 指标 |
| --- | --- |
| 弹长 | 4.25m |
| 弹径 | 180mm |
| 发射重量 | 约240kg |
| 动力 | 可变推力固体火箭＋冲压续航段 |
| 速度 | 巡航Ma 2.2；末段Ma 3.8 |
| 射程 | 对空约80km；对地约150km |
| 战斗部 | 22kg高爆破片主战斗部＋36枚钨合金箭形弹／微型EFP霰射子弹 |
| 引信 | 可编程智能引信，支持触发、近炸、延迟、定时霰射 |

## 制导与用途

中段采用惯性制导、机载导航系统和双向数据链，末段采用毫米波雷达与红外成像双模导引，可选半主动激光。载机包括多用途战斗机、武装无人机和隐身战机弹舱。

距目标约800～1500m时，导弹仍保持Ma 3＋，可解锁前部霰射舱，以锥形散布释放36枚钨合金弹丸，覆盖约100～150m范围。该范围按原始设定保留其覆盖口径，不另行裁定为半径或直径。对空可拦截无人机蜂群、直升机和巡航导弹；对地可杀伤人员、轻装甲、雷达车、导弹发射车和停机坪目标。霰射模式可以关闭，改用主战斗部攻击坚固目标。

矛-C77一弹多用，反蜂群能力强；霰射模式对时序和火控算法要求很高。
