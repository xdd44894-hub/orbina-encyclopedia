20mm惯性制导机关炮弹是寰宇重工空猎-92A、空猎-92B使用的高精度近距空战补充弹药，属于惯性导航微修正机关炮弹，可用于战斗机、无人机和巡航导弹等空中目标。该弹不是能够自行搜索、长距离追踪目标的微型导弹。

## 正式参数

| 参数 | 指标 |
| --- | --- |
| 口径 | 20mm |
| 弹药规格 | 20×110mm |
| 弹丸质量 | 125g |
| 整弹质量 | 约310g |
| 炮口初速 | 1,120m/s |
| 最大弹道射程 | 约5,000m |
| 对空有效射程 | 300～2,200m |
| 对大型空中目标有效射程 | 约3,000m |
| 导航与制导 | 微型惯性导航＋自主弹道微修正 |
| 目标数据 | 发射前由载机火控系统提供 |
| 飞行中控制 | 有限幅度轨迹修正 |
| 末端自主搜索与锁定 | 不支持 |
| 引信 | 碰撞引信 |
| 适配机型 | 空猎-92A、空猎-92B |

表中速度、射程和质量均为俄庇娜世界观正式参数；有效射程受目标类型、相对态势和交战环境影响，不代表任意条件下保证命中。

## 配套机关炮系统

每架空猎-92配备1门20mm机关炮，理论射速1,800发/分钟，约30发/秒；全机备弹720发，分为8个可抛弃弹筒，每筒90发。单弹筒理论持续开火时间约3秒，720发理论持续开火时间约24秒，均不计弹筒切换、射击间隔、故障或其他限制。

720发整弹质量合计约223.2kg，不含弹筒、炮体和供弹机构。弹筒耗尽后可抛弃；这不代表每发弹丸都具有抛壳式独立飞行推进机构。

## 制导与火控逻辑

射击前，载机依据机载雷达、红外传感器、自身飞行状态和目标运动信息形成预定射击解，并将必要弹道参数装订至待发弹药。发射后，炮弹通过微型惯性测量系统估算自身姿态、运动及相对预定轨迹的偏差；当实际轨迹偏离计划时，内置微型控制机构实施有限幅度修正。末端以修正后的弹道争取与目标相交，由碰撞引信起作用。

惯性导航只用于估算弹丸自身运动，不等于直接感知或追踪敌机位置。目标突然大幅变向、目标信息过时、强气动扰动或修正幅度不足时仍可能脱靶。当前正式设定为发射前装订目标预测数据、飞行中自行进行有限轨迹修正，不预设飞行途中持续接收载机更新目标位置的能力。

## 使用定位与局限

相较传统无修正炮弹，本型在适合的射击条件下具有更强的弹道修正能力，适合空猎-92先进火控支持下的高动态近距空战补充射击。20mm弹体内部空间有限，微型惯性测量、计算和轨迹控制组件需要承受炮弹发射时的高加速度与冲击环境，因此成本高于普通20mm无制导炮弹。

它的轨迹修正幅度远小于专门空空导弹，不能替代[标枪-6“刺客”]({{ '/articles/article-374/' | relative_url }})等格斗导弹。空猎-92A由机载AI执行飞行和火控相关控制；空猎-92B由飞行员掌握实际飞行与交战主动权，机载AI协助复杂态势及弹道预测。
