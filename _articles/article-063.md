# 萨德林民生与福利

## 国家利益与公民福利

萨德林优先维护本国利益与地缘战略，并非无条件利他；这不等于本国公民福利较差。其物价与税率整体略高于联合城，民生福利更好。

## 工人社会地位与机械厂工资

萨德林的**工人与军人享有同样高的社会地位**。这体现了国家对生产劳动与国防服役的重视，但**社会地位相当不代表工资、军粮、住房或其他具体待遇完全相同**；相关待遇须分别依据已确定的制度记录。

**典型机械厂工人的平均工资为每月12,000Ɓ。** 该数字专指这一类典型工厂岗位的平均月工资，**不是全国各行业工人的统一工资，也不是全社会或全体机械制造业的正式平均工资**。税前／税后口径、基本工资与奖金的构成、地区与工龄差异以及典型工厂的具体统计范围尚未确定，不据此补造。

可对照[《萨德林标准单兵三日套餐》]({{ '/articles/article-409/' | relative_url }})和[《萨德林高寒单兵三日套餐》]({{ '/articles/article-406/' | relative_url }})了解其军人食品保障制度；**军粮配置不能直接当作工人日常食品配给清单**。

## 纳税区间与工资口径

萨德林常见的**纳税区间为3,000～8,000Ɓ**。这是作者新给出的区间数据；目前尚未明确这里的“纳税区间”具体指**实际缴税额、应税收入区间、适用税档还是其他计税口径**，也未锁定对应的计税周期。因此**不能直接把3,000～8,000Ɓ当作典型机械厂工人12,000Ɓ月工资的固定月税款**，或据此推算统一税后工资、税率。

## 城乡住宅价格与居住渠道

### 城乡住宅单价

| 住宅所在区域 | 已确认单价 |
| --- | ---: |
| **乡下、农村住宅** | **约300Ɓ／㎡** |
| **城市住宅** | **约300,000Ɓ／㎡（30万Ɓ／㎡）** |

这两个单价相差**1,000倍**，但**城乡工作者的收入水平也不同**：在城市工作的人通常收入更高，因此不能直接拿典型机械厂工人的**12,000Ɓ月均工资**套算所有城市工作者的购房负担。作者明确指出，城市劳动者的收入更高，使城市住宅的**相对负担比只看名义单价所推断的情况更小**；具体城市平均收入、房价分布、租金与贷款条件尚未设定，不擅自推算城市购房年限或所有家庭的住房支付能力。

### 工厂和农业劳动者的城市居住

**工厂与农田工作的居民也可以住在城市**，并不是因为从事工业或农业劳动就必须在农村买房或居住。因工作和实际需求，可以使用**宿舍、暂住住所、半永久住宅**等形式安排在城市或工作地的居住。这些属于已确定存在的居住渠道；具体提供主体、租金、产权、分配资格与居住期限尚未确定，不能擅自概括成全民免费城市住房。

## 个人营基地制度

### 基本性质：登记取得土地使用权

在萨德林，**个人不享有土地所有权，只能依法取得土地使用权**。没有房子的人可以选择在符合制度要求的**野外区域圈定一块范围并登记**，形成个人的**“营基地”**。这是受到登记与使用规则约束的土地使用制度，**不是圈地后取得土地私有产权**。

| 项目 | 已确认规则 |
| --- | --- |
| **土地权利** | 个人依法取得使用权，不享有土地所有权 |
| **单个营基地最大面积** | **166㎡** |
| **个人全部营基地面积合计上限** | **200㎡** |
| **营基地数量** | 可以拥有不止一个，但须遵守个人总面积上限 |
| **通常建筑层数** | **最多2层** |
| **通常建筑高度** | **约5米** |
| **多人居住的建筑层数** | **常住人数达5人或以上时，可以建3层** |
| **常住人数认定** | **实际居住超过6个月，自动计入常住人数** |
| **建筑类型限制** | **不允许钢筋水泥建筑**；其他建筑形式原则上可自行选择，但仍受层数与生态保护要求约束 |
| **生态责任** | 使用者对营基地范围内的生态环境负有维护责任 |

### 面积、层数与实际居住

**200㎡指一个人名下所有营基地的面积合计上限，而166㎡是其中任意一个基地的上限。**例如，两处各100㎡的基地符合面积限制；单处200㎡不符合；两处各150㎡也因合计300㎡超出个人上限而不符合。

通常情况下，营基地的建筑**最多两层、约5米高**；当**常住人数达到五人或更多**时，允许建造**三层建筑**。住在该处的人**实际居住超过六个月**就自动被计入常住人数。**三层情形下的具体高度上限尚未单独确定**，不能直接把普通两层的约5米高度强加给三层建筑。

### 建筑选择与生态维护

**钢筋水泥建筑不允许建在营基地内；其他建筑形式原则上不受这种材料禁令限制**，但仍须遵守上述层数、面积和生态要求。木屋、帐篷等可以作为这种制度下的建筑形式示例，**不意味着国家统一提供材料或免费代建住宅**。

营基地使用者所谓**“维护生态环境”**，基本要求是**不乱砍滥伐、不肆意捕猎、不通过擅自开荒种田等行为毁坏原有绿地和植被**。它不等于强制每个使用者承担定期植树、专门生态修复工程或复杂环保报告等未设定的额外义务。正常的非破坏性使用与破坏植被的开荒行为应当区分。

具体登记程序、哪些野外地域开放登记、使用权期限、是否能转让或继承、三层建筑的高度细则，以及对特殊情况的管理程序，目前尚未明确，不在这里擅自补造。

## 黑矿场禁令

**萨德林禁止黑矿场，国内没有合法存在的黑矿场。**这是该国对矿场产业本身的禁止，而不只是对矿工死后遗体或[黑质焦]({{ '/articles/article-373/' | relative_url }})原料的限制。**联合城的黑矿场则是合法产业**，两国政策不同。

目前未明确萨德林此项禁令的具体立法名称、出台年份、刑罚、执法机制、境外相关产品进口规则，以及是否另行明确禁止人体来源黑质焦的所有贸易形式，不能擅自补设。禁止黑矿场也不等于任何劳动场所都不存在职业健康风险。

## 流浪者救助与再就业

- 每月参加3次社区清洁，可领取800Ɓ救济。
- 社区提供约8㎡免费简易住宿、免费体检、基础灰面包与纯净水。
- 社区教室培训清洁、快餐店工作、写字及基础识字等技能。
- 记录强调，多数潜在流浪者会在长期流落街头前被社区人员发现并介入。
- 再就业可结合原有能力，例如破产农户转花卉种植、失败商人经营小商品跳蚤市场、失业工人参与蒸馏水或灰杂粮面包生产。

该救助机制与价格适用于所述地区，不代表全境无例外政策。

## 萨德林共产乌托邦共和国：物价与福利

【1. 国家性格】
- 萨德林在国家层面“自私”：优先维护本国利益与地缘战略，不是无条件利他。
- 这不等于对本国公民差；其内部福利明显强于联合城。
- 物价和税率整体略高于联合城，但民生福利明显更好。

【2. 食品价格】
- 酸黄瓜：4.6Ɓ/500g
- 面包：3.2Ɓ/500g
- 家常鱼子酱：36Ɓ/500g
- 香肠：11Ɓ/500g
- 黄油：15Ɓ/500g
- 葵花籽油：13Ɓ/L
- 柠荷果酱：18Ɓ/500g
- 土豆：0.8Ɓ/500g
- 另有旧口径：本国普通鱼子酱约50Ɓ/500g；出口鱼子酱约5000Ɓ/500g。
- 36Ɓ家常鱼子酱与50Ɓ普通鱼子酱暂不强行合并，可视作不同档次，待后续确认。

【3. 流浪者与再就业】
- 流浪者每月参加3次社区清洁，可领取800Ɓ/月救济。
- 社区提供免费约8㎡简易住宿、免费体检、基础灰面包、纯净水。
- 社区教室培训简单清洁、快餐店工作、写字/基础识字等技能。
- 多数潜在流浪者会在真正长期流落街头之前被社区人员发现并介入。
- 再就业可按原有能力转化：破产农户→花卉种植；失败商人→小商品跳蚤市场；失业工人→蒸馏水生产或灰杂粮面包制作。
- 核心思路：尽量在一个人彻底脱离社会之前把他接住。
