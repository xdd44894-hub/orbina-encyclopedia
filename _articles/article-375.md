标枪-8E“长矛”是远程／超远程空空拦截导弹，E代表增程型，也是空猎-92系列的正式适配弹种之一。

## 正式参数

| 参数 | 指标 |
| --- | --- |
| 弹长 | 5.9m |
| 弹径 | 203mm |
| 发射重量 | 约380kg |
| 动力 | 固体火箭冲压发动机＋高抛弹道 |
| 速度 | Ma 4.5＋ |
| 射程 | 5～260km；高空迎头模式更远 |
| 战斗部 | 38kg高爆破片，定向破片设计 |
| 引信 | 智能近炸＋触发 |

## 制导与使用

标枪-8E采用惯性制导、机载导航系统、双向数据链中段修正，末段使用主动有源相控阵雷达与红外成像双模导引。它支持“A射B导”，可由预警机、隐身战机或无人侦察机中继制导，主要打击预警机、加油机、电子战机、巡航导弹及敌方高价值空中目标，抗电子干扰能力强。

260km和高空迎头模式更远属于特定交战条件下的射程指标，不代表任意高度、速度和目标运动状态都保证达到该距离；射程也不等于必然命中距离。弹体较大、成本较高，通常由重型战机或隐身机外挂或改进弹舱携带。
