# 双政权初期财政、金融与地方自治争端

[民众联邦]({{ '/articles/article-430/' | relative_url }})建立后，旧联合城继续控制其他地区并保有原有国际组织席位和组织结算体系。双方既争夺军事与政治主导，也面临大量普通居民、企业、银行与地方政府遗留的财政和民事法律关系。**战争控制线的改变，不会使工资、银行存款、债务、养老金与地方自治协议在同一天自动改换法律主体。**

本条正式记录分裂初期五项典型而持续的政治经济争端。各事件的制度事实和处理方向纳入正式历史；不虚构尚无依据的精确金额、具体案件当事人姓名、单一全国物价涨幅和全部地区一致的执行结果。

## 一、《双重账簿争议》：有账面资金却无法发工资

一部分位于民众联邦控制区的企业保留旧联合城时期的订单、应收款和银行账户。其中部分账面资产或款项位于旧联合城金融机构，或需要旧联邦组织结算网络完成跨境交易。企业依然拥有一定生产能力，却无法及时把全部应收款变成**能够在本地支付工资、采购能源与零件的实际流动资金**。

新政府财政部门与地方工业机构逐步建立**过渡账务核验**做法，将四种数额分开：

| 类别 | 具体意义 | 不能直接当成 |
| --- | --- | --- |
| 企业或居民对旧机构的应收债权 | 可据合同、账簿、判决等主张的资产请求 | 新政府国库现金 |
| 仍在旧体系登记的账户余额 | 账面存在但可能受结算、管辖与提取条件限制的资金 | 在新控制区随时可动用的现款 |
| 新政府及地方实际持有的可用资金 | 能够依法拨付的现金、认可账户余额或可接受支付资产 | 无限制的长期收入能力 |
| 已获得临时代表机关批准的预算 | 政治上允许安排的支出及责任 | 已经完成全部收款及支付 |

过渡执政委员会在经授权的基础服务项目和受影响企业之间，建立有限的工资、运输和必要供应支持安排。**这些安排在部分地区缓解了支付中断，但没有自动偿清全部私人企业欠薪或承认所有旧银行债权由新政府担保。**

工会与劳动者要求按劳动关系及时付薪，企业要求保留生产，财政人员坚持按实际可用资金安排预算。三方利益可能同时合理，却无法通过一纸行政命令消除所有欠款。

## 二、《退休金接续争议》：两个政府与同一段劳动履历

新联邦控制区的部分居民曾长期向旧联合城社会保障制度缴纳养老金，相关记录、基金权益与领取资格可能由旧机构管理。在分裂发生后，养老权利的**原始缴费记录、承担支付义务的法律主体、金融资产实际控制和跨政权汇款路径**开始出现冲突。

旧联合城并未因失去部分地区，就从法律上自动取消其辖区居民过去一切社会保障债权；民众联邦也不能因实际控制地区便立即取得旧养老金全部资产。

民众联邦由此建立针对部分退休居民的**过渡生计救助安排**，优先解决符合审查条件者在养老金支付障碍期间的基本生活问题。这类救助来自新政府及地方可用财政，与是否已经依法继承原旧联邦养老金债务**不是同一性质**。

旧政府及新政府各自需要核验历史缴费证据、工资记录、身份登记和受益人资格；战争中的档案缺失、重复申领风险和银行准入限制增加了处理成本。某些地区可凭留存材料完成救助核验，另一些地区则因资料损毁或财政不足严重拖延。

**政治影响：**一名退休居民无需支持任何政治派系，也可能因为国界和金融管理权变化而遭受实际生活困难。对原制度的法律请求权和对新政府的临时救助请求，必须区别记账和审查。

## 三、《药品结算与人道供给争议》

民众联邦没有获得旧联合城组织共同结算体系的完整接入资格，其控制区医院采购外地药品和精密医疗设备时，难以继续沿用原有银行与贸易渠道。

新联邦卫生及财政协调人员尝试通过**具备自身支付能力的第三方贸易商、已获少数国家承认的新政府对外关系和不依赖旧结算网络的支付安排**处理部分必要采购。有限的相关交易得以推进，但成本、交货时间、合同保障与覆盖地区均存在明显差别。

旧联合城仍坚持拒绝民众联邦直接加入共同结算体系。**有限第三方贸易不等于旧政府给予了新联邦完整准入，也不等于旧联合城正式承认民众联邦。**是否由旧联合城许可特定人道交易，须区分实际获批文件与第三方自主达成的交易，不得把每一批药品都写成经旧政府特批。

供应商可能因未获付款保证而拒绝运输；贸易加盟城邦可能因原有结算规则面临合规争议；外部国家认可民众联邦也不意味着愿意为全部商业交易承担信用风险。部分医院得到急需药品的同时，另一部分地区仍可能出现缺药。

## 四、《自治协议暂行登记争议》

原联合城成员城邦、联邦核心区与协约辖区原本具有不同政治地位。民众联邦逐步接管的地方不可能在同一天依法变成同一类地方单位。

一些具有较完整地方机构的地区，要求继续管理自己掌握的学校、医院、供电与地方财产，同时希望参与新政府共同财政和防务安排。另一些解放区组织则警惕旧地方精英借自治名义保留严重社会不公。

为避免公共服务陷入政治真空，民众联邦采取**地方公共事务过渡登记及协议协商**做法：

1. 核实当地实际服务机构和合法居民登记资料；
2. 明确哪些日常事务仍由地方负责，哪些需要过渡执政委员会跨区协调；
3. 单独登记地方可用税源、公共企业、债务及中央拨款义务；
4. 明确临时安排不得自动替代未来永久宪制决定；
5. 有争议的财产、司法案件与人员责任，依过渡程序审查。

这并不意味着所有地方都主动接受新政府；军队实际控制区、社会支持和行政整合水平仍有显著差异。原地方在旧联合城获得的自治权，并不自动等于与民众联邦已经签署了内容完全一致的永久自治协议。

## 五、《名义贸易加盟城邦的结算异议》

部分高度自治的城邦只在名义上参加联合城组织，主要为了进入贸易结算体系并按协议承担款项。民众联邦成立后，这类城邦的一些企业可能仍与新控制区有重要商业往来，却因联合城结算限制而难以维持原有交易。

相关城邦可以依据自身协议向旧联合城主张特定交易许可、重新解释条款或谈判补偿，中央则以共同网络的法律规则、金融风险与对民众联邦的外交立场作出回应。

**成员是否属于正式联邦城邦、仅为贸易型名义加盟、还是另有协约地位，直接决定其可要求的待遇与可能承担的义务。**名义贸易加盟不自动取得公民院、城邦院全部政治表决权，也不等于受到正式成员完全相同的外交及军权约束。

这场争议暴露出一个现实：**某个城邦不支持民众联邦的政治目标，仍可能反对旧联合城的特定贸易限制，因为其本地就业与商业利益受到影响。**反之，反对贸易限制也不能直接推断该城邦准备独立或加入新联邦。

此争议并没有导致旧联合城全面撤销对民众联邦的结算排除；不同贸易机构与地方就个别合同采取的替代方案也不构成全国统一恢复正常贸易。

## 六、不同政治机关在争端中的作用

| 政治与经济主体 | 实际权力与局限 |
| --- | --- |
| 旧联合城秘书长与中央行政 | 控制旧政府的依法行政和共同金融政策，但不能凭单方命令使新政府控制区接受旧财政支配 |
| 旧联合城双院 | 审议战时预算、成员义务和有关法律，存在席位资格及法定多数困难 |
| 民众联邦临时代表会议 | 授权过渡财政与公共服务安排，代表资格和地区覆盖尚未达到全面常态化状态 |
| 民众联邦过渡执政委员会 | 组织实际支付、供应、地方协作和对外沟通，但受现金、行政能力与军情限制 |
| 地方政府与自治组织 | 掌握部分实际服务、税源与人员，仍受旧或新政治协议及有效管辖限制 |
| 商业银行与企业 | 负有真实的合同、账户和雇佣义务，但跨政权金融关系可能无法即时履行 |
| 司法与监察人员 | 处理合法权利、证据和违法责任，不能凭判决自动创造缺少的物资或财政收入 |

**特别注意：**旧联合城法定货币Ɓ仍可在不同地区流通，PUMP和金澈券等既有价值媒介也未因战争自动失效；但是民间使用某种货币，不能替代银行准入、国家法定发币权、合同履行及跨境支付能力。

## 七、政治博弈的长期后果

双政权争议不会因为某次谈判成功而彻底结束。新联邦为了维持公共生活而沿用部分旧管理记录，可能遭到革命阵营内部批评；旧联合城坚持合同、金融与国际代表连续性，却也可能面对原控制区居民要求继续支付既有社会保障的诉讼和政治压力。

这些早期争端奠定了后续双方更复杂的国家关系：**旧政权以宪制和制度连续性维持其国际与金融地位，新政权以实际控制、革命政治和公共服务重建争取国内合法性；两方都需要以真正可执行的制度承担居民生活的现实后果。**

事件的准确发生日、双方首批外交谈判人员姓名、养老金总额与各地具体预算，仍需与完整年表及地区治理数据一致后录入，不应随意给出统一数字。
