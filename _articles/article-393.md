**“锋刃”**是[“全球攻势”]({{ '/articles/article-004/' | relative_url }})中发生于**秦棠—新来戈大坝**地区的大型基础设施战役。新来戈大坝在战争语境和部分民间报道中亦被称作**“寰宇大坝”**；两者为**同一座工程设施**，不是两个不同的水坝。

战役的军事结果是**寰宇取得局部战术胜利并重新控制大坝周边重要军事通道**，但新来戈大坝发生严重结构与泄洪系统事故，造成跨地区特大洪灾，军事实得远不能抵消灾难损失。大坝战后的民事监管与产权仍归秦棠政府及相关公共机构，而非由赢得战斗的企业永久接管。

## 工程背景与三方关系

[新来戈大坝]({{ '/articles/article-394/' | relative_url }})是秦棠政府、寰宇重工和深蓝科技共同参与的大型水利工程。建设合作最初由寰宇重工主席长子积极促成，秦棠以东北矿业优惠供货或开采条件吸引合作，既有合同条件约相当于相应市场价格的**30%**。

寰宇负责坝体土建、大型施工机械、钢结构与大宗运输；深蓝负责水轮发电、泄洪调度、自动安全监测、水文研究与配套供水专业工程；秦棠政府承担公共监管、验收与运营。**两家公司在战前是工程合作方，全球攻势期间却在大坝地区交战**，使设备与产权关系异常复杂。

建设时的大坝工程总坝线长**48公里**、最大坝高**90米**、坝体标称厚度**58米**，前期准备及缓启动4.5个月、主体施工18个月、收尾1.5个月，建设合计24个月并于第三年启用。作为平原大型水利工程，其调控水域关系到秦棠全国约**7%的耕地**。这也是坝区在战争中受到破坏后，民用水资源调度与农业生产受到严重冲击的背景。

## 争夺经过

战事初期，双方围绕坝区对外道路、发电设施周边及交通节点争夺控制。深蓝一度控制部分与水电工程相关的设施，寰宇则从周边通道重新组织推进。

交战造成供电、通信与泄洪调度体系多处异常，部分坝体结构受损，水库在高水位背景下发生**非计划大量泄水与局部结构失效**。洪水沿多个河道及低地扩展，救援和人员撤离被基础设施损毁严重阻碍。

寰宇后来在局部地面作战中取得优势，迫使深蓝从关键军事通道撤离；但持续泄水已经造成跨地区破坏。**此役属于寰宇军事战术胜利，同时也是双方及沿线社会的灾难性损失**。

## 战役投入、消耗与伤亡统计

### 统计范围与作战节奏

战区连续作战时段设为**27天**。下表为寰宇—深蓝两方的**战役期累计统计**，用于体现不同战区的战争规模与后勤负担；战役起止的俄庇娜历**绝对年份仍未确立**，此处不擅自指定具体开战年月日。战役发生地的地方警察、救援机构和不属于双方指挥链的军队，不直接计入企业军事人数。

二十七天的坝区争夺中，兵力涵盖主坝、发电设施、外围道路及**峰岭附属战场**，洪灾造成的灾害波及人数远超过直接参战人数。涉洪人员应由灾害统计列示，不强行并入寰宇或深蓝的军人伤亡；坝区毁坏的蓄意责任仍与战役军事胜负分别判断。

### 既定事件与统计口径校正

**洪灾直接造成31,700人死亡、106,000人受伤、13,400人失踪**，已纳入本表对应平民统计；此外非洪灾直接战斗与其他次生事件造成**640人死亡、1,950人受伤、190人失踪**。因此本战役平民死亡合计32,340人、受伤107,950人、失踪13,590人。**洪灾单项151,100人伤亡或失踪**仍保持与[新来戈大坝]({{ '/articles/article-394/' | relative_url }})一致。772亿Ɓ的民用及公共设施直接损失，**包括此前核定的洪灾直接损失730亿Ɓ**，其余42亿Ɓ为独立于洪灾统计的交战毁损；不得重复相加。

## 毁坝责任与公开争议

- **深蓝方面指控寰宇**自行策划坝体毁坏，再以维修为由重新派兵控制秦棠相关地区。
- **寰宇方面指控深蓝**为介入秦棠事务而故意轰炸大坝，导致严重洪水。
- **能够确认的灾害过程**包括战争期间重要设备失效、局部结构受损、非计划洪峰及大规模下游灾难。

上述两个关于**蓄意毁坝责任**的完整指控，均不能仅因一方取得军事胜利就被自动证明。战争造成的设备中断与工程损坏是确定的，针对毁坏的具体刑责仍属于后续调查问题。

## 洪灾损失与战役结局

| 项目 | 战役及工程统计 |
| --- | --- |
| **军事结果** | **寰宇战术胜利**，深蓝撤离坝区关键军事通道 |
| 正式受灾工程 | **新来戈大坝（又称寰宇大坝）** |
| 最大洪水淹没影响面积 | **约4,900km²** |
| 洪灾死亡 | **约31,700人** |
| 洪灾受伤 | **约106,000人** |
| 洪灾失踪 | **约13,400人** |
| **洪灾总伤亡与失踪** | **约151,100人**，三类人员不重复计算 |
| 被迫转移或失去正常住所 | **约182万人** |
| 灾害影响总人口 | **约520万人**，不等同伤亡人数 |
| 民政及工程恢复 | 秦棠政府及跨地区救灾机构主导，企业不得以军事占领替代公共监管 |

洪灾还波及**萨瑞拉西北部的首都与经济核心地区**。这一影响说明存在跨地区水系联系，但**不能据此推定秦棠与萨瑞拉整体必然呈某个特定的南北或边界方位关系**。受灾范围统计包括河道洪水、回水、城市内涝与交通／排水系统失效等复合影响。

“锋刃”最重要的历史结果不是谁最终站上坝顶，而是**一座大型能源和供水工程在企业战争中转化成波及数百万民众的灾难源头**。
