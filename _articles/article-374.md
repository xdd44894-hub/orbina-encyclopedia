标枪-6“刺客”是面向第五／六代机近距格斗的高机动空空导弹，主打高离轴、抗干扰和越肩发射，也是空猎-92系列的正式适配弹种之一。

## 正式参数

| 参数 | 指标 |
| --- | --- |
| 弹长 | 2.95m |
| 弹径 | 160mm |
| 翼展 | 440mm |
| 发射重量 | 约118kg |
| 动力 | 双脉冲高能固体火箭＋推力矢量燃气舵 |
| 速度 | Ma 3.2～3.6 |
| 射程 | 0.3～40km |
| 最大过载 | 60G |
| 离轴发射角 | ±90° |
| 战斗部 | 12kg连续杆／破片复合战斗部 |
| 引信 | 激光近炸引信＋触发引信 |

## 制导与使用

标枪-6采用中段惯性制导与双向数据链，末段使用中波／长波复合双波段红外成像导引头，具备抗热诱饵和红外干扰能力，支持发射后锁定与锁定后发射。±90°高离轴能力和越肩发射属于可用作战功能，但仍受射界、载机姿态、速度和火控条件约束，不代表任何姿态下都能无条件向后命中。

导弹体积小、机动性强，适合近距空战和拦截无人机。载机包括隐身战机内埋弹舱、四代半战机外挂挂架和无人僚机；射程偏短，依赖载机态势感知。
