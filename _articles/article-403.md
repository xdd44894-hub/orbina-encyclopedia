## 定位、归属与联合城等级对照

寰宇重工具备大型太空舰船设计、建造、模块化供货和船坞总装能力，是[联合城联邦舰船供给体系]({{ '/articles/article-343/' | relative_url }})的重要承包商。但必须将**寰宇生产并出售的舰船、寰宇本体战争舰队与集团安全内务的护卫舰船**区分开，详见[《军团与寰宇军事力量的归属》]({{ '/articles/article-402/' | relative_url }})。

**已确认的自有安全与内务护卫数量：四艘武装护卫舰、二百余艘战斗艇。** 这个数据仅对应集团武装护卫与资产保护体系，**不能**代表寰宇整个战争舰队的舰只总数，更不能替代其为客户建造的舰船数量。寰宇本体正规作战舰队的各舰种现役总数仍需另外统计。

本条所谓**“按联合城标准”**，首先指**舰种分层、工业制造与轨道总装方式、质量和装备核算、军舰交付验收、维护后勤口径**与联合城体系相对齐。联合城现行已明确的舰级包括**灰狐级护卫舰、牧羊犬级驱逐舰、远岸-600级巡洋舰、KaRty-e700“极地”级战列巡洋舰、止战级战列舰、边境3000级快速母舰和永恒常量级战略母舰**。这些是联合城的舰级名或分类参照，**不表示它们一定全部由寰宇独家制造**。

联合城现有[年度造舰资料]({{ '/articles/article-343/' | relative_url }})主要给出国家级**年交付区间和工业组织方法**，未给出每一级统一强制的舰体长度、满载质量与主炮数量。因此本条下面的数值，是**本次为寰宇产品线补定的参考型号规格**，而非冒充已经确定的联合城原舰级逐项实测参数。

## 一、舰船工业产品线的参考级别

为符合联合城军购体系中的舰种职责，寰宇采用可由不同客户验收的舰体等级；型号名称采用工业编号与名称混用，不要求全部采用同一命名传统。

| 寰宇参考型号 | 对应联合城舰种层级 | 舰体全长 | **满任务质量** | 典型人类乘员 | 舰内持续电力 | 产品定位 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| **HL-12“巡卫”战斗艇** | 看门人-4型护航艇等级 | **约54m** | **约780t** | **2～6人**，可选无人构型 | **约25MW** | 近地轨道巡逻、船坞警戒、编队伴随 |
| **HFG-42“关隘”武装护卫舰** | 灰狐级护卫舰等级 | **约235m** | **约84,000t** | **约90人** | **约1.6GW** | 厂区、运输航线和资源基地护卫 |
| **HD-220太空驱逐舰** | 牧羊犬级驱逐舰等级 | **约430m** | **约310,000t** | **约260人** | **约7GW** | 护航编队防空、反导和中型舰交战 |
| **HC-620“外缘”巡洋舰** | 远岸-600级巡洋舰等级 | **约710m** | **约1,350,000t** | **约780人** | **约24GW** | 多任务编队指挥、远程火力及区域警戒 |
| **HK-780战列巡洋舰** | KaRty-e700“极地”级战巡层级 | **约1,050m** | **约4,800,000t** | **约2,000人** | **约78GW** | 重型主力交战、远程火力与战役指挥 |
| **HB-990战列舰** | 止战级战列舰层级 | **约1,430m** | **约11,000,000t** | **约3,600人** | **约155GW** | 高防护重型舰队决战平台 |
| **HV-3000快速太空母舰** | 边境3000级快速母舰层级 | **约1,760m** | **约15,500,000t** | **约3,100人**，不含舰载航空器的所有独立乘员 | **约140GW** | 远程舰载机／无人机部署及战区航空支援 |

**表格属于不同型号各自的参考单舰参数**：不能把军舰全长当作同等可利用舱容，也不能将不同型号质量直接视作联合城已命名原型的官方数值。所谓“满任务质量”包含舰体、固定武器系统、推进物资、弹药、载荷和必要的任务补给，不是**空船质量＋再次全额加上已经计入的载荷**。

**永恒常量级对应的战略超大型母舰属于更高层的专案平台**，本次只保留对应生产能力与订单类别；寰宇是否自有该等级战舰、以及其单舰具体吨位与长宽等参数，暂不自行确定。

表中**HD-220及更大的军舰是寰宇可以设计建造并向合格采购方交付的产品段标准**；本次并**不**宣称寰宇自有战争舰队已全部装备这些型号，也不虚构各型号已经交付了多少艘。为集团自用或联合城国防订单制造的舰船，可根据实际军事采购合同与用途另行验收。

## 二、自有护卫舰等级：HFG-42“关隘”

**HFG-42**为寰宇按联合城护卫舰等级设计的**工业资产保护／编队护卫参考型**，能够作为集团四艘既有武装护卫舰所属等级的技术参照；**尚未确认既有四艘均为HFG-42，不能把四艘全写成同一型号**。

| 参数 | HFG-42参考规格 |
| --- | --- |
| 舰体 | **长235m、最大宽58m、最大结构高约42m**，主体为真空环境航行舰体 |
| **基本干质量** | **约59,000t**；包含固定装甲、反应堆、常设主动力、挂装机构及标准航电 |
| 推进工质与任务储备 | **约17,000t** |
| 弹药、人员补给与可替换任务组件 | **约8,000t**，其中可含人员保障、备件及任务货物 |
| **满任务质量** | **约84,000t**（59,000＋17,000＋8,000），三项不重复计算 |
| 舰员 | **约90名人类**；可配置分布式维修机器人与自动化损管设备，机器人不按人类乘员计数 |
| 持续舰用电力 | **约1.6GW**；不等于主推进总热功率 |
| 主动力 | 双通道可冗余的大型聚变推进与姿态控制系统；具体战略跃迁能力依采购构型和航路认证 |
| 标准无需外部补给的任务期 | **约150～180天**，随巡航与火力消耗变化 |
| 核心探测 | 适配联合城任务数据标准的AESA、红外、被动电磁侦测、光电和通信融合 |
| 主要武器类别 | 中口径电磁炮、通用舰载防御导弹、近距拦截炮和定向能反导／反无人机装置 |
| 装甲防护 | 分层实体装甲、内部隔舱、损管、诱饵、主动拦截；能量辅助只为部分定向能防护服务 |
| 主要任务 | 资源站、船坞、工业行星外围及重要运输队的护航和自卫 |
| 行星表面起降 | **基型不具备**整体自主行星起降能力；转运与驻泊依赖轨道设施和专用登陆艇 |

HFG-42**不是以独舰决战巡洋舰、战列舰为标准任务**。它具备保障本舰和商用运输队生存的武装，但仍依赖侦察、编队配合、工业基地和修理力量。企业安保护航时可以采用限制性任务模块，不应默认拥有与联合城正规军护卫舰完全相同的战略弹药授权。

## 三、自有战斗艇等级：HL-12“巡卫”

寰宇安全体系已确认保有**二百余艘战斗艇**，HL-12为其中可使用的一类**标准参考型号**，不代表全部二百余艘只有一种型号。

| 参数 | HL-12参考规格 |
| --- | --- |
| 基本用途 | 近轨警戒、运输队伴随、登临检查、应急拦截 |
| 舰体全长 | **约54m** |
| 最大宽／结构高 | **约13m／10m** |
| 干质量 | **约520t** |
| 推进工质与消耗品 | **约180t** |
| 弹药／任务载荷 | **约80t** |
| **满任务质量** | **约780t** |
| 乘员 | **2～6名人类**；部分构型可无人化 |
| 舰用电力 | **约25MW** |
| 无外部补给任务期 | **约15～25天** |
| 标准武备 | 近程防御导弹、轻型电磁炮／自动拦截武器、光电干扰及诱饵装置 |
| 结构 | 轻型分舱防护、电子告警；不具备大型主力舰级别实体装甲 |
| 运行方式 | 依托母港、补给站或较大型护卫舰；不承担独立跨星系远征的主力角色 |

企业规模大、拥有多座工业基地，因此大量战斗艇适合执行**多节点常态巡逻与资产安全**。战斗艇数量大不意味着全部可以作为一支不依赖补给的舰队，在单一战场长期作战。

| 型号级别 | 主要火力类型 | 电子／防空与保障定位 |
| --- | --- | --- |
| HL-12战斗艇 | 小型电磁武器、短程导弹 | 近防、侦察和近距警戒 |
| HFG-42护卫舰 | 中口径舰载电磁炮、通用防御导弹 | 编队护航、点防空、导引器干扰和货船保护 |
| HD-220驱逐舰 | 中远程防御导弹、电磁炮与快速近防系统 | 编队区域防御与导弹防护 |
| HC-620巡洋舰 | 多类导弹和较大功率电磁武器 | 综合火控、电子战节点、战区通信与编队协调 |
| HK-780战列巡洋舰 | 重型舰炮和多用途大型舰载武器 | 远程主力交战、旗舰感知与持续作战 |
| HB-990战列舰 | 超重型动能舰炮、远程导弹和多层防空 | 高强度正面承压、舰队核心防御 |
| HV-3000快速母舰 | 主要由搭载的各类太空战斗机、无人机和护航力量提供打击能力 | 多机种补给、航空保障、战术数据中继 |

**能量武器和防护技术的作用边界**与[《定向能武器与等离子体能量盾》]({{ '/articles/article-399/' | relative_url }})一致：超大功率舰载激光在特定条件下可以直接损伤或击穿重型装甲，但小型激光防空器材主要适合拦截无人机和损伤导引器；**等离子体能量盾以瞬时吸收／偏转对抗激光，不能当成能永久挡住高速动能炮弹的墙**。高速实弹仍需要**物质装甲、分舱和主动拦截**等。

武器表只确定武器**类型和平台职责**；没有规定具体弹仓数量、每分钟发射率、命中率或弹药末端当量时，不应凭大舰吨位自动推定武器拥有无限射程和无限弹药。

## 五、战略航行与热管理口径

**太空舰不使用大气层内的“马赫数”表示标准作战速度。** 应分别描述：

- **本星系轨道机动**：由主推进、推进工质、舰体质量、姿态与任务期间的加速限制共同决定，不把短时加速度等于跨星系平均航速。
- **战略跨星系航行**：依赖经认证的跃迁／航路体系；并非任意一艘战斗艇都具备完整独立跨星系战略航行能力。
- **舰内持续电力**：表内GW/MW值表示可供常规系统分配的舰用电力；舰用电力不等于推进系统瞬时总功率，亦不表示可以无散热代价将全部电力连续供给武器。
- **能源与散热**：舰载大型雷达、电磁武器与激光在高功率工作期间会带来发热；需依靠辐射散热、储热、循环冷却、非战斗时间调节与受损情况下的功率降级处理。
- **作战续航**：任务期是按弹药、维修备件、推进储备、生活保障及医疗保障所估计的无需外部补给时段，**不是**单凭食物储备计算的“无限战斗时长”。

现有世界观中俄庇娜与旧地球相距约**7光年**，跃迁航行单程大约需要**8个月**。这属于特定航线的战略旅行参照，不能简单作为所有舰艇在任意地理条件下的固定速度，亦不代表表中全部小型护卫艇都能独立完成此航线。

## 六、工业建造、产权和产量统计

寰宇沿用联合城**地面精密零件与模块生产、轨道船坞大型舰体总装**的常用工业路线：在地面生产发动机、控制核心、传感器、武器、精密电子及标准组件；经重复使用的运载系统把大模块送到轨道，由船坞机械臂、焊接机器人与验收人员实施装配、联调和质检。集团也可参与具备自主行星起降能力的特殊舰船项目，但该能力**不是全部舰级标配**。

| 项目 | 既定工业与统计原则 |
| --- | --- |
| 主要船坞 | **23座**，属于寰宇体系内已确定的主要船坞数据 |
| 最大船坞的并行建造能力 | **可同时建设4艘战列巡洋舰级舰船** |
| 四艘武装护卫舰与二百余艘战斗艇 | **集团安全与内务自有护卫资产存量** |
| 集团正规战争舰队存量 | **尚未确定完整统计**；不能以安全护卫存量冒充 |
| 为联合城等客户交付的舰艇 | 交付验收后由**客户拥有、使用和统计** |
| 联合城各舰种年度交付区间 | **全国全部承包商与军工生产体系的交付量**，不等于寰宇一家的产量 |

**“最大船坞四艘同时在建”不是“四艘每年建成”，更不是“公司只能拥有四艘大战舰”。** 重型主力舰往往跨年度分批建造、在多个船坞错峰完成，生产效率受材料、能源、设备、软件验收、工程人员及船坞维护制约。

由于联合城各类军舰的现有年交付区间没有拆分到寰宇单一供应商，本条**不擅自给寰宇制定占全国造舰份额多少的固定百分比**，亦不虚构主战舰年度交付数量。

## 七、与其他组织的关系

- [俄庇娜军团]({{ '/articles/article-011/' | relative_url }})是独立的雇佣兵组织，不因采购寰宇舰船、弹药或签订作战合同而被纳入寰宇直营舰队。
- [联合城太空军]({{ '/articles/article-007/' | relative_url }})属于联邦正规军，其采购和验收后的军舰由国家指挥。
- **寰宇安全舰队**与**寰宇本体战争舰队**是企业内部不同的军事任务与统计口径；前者已知规模不能穷举后者。
- 从[联合城与人民天国造舰体系比较]({{ '/articles/article-345/' | relative_url }})看，寰宇的产品与工业组织属于联合城庞大轨道总装网络的一部分，不能把国家层面的工业及战斗舰队全面归给一家企业。
