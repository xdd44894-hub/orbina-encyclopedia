Snp-762是寰宇重工自主研发的射手步枪，主要装备寰宇自身部队。其外贸衍生型为[Snp-897战斗步枪]({{ '/articles/article-368/' | relative_url }})。

## 定型参数

| 项目 | 参数 |
| --- | --- |
| 工作原理 | 导气式、旋转闭锁枪机 |
| 射击模式 | 以半自动为主；是否另有连发档尚未明确 |
| 弹药 | 7.62×45mm |
| 通常使用弹匣 | 12发 |
| 其他兼容弹匣 | Pck-35的35发弹匣 |
| 拉机柄 | 枪身左侧独立设置 |
| 空仓挂机 | 支持 |
| 枪管长度 | 510mm |
| 枪全长 | 1030mm |
| 空枪质量 | 4.3kg，不含弹匣及光学配件 |
| 100m机械支撑散布精度 | 1.6 MOA，标准测试弹条件 |
| 实用有效射程 | 650m，典型单兵目标 |

自动射速未确定；不由系列关系推定其具有全自动档。有效射程在实战中受环境与射手条件影响。

## 弹道与综合作战评价

代表性弹道为7.62×45mm弹药、8.6g弹头、785m/s枪口初速，枪口动能约2.65kJ。这是本型号代表性参考值，不同弹种、制造批次及环境允许有差异。

与[Pck-35]({{ '/articles/article-366/' | relative_url }})同口径同弹药，代表初速差异部分来自更长枪管。两者子弹与弹匣可以通用，不等于所有内部零件兼容。

其综合作战威力为旧地球7.62×39mm参考体系的3.9倍，包含精度等因素，不是枪口动能或单发物理伤害倍率。该评价的公式、测试场景、距离和权重尚未确定。

## 弹匣与外形

12发短弹匣可以减小伏姿或有支撑射击时的下方障碍。35发弹匣虽可装用，但其满载重量和下伸长度较大，不一定符合射手步枪常规使用习惯。

外观主要为沙色／黑色枪身、绿色局部发光线条及较长的上部结构。发光线条的用途及是否属于电子系统尚未明确。
