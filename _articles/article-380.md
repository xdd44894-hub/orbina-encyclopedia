**“三折磨砂板”**是一种用于[空猎-92B]({{ '/articles/article-369/' | relative_url }})有人驾驶舱的便餐／数据板。它是**单纯的三折叠磨砂塑料板**，不带专用支撑臂、电动展开机构或其他复杂机械结构。可在适宜状态下为飞行员提供临时置物、便餐与查阅任务资料的平面。

## 外形与收纳

| 项目 | 正式设定 |
| --- | --- |
| 本体 | 一块可三折的磨砂塑料板 |
| 表面 | 磨砂防滑 |
| 附属机构 | 无支撑臂，无复杂展开机构 |
| 收纳位置 | 乘员座椅坐垫左下方、靠近座椅底座的扁平收纳槽 |
| 取出方式 | 收纳板附有一根小拉带，安全状态下可抓住拉带抽出 |
| 放置方式 | 可利用座椅／收纳槽边缘形成简易小桌，也可完全摊平置于大腿上 |

## 三折结构

- **左折片**：折起后形成桌面前缘挡边，可减少餐包、坚果和小件向前滚落。
- **中折片**：主桌面，具有磨砂防滑表面，可放餐包、水袋软嘴、任务卡或小型平板。
- **右折片**：折起后形成桌面后缘卡边。展开时可借其卡在收纳槽口或座椅前缘，形成无需支撑臂的简易小桌。
- **全部摊平**：也可把板体完全展开，直接放在飞行员大腿上使用。

板体的确切尺寸、厚度、质量、颜色、塑料配方与不同座椅下的定位尺寸尚未明确，不额外添加不必要的铰链锁具、折叠机械臂或供电接口。

## 使用与飞行安全

本板适用于地面待命、任务准备与飞行状态平稳时的便餐和资料查看。由于板体、包装食品及小件物品在急剧机动中有飞散风险，进入预期高过载机动前应妥善收纳。此限制也适用于飞行员自行带入座舱的其他食品。

常见餐食见[空猎-92B机组配给餐与盒饭轶事]({{ '/articles/article-381/' | relative_url }})。板体只是轻便的生活与辅助工作用品，不替代座舱内正式显示系统、操纵器或机上生命保障设备。
